# 线性卷积与圆周卷积

> 线性卷积描述物理系统的真实输入输出关系；圆周卷积是 DFT 框架下的数学工具，用于**高效计算**线性卷积。

---

## 一、线性卷积

### 定义

$$
y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] \, h[n-k]
$$

### 物理意义

描述**真实的** LTI 系统输入输出关系。将 $h[n]$ 反转、滑动，与 $x[n]$ 逐点相乘并求和。

### 序列长度

输入 $x[n]$ 长度 $L$，$h[n]$ 长度 $M$，输出 $y[n]$ 长度 $N = L + M - 1$。

### 计算示例

$x[n] = [1, 2, 3]$，$h[n] = [1, 1]$：

- $y[0] = 1 \times 1 = 1$
- $y[1] = 1 \times 2 + 1 \times 1 = 3$
- $y[2] = 1 \times 3 + 1 \times 2 = 5$
- $y[3] = 1 \times 0 + 1 \times 3 = 3$

**结果**：$y[n] = [1, 3, 5, 3]$（长度 $3+2-1=4$）

---

## 二、圆周卷积

### 定义

$$
y_N[n] = x[n] \circledast_N h[n] = \sum_{k=0}^{N-1} x[(k)_N] \cdot h[(n-k)_N]
$$

其中 $(k)_N$ 表示 $k$ 模 $N$。序列被**周期延拓**，移位是**循环移位**。

### 频域计算

圆周卷积的核心价值——可通过 FFT 高效计算：

$$
x[n] \circledast_N h[n] = \operatorname{IDFT}_N\{\operatorname{DFT}_N\{x[n]\} \cdot \operatorname{DFT}_N\{h[n]\}\}
$$

### 计算示例

$x[n] = [1, 2, 3]$，$h[n] = [1, 1, 0]$，$N = 3$：

- $n=0$：$1\times1 + 2\times0 + 3\times1 = 4$（$h$ 反转循环移位 0：$[1, 0, 1]$）
- $n=1$：$1\times1 + 2\times1 + 3\times0 = 3$（$h$ 反转循环移位 1：$[1, 1, 0]$）
- $n=2$：$1\times0 + 2\times1 + 3\times1 = 5$（$h$ 反转循环移位 2：$[0, 1, 1]$）

**结果**：$y_3[n] = [4, 3, 5]$

---

## 三、循环移位

圆周卷积中序列的移位是按周期循环的。对于长度为 $N$ 的序列 $x$（索引从 0 开始）：

**向右循环移位 $k$ 步**：序列末尾 $k$ 个元素移到开头
- 例：$x = [1, 2, 3, 4]$，右移 1 → $[4, 1, 2, 3]$

**向左循环移位 $k$ 步**：序列开头 $k$ 个元素移到末尾
- 例：$x = [1, 2, 3, 4]$，左移 1 → $[2, 3, 4, 1]$

在圆周卷积中的 $h[(n-m) \bmod N]$ 就是循环移位（含反转）操作。

---

## 四、两者的关键联系

> **定理**：若圆周卷积点数 $N \geq L + M - 1$，则圆周卷积结果 = 线性卷积结果。

### 为什么重要？

这提供了**快速计算线性卷积**的方法：

1. 将 $x[n]$ 和 $h[n]$ **补零**至长度 $N \geq L + M - 1$
2. 分别计算 $N$ 点 FFT → $X[k]$、$H[k]$
3. 频域相乘：$Y[k] = X[k] \cdot H[k]$
4. $N$ 点 IFFT → $y[n]$ 即为线性卷积结果

对于长序列，频域法的计算量远小于直接时域卷积。这就是 **Overlap-Add** 和 **Overlap-Save** 快速卷积算法的理论基础。

---

## 五、全面对比

| | 线性卷积 | 圆周卷积 |
|---|---|---|
| **本质** | 物理操作，系统响应的真实描述 | 数学工具，DFT 的对偶运算 |
| **定义** | $y[n] = \sum_{k} x[k]h[n-k]$ | $y_N[n] = \sum_{k=0}^{N-1} x[(k)_N]h[(n-k)_N]$ |
| **结果长度** | $L + M - 1$（变长） | $N$（固定） |
| **边界处理** | 超出范围视为 0 | 周期延拓，隐含周期性 |
| **计算域** | 时域直接计算 | 频域 FFT 高效计算 |
| **应用** | 滤波器实现、系统响应 | 快速卷积（Overlap-Add/Save） |

### 一句话总结

> **线性卷积是"我们要做什么"，圆周卷积是"我们如何高效地做到它"。**
