# 论文库说明与模板

本目录存放**阅读过的论文**的消化笔记：

- **PDF 原件** → `raw/论文/<主题>/`（保持原文件名，永不修改，AI 只读）
- **消化笔记** → `wiki/论文/<主题>/<论文名>.md`（主题不存在就新建子目录）
- **论文数据库** → [[wiki/论文/论文数据库]]（每篇论文一行：作者 / 隶属机构 / 年份 / 会议 / 工艺 / 摘要 / 关键字 / 笔记链接，每次收论文自动更新）

## 文件命名

`第一作者姓氏 + 年份 + 短标题`，例如 `Razavi1996-Phase-Noise-CMOS-Oscillators.md`。中文作者直接用姓名。

## frontmatter（必填字段）

每篇论文笔记顶部必须有如下 frontmatter——博客会自动渲染成属性表，`keywords` 和 `tags` 会自动成为标签页：

```yaml
---
title: "论文标题"
authors: ["作者1", "作者2"]
year: 2023
venue: "期刊/会议名"
abstract: "摘要原文，或中文概括"
keywords: ["关键词1", "关键词2"]
tags: ["论文", "主题名"]
doi: "10.xxxx/xxxx"
---
```

## 正文结构（宽松，按需取舍）

1. **一句话核心贡献** — 这篇论文解决了什么问题、有什么亮点
2. **方法 / 系统架构** — 核心思路、框图、关键公式（公式用 `$...$`）
3. **关键结果** — 指标、对比数据（表格优先）
4. **与知识库的联系** — 用 `[[wiki/主题/文章]]` 链到相关文章
5. **个人评价** — 亮点、局限、可借鉴之处

# A Study of Phase Noise in CMOS Oscillators

**一句话贡献**：给出了 CMOS 振荡器相位噪声的完整理论框架，把噪声源到相位扰动的转换统一建模，是 PLL/时钟设计领域引用最高的经典论文之一。

## 方法
- 线性时不变（LTI）相位噪声模型：噪声 → 相位调制
- 闪烁噪声上变频机制分析
- 振荡器环路品质因数 $Q$ 与相位噪声的定量关系

## 关键结果
- 相位噪声随偏移频率的 $1/f^2$ 与 $1/f^3$ 区域划分
- 设计权衡：功耗、$Q$、噪声之间的折中

## 与知识库的联系

- 相关文章：[[wiki/抖动与相位噪声/电路中的抖动与相位噪声]]

## 个人评价
- 亮点：理论推导完整，结论有普适性
- 局限：对压控振荡器大信号效应覆盖有限（后续文献已扩展）
