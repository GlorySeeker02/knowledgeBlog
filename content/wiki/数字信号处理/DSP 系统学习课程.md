# DSP 系统学习课程

> 从零开始，系统掌握数字信号处理的核心理论与工程实践。配套可运行 Python 脚本 + 课后习题，边学边练。

## 课程大纲

| 章节 | 主题 | 内容概要 |
|------|------|----------|
| Ch01 | [信号与系统基础](信号与系统基础.md) | 连续/离散信号、基本运算、卷积、相关性 |
| Ch02 | [离散时间信号与系统](离散时间信号与系统.md) | 差分方程、LTI 系统、系统响应、稳定性 |
| Ch03 | [Z 变换](Z变换.md) | Z 变换定义、收敛域、逆 Z 变换、系统函数 |
| Ch04 | [离散傅里叶变换 DFT](离散傅里叶变换%20DFT.md) | DFS、DFT、频域采样、循环卷积 |
| Ch05 | [快速傅里叶变换 FFT](快速傅里叶变换%20FFT.md) | 基2 DIT/DIF、蝶形运算、频域分辨率 |
| Ch06 | [FIR 滤波器设计](FIR滤波器设计.md) | 窗函数法、频率采样法、等波纹设计 |
| Ch07 | [IIR 滤波器设计](IIR滤波器设计.md) | 冲激不变法、双线性变换、Butterworth/Chebyshev/Elliptic |
| Ch08 | [数字滤波器结构](数字滤波器结构.md) | 直接型、级联型、并联型、格型结构、有限字长效应 |
| Ch09 | [随机信号处理与功率谱估计](随机信号处理与功率谱估计.md) | 自相关、功率谱密度、周期图法、Welch 法、AR 模型 |
| Ch10 | [多速率信号处理](多速率信号处理.md) | 抽取、插值、多相结构、采样率转换 |
| Ch11 | [自适应滤波器](自适应滤波器.md) | LMS、NLMS、RLS、自适应噪声对消、系统辨识 |

## 学习路线

```
基础理论 ──→ Ch01 → Ch02 → Ch03
                ↓
核心变换 ──→ Ch04 → Ch05
                ↓
滤波器设计 ─→ Ch06 → Ch07 → Ch08
                ↓
进阶专题 ──→ Ch09 → Ch10 → Ch11
```

- **每天 1 章** → 约 2 周完成基础
- **每章精读 + 跑脚本 + 做习题** → 约 1.5~2 小时/章

## 环境要求

```bash
pip install numpy scipy matplotlib
```

## 使用方式

1. 按章节顺序阅读
2. 复制 Python 代码块运行验证
3. 完成课后习题

所有 Python 脚本独立可运行，不依赖其他文件。

## 课程总结

完成全部 11 章后，将掌握：

1. **时域分析**：信号分类、卷积、相关
2. **系统分析**：LTI 系统、差分方程、稳定性
3. **变换域分析**：Z 变换、DFT、FFT
4. **滤波器设计**：FIR（窗函数、等波纹）、IIR（冲激不变、双线性）
5. **滤波器结构**：直接型、级联型、格型
6. **高级专题**：功率谱估计、多速率处理、自适应滤波器

**延伸方向**：多维信号处理、小波变换、压缩感知、深度学习 DSP、实时 DSP（嵌入式/FPGA）。
