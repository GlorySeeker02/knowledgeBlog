# FIR 滤波器设计

> 第 6 章 — FIR 滤波器始终稳定、可设计线性相位，是数字滤波器的基础。

## FIR 滤波器特性

$$
H(z) = \sum_{n=0}^{M-1} h[n] z^{-n}
$$

- **始终稳定**：极点全在原点
- **可设计线性相位**：无相位失真
- **结构简单**：无反馈

## 线性相位的四种类型

| 类型 | 对称性 | 阶数 | 适用场景 |
|------|--------|------|----------|
| I 型 | 偶对称 $h[n] = h[M-n]$ | 偶阶 | 低通、带通 |
| II 型 | 偶对称 | 奇阶 | 低通、带通（$H(\pi)=0$） |
| III 型 | 奇对称 $h[n] = -h[M-n]$ | 偶阶 | 差分器、Hilbert |
| IV 型 | 奇对称 | 奇阶 | 差分器、Hilbert |

## 窗函数法

**步骤**：理想频率响应 → IDTFT → $h_d[n]$（无限长）→ 加窗截断 $h[n] = h_d[n] \cdot w[n]$

**理想低通**：$h_d[n] = \frac{\sin(\omega_c n)}{\pi n}$

### 窗函数对比

| 窗函数 | 主瓣宽度 | 旁瓣衰减 | 阻带衰减 |
|--------|----------|----------|----------|
| 矩形 | $4\pi/M$ | -13 dB | -21 dB |
| Hanning | $8\pi/M$ | -31 dB | -44 dB |
| Hamming | $8\pi/M$ | -41 dB | -53 dB |
| Blackman | $12\pi/M$ | -57 dB | -74 dB |
| Kaiser | 可调 ($\beta$) | 可调 | 可调 |

Kaiser 窗参数估计（$\beta$）：按阻带衰减 $A_s$ 选择，$\beta$ 越大旁瓣越低但主瓣越宽。

### 为什么系数越多 → 截止越陡（直觉链，2026-08-20）

1. **理想砖墙 ⟷ 无限长 sinc**：理想低通（矩形频响）的冲激响应是无限长 sinc，FIR 不可能装下。
2. **截断 = 时域乘矩形窗** → 由对偶性（时域乘法 ⟺ 频域卷积），实际频响 = 理想矩形频响 ∘ 窗频谱。
3. **卷积 = 加权平均**：某频率处的频响 = 理想频响在该点邻域内的加权平均——邻域（主瓣）越宽，砖墙边沿被"抹糊"的范围越大。
4. **窗频谱第一零点精确在 $f = 1/L$**（$L$ 个系数的矩形窗 = Dirichlet 核，主瓣全宽 $2/L$，归一化频率单位）。
5. **过渡带 ≈ 主瓣宽度 ∝ $1/L$**：L=15 → 0.133（≈133 Hz @ fs=1000）；L=64 → 0.031（≈31 Hz）。系数翻倍，过渡带减半。

**结论**：$L$ 越长 → 主瓣越窄 → 卷积抹糊范围越小 → 过渡带越窄 → 截止越陡。代价：运算量、延迟、存储。

### 吉布斯现象与 Hamming 窗（2026-08-20）

- 矩形窗频谱除主瓣外还有**旁瓣**（仅 −13 dB），卷积时旁瓣把阻带能量"漏"进带内 → 频响边沿出现过冲纹波（吉布斯现象）。
- **过冲幅度不随 $L$ 衰减**（实测：L=15→+4.1% / 31→+12.7% / 64→+7.7% / 127→+8.4% / 255→+8.6% / 511→+9.2%，围绕吉布斯极限 ~8.95% 波动收敛）；$L$ 只改变 ripple 的疏密与位置。
- **换窗才能消 ripple**：Hamming 窗 $w[n]=0.54-0.46\cos(2\pi n/(L-1))$ 把两端系数压到 0.08（中心 1.0），旁瓣降到 −41 dB → ripple ~0.1%，代价是主瓣宽一倍（过渡带 8π/M）。"窄过渡带"与"小 ripple"不可兼得，按指标取舍。

## 频率采样法

在 $[0, 2\pi)$ 上对理想频率响应采样 → IDFT 得系数。**过渡点优化**可改善阻带衰减。

## 等波纹最优设计 (Parks-McClellan)

- 最小化最大误差（Chebyshev 准则）
- 在给定阶数下获得最平坦的通带/阻带波纹
- `scipy.signal.remez`

## Python 实践要点

1. 不同窗函数设计低通 FIR，对比过渡带和阻带衰减
2. `scipy.signal.firwin` + Kaiser 窗满足给定技术指标
3. `scipy.signal.remez` 等波纹设计 + Hilbert 变换器
4. FIR 滤波实际应用（去噪 + 频谱对比）
