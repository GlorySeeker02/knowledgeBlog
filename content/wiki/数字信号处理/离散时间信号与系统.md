# 离散时间信号与系统

> 第 2 章 — LTI 系统、差分方程、冲激响应、因果性与稳定性。

## 离散时间系统

$$
y[n] = T\{x[n]\}
$$

### 系统分类

| 分类 | 定义 | 示例 |
|------|------|------|
| **线性** | $T\{ax_1 + bx_2\} = aT\{x_1\} + bT\{x_2\}$ | $y[n] = x[n] + x[n-1]$ |
| **时不变** | $y[n] = T\{x[n]\} \Rightarrow y[n-k] = T\{x[n-k]\}$ | $y[n] = nx[n]$ 非时不变 |
| **因果** | $y[n]$ 只依赖 $x[n], x[n-1], \ldots$ | $y[n] = x[n] + x[n-1]$ |
| **稳定** | $\|x[n]\| < \infty \Rightarrow \|y[n]\| < \infty$ | BIBO 稳定 |

### LTI 系统

同时满足**线性**和**时不变**。完全由冲激响应 $h[n]$ 描述：

$$
y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k]
$$

## 差分方程

N 阶 LTI 系统的一般形式（$a_0 = 1$）：

$$
y[n] = -\sum_{k=1}^{N} a_k y[n-k] + \sum_{k=0}^{M} b_k x[n-k]
$$

求解方法：经典解法（齐次+特解）、递推法、Z 变换法（Ch03）。

## FIR vs IIR

| 特性 | FIR | IIR |
|------|-----|-----|
| 冲激响应 | 有限长 | 无限长 |
| 差分方程 | $y[n] = \sum b_k x[n-k]$（无反馈） | 有反馈项 |
| 稳定性 | 始终稳定 | 需极点位于单位圆内 |
| 相位 | 可设计线性相位 | 非线性相位 |

## 因果性与稳定性

- **因果性**：$h[n] = 0, \; n < 0$
- **BIBO 稳定**：$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$（冲激响应绝对可和）
