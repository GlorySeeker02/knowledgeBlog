# 信号与系统基础

> 第 1 章 — 理解信号的基本分类、基本运算、卷积和相关性的概念。

## 信号的基本分类

### 连续 vs 离散

- **连续时间信号** $x(t)$：自变量 $t$ 取连续值
- **离散时间信号** $x[n]$：自变量 $n$ 取离散整数值，通常由连续信号采样得到 $x[n] = x_a(nT_s)$

其中 $T_s$ 为采样周期，$f_s = 1/T_s$ 为采样频率。

### 周期 vs 非周期

- 连续：$x(t + T) = x(t)$，$T$ 为周期
- 离散：$x[n + N] = x[n]$，$N$ 为正整数

### 能量 vs 功率

- **能量信号**：$E = \int_{-\infty}^{\infty} |x(t)|^2 dt < \infty$
- **功率信号**：$P = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 dt < \infty$

## 基本离散信号

| 信号 | 定义 |
|------|------|
| 单位冲激 | $\delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \neq 0 \end{cases}$ |
| 单位阶跃 | $u[n] = \begin{cases} 1, & n \geq 0 \\ 0, & n < 0 \end{cases}$ |
| 指数序列 | $x[n] = a^n \cdot u[n]$ |
| 正弦序列 | $x[n] = A \cos(\omega_0 n + \phi)$，$\omega_0 = 2\pi f / f_s$ |

## 信号的基本运算

| 运算 | 连续时间 | 离散时间 |
|------|----------|----------|
| 时移 | $x(t - t_0)$ | $x[n - n_0]$ |
| 反褶 | $x(-t)$ | $x[-n]$ |
| 尺度 | $x(at)$ | $x[Mn]$（抽取） |

## 卷积

### 定义

**连续卷积**：$(x * h)(t) = \int_{-\infty}^{\infty} x(\tau) h(t - \tau) d\tau$

**离散卷积**：$(x * h)[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k]$

### 性质

| 性质 | 公式 |
|------|------|
| 交换律 | $x * h = h * x$ |
| 结合律 | $x * (h_1 * h_2) = (x * h_1) * h_2$ |
| 分配律 | $x * (h_1 + h_2) = x * h_1 + x * h_2$ |
| 与冲激卷积 | $x * \delta = x$ |

## 相关

- **互相关**：$r_{xy}[l] = \sum_{n} x[n] \cdot y[n - l]$
- **自相关**：$r_{xx}[l] = \sum_{n} x[n] \cdot x[n - l]$

## 采样与混叠（定量，2026-08-20）

- **奈奎斯特**：$f_s \ge 2 f_{max}$，采样后可见区 $[0, f_s/2]$。
- **折叠公式**：$f_{alias} = |f - n \cdot f_s|$，取落在 $[0, f_s/2]$ 的 $n$；$f > f_s$ 时可能折叠多次（例：3400 Hz @ $f_s=2000$：3400−2000=1400 > 1000 → 再折 2000−1400=600 Hz）。
- **采样后不可逆**：真实信号与折叠镜像落在同一频点，数字滤波**无法区分也救不回**——折叠发生在采样瞬间，之后信息已混叠。例：1 MHz ADC + 1.3 MHz 谐波 → 折叠到 300 kHz 带内，必须在采样前（模拟域）处理。
- **噪声折叠**：带内噪声 PSD 抬高 $B/(f_s/2)$ 倍（每 $f_s/2$ 宽的一段噪声折一层进带内）。例：0~5 kHz 白噪声 @ $f_s=2$ kHz → 5 层 → 5×S₀。
- **抗混叠滤波器**：模拟 LPF 必须放在 ADC **之前**（"把噪声频谱关进笼子再采样"）；提高采样率只降低折叠倍数（治标），限带才是治本。
- 演示：`raw/dsp_learning/folding_demo.py`（折叠映射图）、`raw/dsp_learning/antialiasing_demo.py`（噪声 5 层折叠 vs 抗混叠）
