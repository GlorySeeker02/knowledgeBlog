# 数字环路滤波器与 ADPLL

> 从 Z 变换到数字 PLL 环路滤波器：积分器、单位圆稳定判据、PI 阻尼与极点位置。2026-08-15 苏格拉底课程产出（配合交互仿真器学习）。

## 动机

ADPLL 中，鉴相器输出**相位误差 e[n]**（数字量）→ 环路滤波器 → **频率控制字** → DCO（数控振荡器，相位 = 频率的累加，本身也是积分器）。环路滤波器设计的目标：

1. **锁定**：稳态相位误差 → 0
2. **稳定**：闭环极点全在单位圆内
3. **动态**：合适的收敛速度（阻尼 ζ ≈ 0.7）

## 核心概念

### z⁻¹ = 延迟一拍

数字系统的基本单元。`y[n-1]` 在 z 域写作 $z^{-1}Y(z)$。

### 积分器（累加器）

$$y[n] = y[n-1] + x[n] \;\Rightarrow\; H(z) = \frac{1}{1 - z^{-1}}$$

- 极点 $z=1$，恰在单位圆上 → **临界稳定**（不是发散：阶跃输入输出无限累加，这是积分器的本质行为）
- **但它是环路必需的**：误差归零后，积分器靠"记忆"（历史累加）保持非零输出，持续供给频率控制字；纯比例项在 e=0 时输出 0，无法维持锁定

### 稳定判据

因果 LTI 系统稳定 ⇔ **所有极点位于单位圆内** $|z| < 1$

极点位置速查（|λ| = 每拍衰减因子）：

| 位置 | 行为 | 记忆 |
|------|------|------|
| $\|\lambda\| = 0$ | 一拍死透，零记忆（FIR / deadbeat），最安全最快 | 能量集中在一个时间点 |
| $0 < \|\lambda\| < 1$ | 指数衰减，越靠近 1 越慢（慢尾巴） | 有记忆 |
| $\|\lambda\| = 1$ | 等幅振荡 / 临界稳定 | 能量在环内循环 |
| $\|\lambda\| > 1$ | 指数发散，失稳 | 误差每拍 ×\|λ\| 爆炸 |

### PI 环路滤波器

$$H_{LF}(z) = K_p + \frac{K_i}{1 - z^{-1}} = \frac{(K_p + K_i) - K_p z^{-1}}{1 - z^{-1}}$$

- 极点 $z=1$（积分项，压稳态误差）
- 零点 $z_0 = \frac{K_p}{K_p + K_i}$（**在单位圆内** ← 阻尼的来源）

### 闭环视角：开环不稳定 ≠ 闭环不稳定

关键认知：**闭环稳定性看闭环极点（$1 + H_{ol}(z) = 0$ 的根），不是开环极点**。负反馈把极点"拉"到新位置。

- 前向通路有两个积分器（环路滤波器 + DCO），两个极点都在 $z=1$
- **Kp = 0**（两积分器闭环）：无阻尼等幅振荡，e[n] = 1, 0, −1, −1, 0, 1, … 循环，永不锁定（能量守恒，不是发散）
- **闭环特征方程**：$\lambda^2 - (2 - K_p - K_i)\lambda + (1 - K_p) = 0$
- **Kp 拉极点进圆**：$K_p$ 直接把当前误差送进控制字 = 与误差成正比的"摩擦"（阻尼）；常数项 $1-K_p$ 降到 1 以下时极点进入圆内

Kp 取值效果（Ki=0.1）：

| Kp | 闭环极点 \|λ\| | 行为 |
|----|---------------|------|
| 0 | 1.000 | 等幅振荡，锁不上 |
| 0.3 | 0.837 | 平滑锁定 ✅ |
| 1.0 | 0 和 0.9 | 一拍过冲 + 慢尾巴（极点 λ=0 一拍死透） |
| 1.8 | 0.946 / 0.846 | 仍锁定但更慢 |
| ≥ 2 | 有一根 > 1 | 失稳，振荡着发散（Kp=2.5 时 λ≈−1.56，误差每拍 ×1.56） |

### 一型环 vs 二型环

- **一型（纯比例 Kp）**：对频率偏移有稳态误差——e=0 时控制字归零，VCO 频率回标称，锁不死频率偏移
- **二型（+积分器）**：误差归零 → **ADPLL 是二型环**
