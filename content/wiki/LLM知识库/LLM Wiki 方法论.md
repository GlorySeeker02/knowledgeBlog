# LLM Wiki 方法论

> LLM 驱动的个人知识库构建模式 —— 不是每次提问都从头检索，而是持续维护一本不断增长的百科。

## 核心思想

传统 RAG（检索增强生成）的工作方式：上传文档 → 提问时检索相关片段 → LLM 生成回答。问题是每次提问 LLM 都**从头发现知识**，没有积累。问一个需要综合五篇文档的微妙问题，LLM 每次都要重新查找和拼凑。

**LLM Wiki 的思路完全不同：** LLM **增量式地构建和维护一个持久的 wiki**——结构化的、相互链接的 Markdown 文件集合，位于你和原始素材之间。新素材不是被"索引"起来等以后检索，而是被**编译进 wiki**——更新实体页面、修订主题摘要、标注新旧矛盾、强化或挑战已有的综合。

**关键区别：wiki 是持久化的复合产物。** 交叉引用已经存在，矛盾已经标注，综合已经反映所有读过的内容。每加一篇素材，wiki 就更丰富一点。

## 三层架构

```
┌─────────────────────────────────────────────┐
│  1. Raw Sources（原始素材）— 不可变的事实来源   │
│     文章 / 论文 / 图片 / 笔记 / 数据文件       │
├─────────────────────────────────────────────┤
│  2. Wiki（知识库）— LLM 维护的消化笔记         │
│     摘要 / 概念页 / 实体页 / 对比 / 综合       │
├─────────────────────────────────────────────┤
│  3. Schema（规则文件）— 定义结构和行为          │
│     CLAUDE.md / AGENTS.md                    │
└─────────────────────────────────────────────┘
```

### 1. Raw Sources（原始素材）
- 你精选的源文档，**LLM 只读不改**
- 按主题分子目录，允许多级嵌套
- 这是你的事实来源

### 2. Wiki（知识库）
- LLM 全权负责：创建、更新、交叉引用、一致性维护
- 你阅读，LLM 写作
- 子目录深度不限，命名自由

### 3. Schema（规则文件）
- 告诉 LLM 知识库的结构、命名约定、工作流
- 关键配置：让 LLM 成为规范的管理员而非通用聊天机器人
- 你和 LLM 随着时间推移共同优化

## 三个核心操作

### Ingest（录入素材）
扔入新素材 → LLM 完成以下流程：
1. 素材存入 `raw/<主题>/`
2. 编译成 `wiki/<主题>/<文章>.md`
   - 同一核心论点 → 合并进现有文章
   - 全新概念 → 新建文章
3. 检查事实冲突，标注分歧和来源
4. 级联更新同主题受影响文章
5. 更新 `wiki/index.md`
6. 追加 `wiki/log.md`

一篇素材可能触及 10-15 个 wiki 页面。

### Query（查询）
提问 → LLM 先读 index.md 定位文章 → 深入读取 → 综合回答并引用来源。
- 默认只在对话回答，不写文件
- 加"存下来"可以把回答归档为新 wiki 文章（前缀 `[Archived]`）

### Lint（体检）
定期健康检查，分两类：

**确定性检查（自动修复）：**
- index.md ↔ 实际文件一致性
- 内部链接失效
- See Also 缺失或指向死文件

**启发式检查（只报告）：**
- 跨文章事实矛盾
- 新素材让旧论点过时
- 源头分歧未标注
- 孤岛页面
- 跨主题该链没链的概念

## 索引与日志

两个特殊文件帮助导航：

- **wiki/index.md** — 内容导向的目录，每篇文章一行（链接 + 摘要 + Updated 日期），按主题分组。查询时先读它定位文章。
- **wiki/log.md** — 时间导向的 append-only 操作日志。格式规范可用 `grep` 解析。

## 为什么有效

知识库维护最繁琐的**书签整理工作**——更新交叉引用、保持摘要最新、标注矛盾——LLM 不会觉得无聊，不会忘记，一次能处理 15 个文件。

| 角色 | 职责 |
|------|------|
| **你（人类）** | 策展素材、指导分析、提出好问题、思考意义 |
| **LLM** | 总结、交叉引用、归档、书签整理 |

思想源头可追溯到 Vannevar Bush 的 Memex（1945）——私人、主动策展的知识库。Bush 没解决的是"谁来维护"——LLM 补上了这块。

## 适用场景

- **个人知识管理** — 目标、健康、心理、自我提升
- **深度研究** — 数周数月深入一个主题
- **读书** — 逐章归档，构建人物/情节/主题网络
- **商业/团队** — 内部 wiki，由 Slack/会议/项目文档喂养
- **竞品分析、旅行计划、课程笔记、爱好深挖**
