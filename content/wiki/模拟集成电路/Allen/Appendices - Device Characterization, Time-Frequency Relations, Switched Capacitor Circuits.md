## 概述

本文覆盖 Allen & Holberg《CMOS Analog Circuit Design》第三版的三个附录（书中编号为 Appendix C/D/E）：

- **附录 C（CMOS Device Characterization）**：如何从实测数据中提取 MOS 简单模型参数、1/f 噪声参数、衬底 BJT 参数、电阻与电容的工艺参数。
- **附录 D（Time and Frequency Domain Relationships for Second-Order Systems）**：二阶低通系统的传递函数、阶跃响应、超调量与相位裕度之间的定量关系。
- **附录 E（Switched Capacitor Circuits）**：开关电容电路在 z 域的分析方法、开关电容放大器与积分器的实现、以及运放非理想因素对电路性能的影响。

三个附录共同构成模拟 IC 设计中从器件建模到系统补偿、再到采样电路实现的完整知识链。

## 附录 C：CMOS Device Characterization

附录的核心思路：**在流片前，从 wafer vendor 获取样品器件，通过电学测试提取 SPICE 等仿真所需的关键模型参数。**

### C.1 简单模型的参数提取

简单模型中有四个核心参数：`VT0`、`K'`、`γ`、`λ`，以及有效沟道尺寸偏差 `ΔL`、`ΔW`。

#### C.1.1 阈值电压 VT0 与饱和区跨导参数 K'S

**前提条件**：使 `vSB = 0` 以消除体效应，`vDS` 足够大使得 `λ·vDS` 项可忽略。

由饱和区电流公式：

```
sqrt(iD) = sqrt(K'S/2 · W/L) · (vGS − VT0)
```

**方法**：在饱和区测量多个 `(vGS, iD)` 数据点，绘制 `sqrt(iD)` vs `vGS` 曲线，线性区段的：

- **斜率** → 反推 `K'S`（需要已知 `Weff, Leff`）
- **x 截距** → `VT0`

**注意事项**：
- `W`、`L` 应选取较大尺寸以保证 `Weff ≈ W`、`Leff ≈ L`，减小 ΔW/ΔL 的相对误差。
- 弱反型区（`vGS` 靠近 `VT0`）的点和强反型迁移率退化区的点不应纳入线性回归，否则会显著偏离真实值。

#### C.1.2 非饱和区跨导参数 K'L

在非饱和区（`vDS` 很小，如 0.1V）：

```
iD = K'L · (W/L) · vDS · (vGS − VT0)
```

绘制 `iD` vs `vGS` 曲线，**斜率 m = K'L · (W/L) · vDS**，由此可提取 `K'L`，并进一步估算零场迁移率 `μ0`。

> `K'S` 和 `K'L` 通常不相同，分别表征饱和区和非饱和区的跨导行为。

#### C.1.3 体效应参数 γ

阈值电压与衬底偏置的关系：

```
VT = VT0 + γ · [sqrt(2|φF| + vSB) − sqrt(2|φF|)]
```

**方法**：
1. 在多个不同 `vSB` 值下分别测量 `VT`（每次都使用 C.1.1 的 sqrt(iD) 法）。
2. 以 `VT` 为 y 轴、`[sqrt(2|φF|+vSB) − sqrt(2|φF|)]` 为 x 轴作图。
3. 线性回归斜率即为 `γ`。

`2|φF|` 通常初始假设约 0.6~0.7 V，可通过迭代（由 γ 算出 NSUB，再由 NSUB 反算 2|φF|）提高精度。

#### C.1.4 沟道长度调制参数 λ

由饱和区公式：

```
iD = i'D · (1 + λ · vDS)
```

其中 `i'D` 为 λ=0 时的外推值。

**方法**：在饱和区绘制 `iD` vs `vDS`，**斜率 ÷ y 截距 = λ**。

**注意事项**：饱和区斜率通常非常小，数据分辨率不足时可能导致提取值误差很大。

#### C.1.5 有效尺寸偏差 ΔL 和 ΔW

利用两个**宽度相同、长度不同**的晶体管（W 应很大使 ΔW 可忽略），测量其非饱和区小信号跨导 `gm`：

```
ΔL = Leff2 − L2 = Leff1 − L1
Leff = (gm2·L2 − gm1·L1) / (gm2 − gm1)
```

同理，长度相同、宽度不同的两管可提取 ΔW。**关键**：L1 与 L2（或 W1 与 W2）应足够大以保持模型的适用性，同时差值又要大到足够避免减法误差。

### C.2 1/f 噪声参数提取

MOSFET 低频噪声的输入参考电压平方谱密度：

```
e_n^2 = (KF) / (2·K'·W·L·Cox · f)    (单位带宽 Δf = 1Hz)
```

**方法**：在对数坐标中绘制 `log(f)` vs `log(e_n^2)`，**截距**可反推出 `KF`。

### C.3 衬底 BJT 参数提取

CMOS 工艺中寄生衬底 BJT（以 p-well 工艺为例：n-substrate 为集电极、p-well 为基极、n+ 扩散为发射极）主要用于输出驱动或带隙基准。

**提取 `β_dc`**：利用 `iE = (β_dc+1)/β_dc · iC`，绘制 `iB` vs `iE`，斜率 → `β_dc`。

**提取饱和电流密度 `JS`**：由 `iC = JS·AE · exp(vBE/VT)`，取对数后做线性回归：
- 斜率 → `VT` 可验证温度
- 截距 + 已知发射极面积 → `JS`

### C.4 电阻表征

#### 薄层电阻 RS 与宽度偏差（Bias）

使用窄电阻 + 宽电阻的测试结构（Figure C.4-1），通过通电流测电压（四端法，消除接触电阻影响）：

- `Rn = RS · Ln/(Wn + Bias)`
- `Rw = RS · Lw/(Ww + Bias)`

解联立方程即可同时得到 `RS` 和 Bias。

#### 接触电阻 RC

使用两个同材料、不同方块数的电阻 `RA` = `N1·RS + 2·RC`，`RB` = `N2·RS + 2·RC`，联立求解可得 `RS` 和 `RC`。

另一种更直接的方法：用交叉梳状测试结构，四点法直接测量单个接触电阻。

#### 阱电阻的背栅效应

轻掺杂电阻（p-well、n-well）的阻值随背栅电压变化。应表征 **R = f(V_BIAS)** 的关系曲线，或用 JFET 模型描述。

### C.5 电容表征

#### MOS 寄生电容 CGSO、CGDO、CGBO

**测试方法**：使用多指宽沟道并联的晶体管测试结构以提高总电容值，电容桥测量后除以总宽度得到单位宽度电容。

**CGSO/CGDO**：将源极和漏极短接，测量栅到源-漏总电容 → 减去引线和焊盘寄生 → 得到 `CGS + CGD` → 假设对称则各取一半。

**CGBO**：先测量 poly-场氧单位面积电容 `C_poly-field`，CGBO ≈ `C_poly-field · d_overhang`（栅极超过有源区的 overhang 区域）。

#### 结电容 CJ 与 MJ

对于大面积矩形结（侧壁贡献可忽略）：

```
log[CJ(VJ)] = log[A·CJ(0)] − MJ · log(1 + VJ/PB)
```

线性回归：**斜率 = −MJ**，**截距 → CJ(0)**。类似方法适用于长窄结构来提取侧壁电容参数 CJSW 和 MJSW。

#### 互连电容

类似 poly-场氧电容的测量方法，分别测量金属-场氧、金属-poly 的大面积测试结构，得到单位面积电容值。

## 附录 D：Time and Frequency Domain Relationships for Second-Order Systems

运放电路通常可近似为二阶系统。本附录建立了**二阶低通系统在时域和频域之间的定量关系**，使得设计者可通过更容易测量的时域响应来推测频域性能。

### D.1 频域二阶系统

二阶低通传递函数的标准形式：

```
                A0 · ωn^2
H(s) = ──────────────────────────────
         s^2 + (ωn/Q)·s + ωn^2
         s^2 + 2ζωn·s + ωn^2
```

其中 `ζ = 1/(2Q)` 为阻尼因子。

#### 闭环反馈解释

设反馈框图：前向增益 `a(s) = a0 / [(1 + s/ω1)(1 + s/ω2)]`，反馈系数 β 为实数。闭环传递函数与标准二阶形式对照得到：

```
ωn^2 = (1 + a0·α·β) · ω1·ω2 ≈ a0·α·β · ω1·ω2
ζ = (ω1 + ω2) / (2ωn)
```

#### 幅频特性峰值

当 `ζ < 0.707` 时出现频率响应峰值，峰值频率和幅度为：

```
|H(jω/ωn)|_max = 1 / [2ζ·sqrt(1−ζ^2)]
```

### D.2 时域二阶系统——阶跃响应

单位阶跃响应的一般表达式（欠阻尼 `ζ < 1`）：

```
vo(t)/A0 = 1 − (1/sqrt(1−ζ^2)) · e^{−ζ·ωn·t} · sin[ωn·sqrt(1−ζ^2)·t + arccos(ζ)]
```

#### 超调量 OS（Overshoot）

```
OS = exp[−πζ / sqrt(1−ζ^2)]
```

#### 峰值时间 tp

```
tp = π / [ωn · sqrt(1−ζ^2)]
```

**实用流程**：
1. 测量阶跃响应的超调量 → 代入 OS 公式 → 反解 ζ
2. 测量峰值时间 tp → 连同 ζ 代入 tp 公式 → 反解 ωn
3. 已知 ζ 和 ωn → 完整重构频率响应

**过阻尼情况（ζ > 1）**：无超调，难以从响应中精确提取 ζ 和 ωn。建议将实验曲线与标准曲线（Figure D.2-1）对照匹配。

### D.3 从 ζ 和 ωn 确定相位裕度和交越频率

由反馈系统，**相位裕度 φm** 与 ζ 的关系（假设 β 为实数）：

```
φm = arccos[ sqrt(sqrt(4ζ^4 + 1) − 2ζ^2) ]
```

该关系通过 Figure D.3-3 以图形方式呈现——设计者可以**从阶跃响应的超调量直接读出对应的相位裕度**。例如：
- OS = 10% → φm ≈ 58°
- OS = 20% → φm ≈ 48°

**交越频率 ωc** 与 ωn 的关系：

```
ωc/ωn = sqrt[sqrt(4ζ^4 + 1) − 2ζ^2]
```

图 D.3-2 给出了该函数的曲线。

**总结**：通过测量两个时域参数（OS 和 tp），就能全面确定一个二阶系统的频域行为——包括带宽、峰值和相位裕度。

## 附录 E：Switched Capacitor Circuits

开关电容电路是模拟采样数据系统的基础，广泛应用于滤波器、ADC 前端等。信号在时间上离散、幅度上连续。

### E.1 双相非重叠时钟下的 z 域分析方法

#### 波形分解

连续信号 `v(t)` 经双相时钟采样保持后形成 `v*(t)`，可分解为奇相（φ1）和偶相（φ2）分量：

```
v*(t) = v^o(t) + v^e(t)
```

在 z 域中：`V(z) = V^o(z) + V^e(z)`

#### 四种传输函数

开关电容电路的输入和输出均可分解为奇/偶分量，因此共有四种传输函数：

| 符号 | 含义 |
|------|------|
| `H^{oo}(z)` | 奇相输入 → 奇相输出 |
| `H^{ee}(z)` | 偶相输入 → 偶相输出 |
| `H^{oe}(z)` | 奇相输入 → 偶相输出 |
| `H^{eo}(z)` | 偶相输入 → 奇相输出 |

大多数应用关注 `H^{oo}(z)` 或 `H^{ee}(z)`。

#### 分析流程

1. **选择时间参考点**：与每个时钟相位关联一个时间点（本文统一选相位开始时）。
2. **分相分析**：先分析 φ1 相，写出各电容电压；再分析 φ2 相，利用前相结果作为初始条件。
3. **写出时域差分方程**。
4. **用 `z^{-1}` 表示时延**（`v(nT) ↔ V(z)`，`v[(n−1)T] ↔ z^{-1}V(z)`）转换到 z 域。
5. **得到 `H(z)`**。

**示例**：一阶低通 SC 滤波器的传递函数为 `H^{oo}(z) = −α / (z − 1 + α)`，其中 `α = C1/C2`。

#### 频率响应

将 `z = e^{jωT}` 代入 `H(z)` 得到离散时间频率响应。

#### 过采样假设

当信号频率远小于时钟频率（`f_signal << f_c`，即 `ωT << 2π`）时，可以用小角度近似将 SC 电路的离散时间响应等效为连续时间响应，从而确定电路参数（如电容比）。

### E.2 开关电容放大器

#### 连续时间放大器回顾

- 非反相：`Av_ideal = 1 + R2/R1`
- 反相：`Av_ideal = −R2/R1`

有限增益和带宽影响：
- **有限 DC 增益 `Avd(0)`** → 增益误差，由反馈环路增益 `LG = Avd(0)/(1+R2/R1)` 决定
- **有限 GB** → 上限 −3dB 频率 `ω_H = GB / (1 + R2/R1)`（非反相）或 `GB / (1 + R2/R1)`（反相）

#### 电荷放大器

将连续时间放大器中的电阻替换为电容。注意：**电荷放大器依赖电容储能，若输入长时间不变则漏电会导致输出电压漂移**。在 SC 电路中，电容电压每周期重新定义一次，因此电荷放大器可作为电压放大器使用。

#### 反相开关电容放大器

基本结构：φ1 时 `C1` 充电至 `v_in`，`C2` 放电；φ2 时 `C1` 跨接至运放反相输入端。

理想传输函数：

```
H^{oe}(z) = −(C1/C2) · z^{−1/2}
H^{oo}(z) = −(C1/C2) · z^{−1}
```

**关键特征**：幅度恒为 `C1/C2`（与频率无关），但存在**过量线性相位延迟** `−ωT/2`（`H^{oe}`）或 `−ωT`（`H^{oo}`）。在反馈环路中使用时，该额外相移可能影响稳定性。

#### 寄生不敏感的跨阻等效

单个电容配合四开关构成**寄生不敏感跨阻**（Figure E.2-6）：
- 正跨阻：`R_T = T/C`
- 负跨阻：`R_T = −T/C`

用这些跨阻替代连续时间电路中的电阻，可实现寄生不敏感的非反相和反相 SC 放大器（Figure E.2-7）：
- 非反相：`H^{oe}(z) = (C1/C2) · z^{−1/2}`
- 反相：`H^{ee}(z) = −C1/C2`（无额外延迟！）

**两者的唯一区别**：最左侧开关的时钟相位排列顺序不同。

#### Flip-Around ×2 放大器

`C1 = C2` 时，φ1 相 `C1` 采样输入电压，φ2 相 `C1` 翻转并联到 `C2` 上 → `Av = 2`。

**优点**：相比常规 `C1 = 2C2` 的方案，反馈系数更大（`C2/(C1+C2) = 1/2` 而非 `1/3`），因此**带宽更高**。

#### 非理想效应

**时钟馈通**：开关关断时，沟道电荷注入和 overlap 电容耦合导致电容上产生直流偏移电压。包括：
- **与输入无关的偏移**：可由差分结构或时钟延迟技术抑制
- **与输入相关的偏移**：用延迟时钟 φ1d 控制输入采样开关，使其在接地开关关断后才关断

**有限 DC 增益**：`H(z)` 乘以一个小于 1 的因子 → 幅度误差。以 Avd(0)=1000、Av_ideal=10 为例，实际增益约为 9.901。

**有限 GB**：导致电荷转移不完整 → 幅度误差和相位误差。一般要求 `T > 10/GB`。

**压摆率**：输出大摆幅时，压摆率限制使建立时间延长。`T_min > ΔVo_max / SR`。

### E.3 开关电容积分器

积分器是滤波器设计的核心模块，用 SC 实现具有精确且稳定的积分常数。

#### 连续时间积分器

- 反相积分器：`H(s) = −1/(s·R1·C2) = −ω_I/s`
- 积分频率 `ω_I = 1/(R1·C2)`

#### 非反相 SC 积分器

用负跨阻（负电阻）替代 R1，实际效果相当于反相积分器 + 反相器 = 非反相积分器。

z 域传输函数：

```
H^{oo}(z) = (C1/C2) · [z^{−1} / (1 − z^{−1})]
```

频率响应（`z = e^{jωT}`）：

```
H^{oo}(e^{jωT}) = (C1/C2) · [e^{−jωT/2} / (j2·sin(ωT/2))]
```

当 `ωT << 1` 时，幅度近似为 `C1/(C2·ωT)` = `ω_I/ω`，其中：

```
ω_I = (C1/C2) · f_c
```

**积分常数由电容比和时钟频率决定，精度远优于 RC 积分器。**

#### 反相 SC 积分器

用正跨阻替代 R1 实现。其频率响应幅度与非反相相同，但**相位误差符号相反**。

关键是：**非反相和反相积分器级联时，两者的相位误差相互抵消**，使得级联滤波器在相位层面表现理想。

#### 误差分析

SC 积分器的理想传输函数可表示为：

```
H_actual(e^{jωT}) = H_ideal(jω) · [1 − m(ω)] · e^{jθ(ω)}
```

其中 `m(ω)` 为幅度误差，`θ(ω)` 为相位误差。

**有限 Avd(0) 的影响**：
- `m(ω) ≈ −C1/[C2 · Avd(0)]` （幅度误差约 −1/Avd(0) 量级）
- `θ(ω) ≈ 0` （相位误差可忽略）

**有限 GB 的影响**（Martin & Sedra 的结果）：
- `m(ω) ≈ −C1/[C2 · GB · T]` （非反相和反相相同）
- 相位误差对非反相积分器约等于零，对反相积分器约等于 `m(ω)`

#### 消除输入相关时钟馈通

使用**延迟时钟 φ1d**：先关断接地开关（φ1），等馈通稳定后关断采样开关（φ1d）。此时采样开关关断时无电流通路，charge injection 不产生偏移。

#### kT/C 噪声

开关导通电阻 `Ron` 与采样电容 `C` 构成的 RC 网络产生热噪声：

```
v_{n,rms}^2 = kT / C
```

等效噪声带宽：`f_noise = 1/(4·Ron·C)`

这是 SC 电路中不可消除的底噪来源。要降低噪声需要增大电容，但这会增加功耗和面积。
