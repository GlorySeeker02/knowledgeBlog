## 本章定位

Ch05 将 Ch04 介绍的基本子电路（电流镜、电流源/沉、共源共栅结构）组合为实用的 CMOS 放大器拓扑，是全书从 "简单电路" 到 "复杂电路" 的过渡桥梁。本章涵盖的放大器类型按信号链路组织：输入级（差分放大器）→ 增益级（共源共栅放大器）→ 输出级，最后讨论了这些级如何组合成高增益放大器。掌握本章的放大器结构是理解运放和比较器设计的前提。

## 核心概念

### 1. 反相器的三种基本构型

| 类型 | 负载 | 增益 | 输出电阻 | 输出摆幅 | 特点 |
|------|------|------|---------|---------|------|
| **Active PMOS Load** | 二极管连接的 PMOS | 低（~g_m1/g_m2） | 低（≈1/g_m2） | 受限（VDD−\|VTP\| ~ IDE 决定的底限） | 带宽最大，增益可预测 |
| **Current-Source Load** | 偏置在饱和区的 PMOS | 高（g_m1·(r_o1‖r_o2)） | 高 | VDD ~ 由底部晶体管决定 | 增益∝1/√I_D，匹配敏感 |
| **Push–Pull** | 互补驱动的 PMOS | 最高（(g_m1+g_m2)(r_o1‖r_o2)） | 高 | Rail-to-Rail | 两管同时被驱动，增益最大，直流偏置点不稳定 |

### 2. 增益与偏置电流的关系

- 电流镜/电流源负载反相器：A_v ∝ 1/√I_D（因为 g_m ∝ √I_D，g_ds ∝ I_D）。电流减小 → 增益增大。
- 趋近亚阈值区时，g_m 变成 ∝ I_D，增益趋于常数。极端情况下（W/L=10μm/1μm，I_D≈1μA），增益上限约 521 V/V。
- Push–Pull：增益对称，同样 ∝ 1/√I_D。

### 3. 频率响应与 Miller 效应

- 所有反相器在电压源驱动时呈现单极点响应：ω_{-3dB} = 1/[R_out(C_out + C_M)]，C_M = C_gd(1 + |A_v|)。
- **Miller 效应**：高阻抗源驱动反相器时，C_gd 被放大（1+增益）倍反射到输入端，产生极低频率的主导极点，严重限制带宽。
- **共源共栅结构的核心优势之一**：将 M1 漏端增益限制在 ~−2 以内，大幅削弱 Miller 效应，提升输入极点频率。

### 4. 差分放大器的关键指标

- **差模增益 A_VD**：对应 v_ID = v_1 − v_2 的放大倍数。
- **共模增益 A_VC**：对应 v_IC = (v_1+v_2)/2 的放大倍数，理想值为 0。
- **共模抑制比 CMRR** = |A_VD/A_VC|。
- **输入共模范围 ICMR**：保证所有晶体管饱和的最大/最小共模输入电压。
- **输入失调电压 V_OS**：CMOS 典型值 5–20 mV。
- **摆率 SR** = I_SS/C_L（受尾电流限制）。

### 5. 差分对的跨导

- 单端输出差分跨导（电流镜负载）：g_md = g_m1 = g_m2（输入差分管各自的跨导）。
- 差模-差模跨导：等于单管 g_m 的两倍，即 i_out/v_id = g_m1 = g_m2。
- 有效跨导退化：源极负反馈电阻 R_S 使 g_m(eff) = g_m/(1 + g_m R_S)，当 g_m R_S ≫ 2 时逼近 1/R_S，实现跨导线性化。

### 6. 沟道长度调制效应与增益的折中

- 各种放大器的增益表达式都可以归纳为 A_v = −g_m · R_out。
- R_out 取决于负载结构：简单电流源负载时为 r_o1 ‖ r_o2；共源共栅时为 g_m2·r_o2·r_o1 ‖ r_o3；双 cascode 时为 (g_m2·r_o2·r_o1) ‖ (g_m3·r_o3·r_o4)。
- 增加增益的代价是输出极点 ω_p = 1/(R_out·C_L) 降低。

### 7. 输出放大器的分类

| 类型 | 效率上限 | 导通角 | 特点 |
|------|---------|--------|------|
| **Class A** | 25% | 360° | 恒流偏置，输出电阻由器件决定，结构最简单 |
| **Class B** | 78.5% | 180° | 零静态电流，交叉失真较大 |
| **Class AB** | 25%~78.5% | 180°~360° | 小静态电流消除交叉失真，最常用 |

### 8. 源极跟随器的体效应限制

- 增益始终 < 1：A_v ≈ g_m1/(g_m1 + g_mbs1 + g_ds1 + g_ds2 + G_L)。
- 体效应使阈值随输出电压升高而增加，严重压缩正输出摆幅。
- 输出电阻 ≈ 1/(g_m1 + g_mbs1)，典型值数百 Ω，为 MOSFET 电路中最小的开环输出阻抗。

### 9. 电流放大器

- 电流放大器要求低输入阻抗（≈1/g_m 量级）、高输出阻抗、确定的电流增益。
- 基本实现：简单电流镜（R_in ≈ 1/g_m，A_i = W_2/W_1）。
- 改进：自偏置共源共栅电流镜（R_in ≈ R + 1/g_m），R 由 V_ON/I_1 设定；并联负反馈可进一步降低输入阻抗至 1/(g_m·g_m·r_o)。
- 优势：闭环带宽与闭环电压增益无关（关键结论：ω_{-3dB,CL} = ω_A·(1+A_o)）。

### 10. 直观小信号分析法

Allen 提倡用直观法替代完整的模型推导：
1. 确定跨导管（将输入电压转换为电流的晶体管）。
2. 追溯电流流向：电流经由电流镜复制/叠加，流向输出节点。
3. 乘以该节点的等效接地电阻得输出电压。
4. 关键辅助公式：
   - Cascode 输出阻抗：R_out ≈ g_m·r_o·r_o（共栅管倍增共源管输出阻抗）。
   - 源极退化有效跨导：g_m(eff) = g_m/(1 + g_m·R_S)。

## 关键公式与结论

### 反相器（5.1）

- **Active Load 增益**：A_v = −g_m1/(g_m2 + g_ds1 + g_ds2) ≈ −g_m1/g_m2
- **Current-Source Load 增益**：A_v = −g_m1 · (r_o1 ‖ r_o2)
- **Push–Pull 增益**：A_v = −(g_m1+g_m2)(r_o1 ‖ r_o2)
- **等效输入噪声**：e²_eq = e²_n1 + e²_n2(g_m2/g_m1)² + 热噪声贡献（白噪声）；1/f 噪声由输入管 M1 主导（若 L1 ≪ L2）。
- **频率响应（电压源驱动）**：
  - 零点（RHP）：z_1 = +g_m1/C_gd1
  - 极点：p_1 = −1/[R_out(C_out + C_M)]，其中 C_M = C_gd(1 + |A_v|)

### 差分放大器（5.2）

- **差模跨导（电流镜负载，单端输出）**：i_out/v_id = g_m1 = g_m2
- **差模电压增益（电流镜负载）**：A_VD = g_m1 · (r_o2 ‖ r_o4) = [2/(λ_N+λ_P)] · √[2K'_N·(W/L)_1/I_SS]
- **共模增益（电阻/二极管负载）**：A_VC ≈ −g_m1·R_load / (1 + 2g_m1·r_o5) → 增大 r_o5 可抑制共模增益。
- **CMRR（二极管负载）**：CMRR ≈ g_m1·r_o5 · (g_m3+g_ds3)/(g_m1+g_ds1) → 使用 cascode 尾电流源可提高 g_m·r_o 倍。
- **ICMR 上限（n 管输入，电流镜负载）**：V_IC(max) = V_DD − V_SG3 + V_TN1
- **ICMR 下限（n 管输入）**：V_IC(min) = V_SS + V_GS1 + V_DS5(sat)
- **摆率**：SR = I_SS/C_L
- **等效输入 1/f 噪声**：e²_eq(1/f) ≈ 2[K_FN/(C_ox·W_1·L_1·f) + K_FP·K'_P/(K'_N·C_ox·W_3·L_3·f)]

### 共源共栅放大器（5.3）

- **简单 cascode 增益**：A_v ≈ −g_m1 · r_o3（因为 cascode 输出阻抗远大于 r_o3，R_out ≈ r_o3）
- **双 cascode 增益**：A_v ≈ −g_m1 · [(g_m2·r_o2·r_o1) ‖ (g_m3·r_o3·r_o4)]，增益可达 ~400 V/V 以上
- **增益与偏置电流关系**（双 cascode）：A_v ∝ 1/I_D
- **从 M2 源端看入的阻抗**：R_s2 = (r_o3 + r_o2)/[1 + g_m2·r_o2] ≈ (r_o3+r_o2)/(g_m2·r_o2)，当 r_o3 = r_o2 时 ≈ 2/g_m2；当 r_o3 → ∞ 时 ≈ r_o2
- **Miller 效应消除**：M1 漏端增益 ≈ −2（仅由 2/g_m2 决定），C_gd1 不被大幅放大
- **极点估算方法**：依次短路已有极点对应的节点，用 (R_node·ΣC_node)⁻¹ 估算下一极点。
- **零点**：C_gd1 提供前馈路径，产生 RHP 零点 z = +g_m1/C_gd1。

### 电流放大器（5.4）

- **简单电流镜**：R_in ≈ 1/g_m1，A_i = g_m2/g_m1，R_out = r_o2
- **自偏置 cascode 电流镜**：R_in ≈ R + 1/g_m1，A_i ≈ 1（V_DS1 = V_DS2 精确匹配时），R_out ≈ g_m4·r_o4·r_o2
- **并联负反馈电流放大器**：R_in ≈ 1/(g_m1 · g_m3·r_o3) ≪ 1/g_m1

### 输出放大器（5.5）

- **Class A 效率（理想正弦）**：η_max = 25%
- **Class B 效率（理想正弦）**：η_max = 78.5%
- **源极跟随器增益（含体效应）**：A_v = g_m1/(g_m1 + g_mbs1 + g_m2 + g_ds1 + g_ds2 + G_L) < 1
- **源极跟随器输出阻抗**：R_out ≈ 1/(g_m1 + g_mbs1 + g_m2)
- **Push–Pull 源极跟随器增益**：A_v = (g_m1+g_m2)/(g_m1+g_mbs1+g_m2+g_mbs2+g_ds1+g_ds2+G_L)
- **体效应导致的输出摆幅限制**（源极跟随器）：v_OUT(max) ≈ [V_DD − V_T0 − 2φ_F]/[1 + γ/(2√(2φ_F+v_OUT))]，典型 NMOS 源随仅约 1.5V（VDD=2.5V 时）


## 设计启示

1. **增益与带宽是根本折中**：R_out 增大 → 增益增大 → 主导极点频率降低。高增益放大器需更复杂的频率补偿。

2. **偏置电流的双刃剑**：减小 I_D 提高增益但不提高 g_m/I_D 效率；增大 I_D 提高带宽（降低 R_out）和摆率。

3. **Cascode 是多用途工具**：既可提高输出阻抗获取高增益，又可抑制 Miller 效应提高带宽，还可用作电流镜提升精度。

4. **CMRR 设计本质是增大尾电流源阻抗**：从简单电流源 → Cascode 电流源 → 有源负反馈，每一步提升约 g_m·r_o 倍。

5. **体效应不可忽略**：源极跟随器摆幅、共模范围、增益都受体效应显著影响。p-well 工艺中可考虑将输入差分对置于浮空阱中消除体效应（代价是阱-衬底电容）。

6. **输出级设计须同时考虑 R_L 和 C_L**：阻性负载决定最大输出电流，容性负载决定摆率。两者中限制更严格的成为设计瓶颈。

7. **直观分析法的价值**：掌握 g_m(eff) 和 R_out 的快速估算公式后，绝大多数单级放大器增益可通过观察电路图直接写出，无需建立完整小信号模型。

8. **电流放大器在高频/低电压场景中日益重要**：闭环带宽与闭环电压增益无关的特性使其在可编程增益放大器中具有天然优势。低输入阻抗天然适合低电源电压下信号以电流形式传输的系统。
