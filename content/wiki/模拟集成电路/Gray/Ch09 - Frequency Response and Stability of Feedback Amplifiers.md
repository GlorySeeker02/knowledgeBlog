# 第9章：频率响应与反馈放大器稳定性

## 本章定位

第9章在第8章（反馈）的基础上，回答一个核心问题：**负反馈改善了增益灵敏度、失真和阻抗，但在高频下会带来什么代价？** 答案是：多极点放大器在深度反馈下会**振荡**。本章系统建立稳定性理论（Nyquist判据、相位裕度），然后给出解决振荡问题的工程手段——频率补偿（compensation），最后讨论补偿对大信号高速性能（摆率）的制约。

本章的分析框架建立在两端口反馈模型（$a$ + $f$）之上，但也说明了如何通过变量替换与第8章的 return-ratio 分析对应（见附录 A9.1）。

---

## 核心概念

### 反馈的带宽扩展效应（单极点情况）

对于只有一个极点 $p_1$ 的基本放大器：

$$a(s) = \frac{a_0}{1 - \frac{s}{p_1}}$$

接入纯电阻反馈 $f$ 后，闭环增益为：

$$A(s) = \frac{a(s)}{1 + a(s)f} = \frac{A_0}{1 - \frac{s}{(1 + T_0)|p_1|}}$$

其中 $T_0 = a_0 f$ 为低频环路增益。

> [!important] 增益-带宽权衡
> 反馈使低频增益降低 $(1+T_0)$ 倍，但 −3 dB 带宽增大 $(1+T_0)$ 倍。**增益-带宽积不变。**
> 这也意味着：环路增益越大，主极点沿负实轴外移越远（见图 9.3 根轨迹）。

这个单极点情况始终稳定（相位裕度约 90°），但**只是理想化情形**。实际放大器有多个极点。

---

## 稳定性判据

### 多极点放大器与振荡

考虑三极点基本放大器：

$$a(s) = \frac{a_0}{\left(1 - \frac{s}{p_1}\right)\left(1 - \frac{s}{p_2}\right)\left(1 - \frac{s}{p_3}\right)}$$

Bode 图上，随频率升高：
- 幅频曲线依次经历 −6 dB/oct → −12 dB/oct → −18 dB/oct
- 相频曲线依次经历 −45° → −135° → −225° → −270°

当 $\angle T(j\omega_{180}) = -180^\circ$ 时，若 $|T(j\omega_{180})| \ge 1$，放大器振荡。

### Nyquist 判据

> [!abstract] Nyquist 稳定性判据
> "考虑一个反馈放大器，其 $T(s)$ 稳定（所有极点在左半平面）。若 $T(j\omega)$ 的 **Nyquist 图** 包围点 $(-1, 0)$，则反馈放大器**不稳定**。"
>
> ——包围次数等于右半平面极点数。

**物理意义**：若 $T(j\omega_{180}) = -1$，则 $A(j\omega) \to \infty$——极点落在 $j\omega$ 轴上，系统等幅振荡（临界稳定）。若 $T_0$ 进一步增大，极点进入右半平面 → 增幅振荡 → 不稳定。

### 相位裕度与增益裕度

从 Nyquist 判据可导出更易于工程使用的简化判据：

- **相位裕度（Phase Margin）**：$\text{PM} = 180^\circ + \angle T(j\omega_0)$，其中 $\omega_0$ 满足 $|T(j\omega_0)| = 1$（即单位环路增益频率）。
  - PM 必须 $> 0^\circ$ 才稳定。
  - 工程上通常要求 $\text{PM} \ge 45^\circ \sim 60^\circ$。

- **增益裕度（Gain Margin）**：在 $\angle T = -180^\circ$ 的频率处，$|T|^{-1}$ 的 dB 值，必须 $>0$ dB。

> [!warning] 相位裕度的物理意义
> - PM = 90°（单极点）：闭环无过冲，−3 dB 在 $\omega_0$。
> - PM = 60°：闭环在 $\omega_0$ 处基本平坦，约 0.2 dB peaking。
> - PM = 45°：闭环在 $\omega_0$ 处有约 2.4 dB（1.3倍）增益 peaking。
> - PM = 30°：严重 peaking。
> - PM → 0°：振荡。

**注意**：相位裕度和增益裕度只有在唯一定义时才可直接使用。若环路增益幅频/相频曲线有多重穿越，必须回到 Nyquist 图判断。

## 关键公式与结论

### 闭环增益与环路增益的关系

$$A(j\omega) = \frac{a(j\omega)}{1 + T(j\omega)}$$

在 Bode 图上，$20\log_{10}|A(j\omega)|$ 的低频段由所需闭环增益水平线决定，在高频段（$|T| \to 0$）退化为 $20\log_{10}|a(j\omega)|$。

Bode 图中 $20\log_{10}|a(j\omega)|$ 与 $20\log_{10}(1/f)$ 之间的**垂直距离**就是环路增益的 dB 值 $x = |T(j\omega)|_{\text{dB}}$。

### 单极点 PM = 90° 的证明

对单极点放大器，$p_1$ 在 $\omega_0$ 处产生 −90° 相移（远低于 $p_1$ 时有 −45°，但在 $\omega_0$ 远大于 $|p_1|$ 时已接近 −90°），因此 $\text{PM} = 180^\circ - 90^\circ = 90^\circ$。

## 频率补偿技术

### 补偿的基本思想

**问题**：给定一个多极点放大器，若反馈过深（$f$ 过大），环路增益在 $\omega_{180}$ 处仍 $\ge 1$，导致振荡。

**解决**：人为引入/移动一个**主极点**（dominating pole），使增益在到达第二个极点前就降到 0 dB 以下，此时相移尚未达到 −180°。

**代价**：带宽减小。

### 方法一：增加新的主极点（窄带化）

在放大器输入端或级间增加一个大电容，创造一个频率很低的新极点 $p_D$，使幅频曲线以 −6 dB/oct 穿 0 dB 线时相移仅约 −90° ∼ −135°。

**缺点**：电容极大（通常 >1000 pF），难以在单片集成电路上实现；带宽浪费严重。

### 方法二：压低原有主极点（Miller 补偿）

将补偿电容 $C$ 跨接在增益级的输入和输出之间。利用 Miller 效应：

$$C_{\text{eff}} \approx C \cdot (1 + g_m R_L)$$

等效输入电容被放大 $(1 + A_v)$ 倍，小电容（~30 pF）即可产生足够低的极点频率，可**片上集成**。

### Pole Splitting（极点分裂）——Miller 补偿的核心机制

分析两极点等效电路（图 9.18）得出（假设 $g_m R_1, g_m R_2 \gg 1$，且极点实且分离）：

$$p_1 \simeq -\frac{1}{g_m R_1 R_2 C}$$

$$p_2 \simeq -\frac{g_m C}{C_1 C_2 + C(C_1 + C_2)}$$

> [!tip] Pole Splitting 的本质
> 增大 $C$ 时：
> - **$|p_1|$ 减小**（向低频移动）——Miller 效应增大第一级输出的等效时间常数。
> - **$|p_2|$ 增大**（向高频移动）——$C$ 对第二级提供了负反馈，降低了输出电阻 $R_o$。
>
> 两个极点一个向左、一个向右分裂，如图 9.19 所示。这比单纯给 $C_1$ 加电容（只移动 $p_1$ 而不提升 $p_2$）高效得多。

### 两级 CMOS 运放补偿（9.4.3）

CMOS 运放的特殊挑战：$g_m$ 比 BJT 低约一个数量级，导致 Miller 补偿产生的**右半平面零点** $z = +g_m/C$ 可能落在单位增益频率以下。

RHP零点的影响：幅频曲线+6 dB/oct 抵消了补偿电容的 −6 dB/oct 滚降，同时相位多 −90°（正实零点恶化相位）。

**三种消除 RHP 零点的方法**：

1. **源跟随器隔离**（图 9.21a）：在 $C$ 的输出端串入源跟随器，阻断前馈电流。→ 消除了零点，但占用电压余度。
2. **共栅管隔离**（图 9.22a）：$C$ 接共栅管的源极，利用共栅极高输出阻抗阻断前馈。→ 消除了零点，$p_2$ 提升更显著，但对电流源匹配敏感。
3. **串联电阻调零**（图 9.24a）：在 $C$ 上串电阻 $R_Z$，使零点移动到无穷远处。
   - 条件：$R_Z = 1/g_m$。
   - 若 $R_Z > 1/g_m$，零点移至左半平面，可**改善相位裕度**。
   - $R_Z$ 通常用线性区 MOS 管实现，并使 $R_Z$ 跟踪 $1/g_m$。

### 单级 CMOS 运放补偿（9.4.4）

Telescopic cascode 和 folded cascode 等单级运放只有输出节点设置主极点。不能使用 Miller 补偿。

- 主极点由 $R_o C_L$ 决定（$R_o$ 为输出阻抗）。
- 次极点在 cascode 源极节点，约 $g_{m,\text{casc}} / C_p$。
- **Fold cascode 的次极点更近**（因为 cascode 节点电容 $C_p'$ 更大 → 单位增益带宽受限更严重）。
- 补偿策略：增大 $C_L$ 压低主极点，或添加额外并联电容。

### 嵌套 Miller 补偿（9.4.5）

三级及以上增益级的运放，需要**嵌套 Miller 补偿**（Nested Miller Compensation）。

**基本原理**：
- $C_{m1}$ 跨接在末级：使第二三级综合频率响应表现出一个主极点。
- $C_{m2}$ 跨接在末两级：在第一级输出产生进一步 Miller 放大的主极点，同时通过负反馈将第二个极点推高。

**关键设计要求**：$g_{m2} > g_{m1}$（否则高频极点进入右半平面）。

**RHP 零点消除**：嵌套补偿产生两个零点（一个LHP、一个RHP）。在低电源电压下，传统消除方法受限，可用**前馈跨导**（Fig. 9.33a）消除零点。取 $g_{mf} = g_{m1}$ 时零点移入左半平面。

## Root-Locus（根轨迹）技术

### 频率域方法与根轨迹的关系

|  | 频率域（Bode/Nyquist） | 根轨迹 |
|---|---|---|
| 核心对象 | $|T(j\omega)|$ 和 $\angle T(j\omega)$ | 闭环极点在 $s$ 平面的位置 |
| 优势 | 直观，设计补偿电容方便 | 全面展示极点随 $T_0$ 的运动 |
| 典型用途 | 补偿设计、PM/GM 计算 | 了解瞬态响应、peaking、Q 值 |

### 根轨迹基本规则

1. **起点终点**：分支起始于 $T(s)$ 的极点（$T_0=0$），终止于 $T(s)$ 的零点（$T_0 \to \infty$）。若极点多于零点，部分分支终止于无穷远。
2. **实轴分布**：若 $T(s)$ 的所有零极点在 LHP（或偶数个 RHP 零点），根轨迹在实轴上位于有**奇数个**零极点**右侧**的部分。
3. **脱离点**：实轴上两极点之间的根轨迹必定在某一内点脱离实轴，且离开时与实轴成直角。
4. **渐近线**：终止于无穷远的分支渐近线与实轴夹角为 $\frac{(2n-1)\pi}{N_p - N_z}$（无 RHP 零点或偶数个）。
5. **对称性**：轨迹关于实轴对称。

### 三极点放大器根轨迹（9.5.1）

三个相同极点 $p_1$ 的放大器：
$$a(s) = \frac{a_0}{(1 - s/p_1)^3}$$

根轨迹显示（图 9.35）：$T_0 = 8$ 时复数极点进入右半平面。即：三个相同极点的放大器在 $T_0 > 8$ 时振荡——条件相当苛刻，凸显补偿的必要性。

### 反馈零点补偿（9.5.4）

不同于在基本放大器内加主极点，可在反馈网络中引入零点。该零点会**将根轨迹弯离 $j\omega$ 轴**，降低极点 Q 值（抑制 peaking），同时不牺牲带宽。

> [!note] Phantom Zero
> 反馈网络引入的零点是 $T(s)$ 的零点（影响根轨迹），但**不是**闭环传递函数 $A(s)$ 的零点——故称 "phantom zero"。它改善了稳定性而不在最终输出中添加零点影响。

## 摆率（Slew Rate）

### 小信号与大信号响应的差异

> [!warning] 摆率限制的起源
> 大信号阶跃下，运放输入差分对进入**限幅非线性**（$|V_{id}| > 3V_T$ 或 $\sqrt{2}V_{ov}$），差分对输出电流被尾电流 $2I_1$ 所限。补偿电容以恒定电流充电，输出电压呈线性斜坡而非指数上升。

基本关系：
$$\text{SR} = \frac{dV_o}{dt}\bigg|_{\max} = \frac{I_{xm}}{C}$$

其中 $I_{xm}$ 为第一级可提供的最大充放电电流（对简单差分对 $I_{xm} = 2I_1$）。

### 小信号与大信号的统一视角

对于两极点 Miller 补偿运放，小信号单位增益频率 $\omega_u$ 和大信号摆率 SR 的关联：

$$\text{SR} = \frac{I_{xm}}{g_{mI}} \cdot \omega_2$$

其中 $\omega_2$ 为次极点频率。**提高 $\text{SR}$ 的关键**：增大 $I_{xm}/g_{mI}$ 比值。

| 方法 | 实现 | 局限 |
|---|---|---|
| BJT 加射极退化电阻 | $R_E$ 降低 $g_{mI}$，$C$ 减小 | 电阻失配贡献失调电压 |
| MOS 减小 $(W/L)_1$ | $g_{mI}$ 降低 | 第一级增益下降 |
| MOS 增大尾电流 | $I_{xm}$ 增大（$\propto \sqrt{x}$） | 失调增大 |
| Class AB 输入级 | $I_{xm}$ 远大于静态电流 | 晶体管关断/开启有恢复时间 |

### 满功率带宽

$$\omega_{\text{FP}} = \frac{\text{SR}}{\hat{V}_i}$$

当正弦信号的 $\omega \hat{V}_i$ 超过摆率极限时，输出波形出现摆率限制失真（图 9.57b）。

## 设计启示

1. **反馈越深，越需要补偿**——闭环增益越低（$f$ 越大），环路增益越高，相位裕度越小。
2. **补偿方案的选择取决于所需增益**——针对特定增益补偿（Fig. 9.14）比统一单位增益补偿（Fig. 9.12）显著节省带宽。
3. **增益级数量越少越好**——每增加一级就多引入极点，补偿更困难。能用 cascode 提高增益就别加级。
4. **Pole splitting 是最有效的单片补偿手段**——Miller 电容既压低主极点又推高次极点，比单纯加并联电容高效。
5. **CMOS 运放必须处理 RHP 零点**——低 $g_m$ 特性使 RHP 零点频率较低，用调零电阻或隔离级消除。
6. **在线性度和速度间权衡**——加大输入对偏置电流提升摆率，但可能增大失调、降低增益并增加功耗。
7. **单级运放设计要点**——负载电容即为补偿电容，合理选择 $C_L$ 保证相位裕度；folded cascode 次极点更低，带宽受限更明显。
8. **三级运放的嵌套补偿**——需要 $g_{m2} > g_{m1}$ 保证高频极点位于 LHP；两个补偿电容用迭代法或计算机优化确定。
9. **SPICE 仿真是补偿设计的重要工具**——环路增益的仿真（return ratio 技术）能捕捉寄生效应（如输入电容引起的反馈网络频率依赖性）对相位裕度的影响。
10. **摆率与带宽的工程设计**——通过 $I_{xm}/g_{mI}$ 比率规划摆率性能。高摆率应用优先考虑 Class AB 输入级或退化技术。

## 检索关键词

- **Nyquist 判据** — 稳定性判断的充要条件，判断 $T(j\omega)$ 是否包围 $(-1,0)$
- **相位裕度 (Phase Margin)** — 单位环路增益频率处的相移距离 −180° 的余量，工程最常用判据
- **增益裕度 (Gain Margin)** — $\angle T = -180^\circ$ 处的环路增益倒数
- **频率补偿 (Compensation)** — 通过窄带化或极点分裂实现稳定
- **Miller 效应补偿** — 电容跨接增益级，利用 Miller 放大减小所需电容值
- **Pole Splitting** — 增大 $C$ 使主极点变低、次极点变高，是 Miller 补偿的核心机制
- **右半平面零点 (RHP Zero)** — CMOS Miller 补偿的特有问题，$z = +g_m/C$
- **调零电阻 (Nulling Resistor)** — $R_Z = 1/g_m$ 消除或移动 RHP 零点
- **嵌套 Miller 补偿 (NMC)** — 三级及以上运放的层级化 Miller 补偿方案
- **根轨迹 (Root Locus)** — $T_0$ 变化时闭环极点在 $s$ 平面的运动轨迹
- **Phantom Zero** — 反馈网络零点的闭环特性：影响根轨迹但不成为闭环零点
- **摆率 (Slew Rate)** — 大信号速度极限，$\text{SR} = I_{xm}/C$
- **满功率带宽** — 给定输出电压摆幅下不出现摆率限制的最高正弦频率
- **Class AB 输入级** — 打破尾电流限制以实现高摆率
