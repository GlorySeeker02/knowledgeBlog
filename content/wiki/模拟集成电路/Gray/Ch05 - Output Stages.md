# 第五章 输出级

## 本章定位

输出级是放大器与负载之间的最后一级。它的核心任务不是提供电压增益，而是**以可接受的低失真将信号功率传递给负载**。本章系统分析 Class A、Class B、Class AB 三种输出级拓扑，覆盖双极型和 CMOS 两种工艺实现，并深入讨论效率、失真、热耗散和过载保护等工程问题。

## 核心概念

### 1. 输出级的设计目标

- **功率传输**：向负载提供规定的信号功率。
- **低输出阻抗**：使电压增益对负载阻抗不敏感。
- **低失真**：在大信号摆幅下保持良好的线性度。
- **低静态功耗**：无信号时消耗尽量少的功率。
- **频率响应**：不成为放大器带宽的主要瓶颈。

### 2. Class A 输出级

**定义**：输出器件在整个信号周期内始终导通。

- 最简单的实现是射极跟随器（BJT）或源极跟随器（MOS）。
- **最大效率只有 25%**（理想情况，$V_{CE(\text{sat})} \ll V_{CC}$）。
- 无信号时仍在消耗静态功率 $P_{\text{supply}} = 2V_{CC}I_Q$，效率随输出功率增大而增大。
- 适合对线性度要求高但功率要求不高的场景。

### 3. Class B 输出级（推挽）

**定义**：两个有源器件各导通半个周期（push-pull），无信号时静态功耗为零。

- 理想**最大效率 78.6%**（$\eta_C = \frac{\pi}{4} \frac{\hat{V}_o}{V_{CC}}$），远高于 Class A。
- 效率与 $\hat{V}_o$ 成正比，与 $R_L$ 无关。
- 致命缺陷：**交越失真（crossover distortion）**——两个管子切换时存在 $2V_{BE(\text{on})}$ 的死区。

### 4. Class AB 输出级

**定义**：给 Class B 的两个输出管施加小静态偏置电流，消除交越失真死区，同时仍保持接近 Class B 的高效率。

- 用二极管或二极管接法的晶体管并联在输出管的基极-发射极之间提供偏置。
- 静态电流由输出管与偏置二极管的面积比决定。
- 实际电路中几乎总是配合负反馈使用以进一步降低失真。

### 5. 热与安全

- **瞬时功率耗散**由 $P_c = I_c V_{ce}$ 描述，在 Ic-Vce 平面上为双曲线。
- 最大瞬时耗散出现在**负载线的中点**——负载线与功率双曲线在该点相切。
- **短路保护**：通过串联小电阻检测输出电流，过流时旁路驱动电流（如 741 运放中的 $Q_{15}$ 和 $R_6$）。

### 6. CMOS 输出级的特殊问题

- **共漏 Class AB**：输出摆幅受阈值电压和过驱动电压的严重限制，远不如对应的 BJT 电路。
- **共源 + 误差放大器**（准互补）：用共源管配合低增益误差放大器模拟源跟随器行为，输出摆幅可以比共漏结构更接近电源轨。
- **体效应**在源跟随器中引入非线性失真（二次谐波 $HD_2$ 与 $\gamma$ 近似成正比）。
- 误差放大器的增益需要**折中**：高增益降低失真但恶化静态电流控制，低增益（$A < 8 \sim 10$）能限制失配引起的静态电流变化。

### 7. 驱动级限制

输出级的实际最大摆幅常受限于**前级驱动级**，而非输出管本身。因为驱动级通常用与输出级相同的电源电压，一旦驱动级饱和或截止，输出信号就发生削波。

## 关键公式与结论

### Class A 射极跟随器

| 参数 | 公式 | 说明 |
|------|------|------|
| 最大输出功率（最优负载） | $P_{L\max} = \frac{1}{2} I_Q [V_{CC} - V_{CE(\text{sat})}]$ | $R_L = R_{L3} = [V_{CC} - V_{CE(\text{sat})}]/I_Q$ |
| 电源功率 | $P_{\text{supply}} = 2V_{CC}I_Q$ | 恒定，与信号无关 |
| 最大效率 | $\eta_{C\max} = \frac{1}{4} \frac{V_{CC} - V_{CE(\text{sat})}}{V_{CC}}$ | 理想极限 25% |
| 平均耗散（满摆幅） | $\overline{P_{c1}} = \frac{1}{2} V_{CC} I_Q$ | 为静态值的一半 |
| 削波条件（小 $R_L$） | $V_o^{\min} = -I_Q R_L$ | 若 $I_Q R_L < V_{CC}$ 则负向先削波 |

### Class B 推挽

| 参数 | 公式 | 说明 |
|------|------|------|
| 电源平均电流 | $\overline{I_{\text{supply}}} = \frac{\hat{I}_o}{\pi}$ | 半波正弦 |
| 电源功率 | $P_{\text{supply}} = \frac{2}{\pi} V_{CC} \hat{I}_o$ | 随信号线性增长 |
| 效率 | $\eta_C = \frac{\pi}{4} \frac{\hat{V}_o}{V_{CC}}$ | 与 $R_L$ 无关 |
| 最大效率 | $\eta_{C\max} = \frac{\pi}{4} \left(1 - \frac{V_{CE(\text{sat})}}{V_{CC}}\right)$ | 理想极限 $\frac{\pi}{4} \approx 78.6\%$ |
| 峰值瞬时耗散 | $V_{ce} = \frac{2}{\pi} V_{CC}$ 处 | 负载线中点 |

> [!important] 功率传递的几何解释
> 平均输出功率 $P_L = \frac{1}{2}\hat{I}_o \hat{V}_o$ 等于 Ic-Vce 平面中由负载线和坐标轴围成的**三角形面积**。最优负载使该三角形面积最大。

### Class AB（CMOS 共漏）

| 参数 | 公式 |
|------|------|
| 静态电流关系 | $\sqrt{\frac{2I_{D1}}{k'(W/L)_1}} + \sqrt{\frac{2I_{D1}}{k'(W/L)_2}} = \sqrt{\frac{2I_{D4}}{k'(W/L)_4}} + \sqrt{\frac{2I_{D5}}{k'(W/L)_5}}$ |
| 最大正输出 | $V_o^+ = V_{DD} - V_{gs1} - |V_{ov3}|$ |

### 源跟随器失真（Class A MOS，忽略 $R_L$ 时）

$$
HD_2 \approx \frac{\hat{v}_i}{4} \cdot \frac{\gamma}{(V_O + V_{DD} + 2\phi_f)^{3/2}}
$$

$$
HD_3 \approx \frac{\hat{v}_i^2}{32} \cdot \frac{\gamma}{(V_O + V_{DD} + 2\phi_f)^{5/2}}
$$

- $HD_2$ 与信号幅度 $\hat{v}_i$ 成**线性**关系。
- $HD_3$ 与 $\hat{v}_i^2$ 成**平方**关系。
- 消除体效应（将源跟随器放在隔离阱中，源与阱短接）可消除该失真。

### 共源准互补级增益误差

共源 + 误差放大器结构的小信号增益为：

$$
\frac{v_o}{v_i} \approx \frac{2A g_m R_L}{1 + 2A g_m R_L}
$$

增益误差约 $1/(2A g_m R_L)$，其中 $A$ 为误差放大器增益，Loop gain = $2A g_m R_L$。

### 误差放大器增益约束（静态电流控制）

$$
A_{\max} \approx \frac{2V_{ov}}{V_{OSP} - V_{OSN}} \cdot (\text{允许的 } \Delta I_Q/I_Q)
$$

例如 $V_{ov}=200\text{mV}$、$V_{OS}=5\text{mV}$、允许 20% 偏差时，$A \leq 8$。

## 重要电路结构

### 1. Class A 射极跟随器输出级（Fig. 5.1）

```
         +Vcc
          |
          Q1
 Vi --+--B   E--+-----+---- Vo
      |         |     |
      |       I_Q    R_L
      |         |     |
     R3        Q2    GND
      |         |
     Q3  R1    R2
      |   |     |
     GND GND  -Vcc
```

- $Q_1$：射极跟随器输出管。
- $Q_2$：电流源偏置，提供静态电流 $I_Q$。
- $Q_3, R_1, R_3$：电流镜基准。
- 传输特性分为三个区域：$Q_1/Q_2$ 均放大（线性区）、$Q_1$ 饱和（正饱和）、$Q_2$ 饱和或 $Q_1$ 截止（负饱和/削波）。

### 2. Class B 互补输出级（Fig. 5.10）

```
         +Vcc
          |
          Q1 (npn)
 Vi --+--B   E--+---- Vo
      |         |
      |        R_L
      |         |
      +--B   E--+
          Q2 (pnp)
          |
         -Vcc
```

- 无偏置时存在 $2V_{BE(\text{on})}$ 死区。
- 正半周 $Q_1$ 导通 $Q_2$ 关断，负半周相反。
- 加上二极管偏置（Fig. 5.13）即变为 Class AB。

### 3. 全 npn Class B 输出级（Fig. 5.22）

```
          Vcc
           |
          Q3 (pnp 电流源)
           +----+---- V2
           |    |
           D1   Q2 (npn EF)
           |    E----+---- Vo
           +----+    |
           |    |    R_L
           D2   |    |
           |    |   GND
          Q1 (CE)   |
          E----------+
           |
          -Vcc
```

- 两个输出管都是大功率 **npn**，克服了衬底 pnp 电流能力不足的瓶颈。
- $Q_1$ 自举驱动 $Q_2$：正半周 $Q_1$ 驱动 $Q_2$ 做射随，负半周 $Q_1$ 做共射输出。
- 用于瓦级以上的功率运放（如 791）。

### 4. 741 运放输出级（Fig. 5.20）

- **$Q_{14}$（npn）和 $Q_{20}$（pnp）**：互补 Class AB 输出管。
- **$Q_{18}, Q_{19}$**：偏置二极管，消除交越失真。
- **$Q_{23}$**：横向 pnp 射随驱动级。
- **$Q_{13A}$（0.22 mA）**：$Q_{14}$ 的正向驱动电流源——其电流大小限制了最大正向输出电流（$I_{o\max}^+ = \beta_{F14} \times 0.22\text{mA}$）。
- **$Q_{17}$**：共射前级，饱和时限制负向输出摆幅。
- **短路保护**：$R_6 + Q_{15}$ 检测 $Q_{14}$ 电流，超过 ~20 mA 时分流驱动电流。

### 5. CMOS 共漏 Class AB（Fig. 5.31）

```
         VDD
          |
         M3 (电流源)
          |
         M4 (diode)  M1 (pMOS 输出)
          +----+------+
         M5 (diode)  M2 (nMOS 输出)
          |           +---- Vo
         M6           R_L
          |           |
         -VSS        GND
```

- 从 BJT 版 Class AB 直接迁移而来。
- 输出摆幅严重受限于 $V_{gs1}$（含阈值电压 + 过驱动），无法像 BJT 那样仅需一个 $V_{BE}$。
- 增大 $W/L$ 可降低过驱动、提升摆幅，但会引入大量寄生电容。

### 6. 共源 + 误差放大器准互补级（Fig. 5.32）

```
         VDD
          |
    误差放大器_A -- M1 (pMOS CS)
          |         |
    Vi ---+---------+---- Vo
          |         |
    误差放大器_A -- M2 (nMOS CS)    R_L
          |         |
         -VSS      GND
```

- 用共源管替代源跟随器输出管，每个共源管配一个误差放大器（单级，增益约 5~8）。
- 输出可摆到距电源轨一个 $V_{ov}$ 以内，远优于共漏结构。
- **问题**：误差放大器带宽受限 → 高频失真；增益受限 → 静态电流对失调敏感。

### 7. 组合共漏-共源输出级（Fig. 5.36 / 5.37 / 5.38）

> [!note] 核心思想
> 并联两条路径：低速共源路径负责大摆幅驱动，高速共漏路径控制静态电流并提供高频 feedforward 通路。

- **Fig. 5.36**：共漏 AB 级 + 共源 B 级并联，误差放大器内置故意失调使共源级在 $V_o=0$ 时截止。
- **Fig. 5.37**：额外添加 $M_7$-$M_8$ 支路，使 $V_1$ 节点摆幅突破 $M_4$/$M_5$ 阈值电压的限制。
- **Fig. 5.38**：两级误差放大器（$A_1$ 增益 ~8 控制静态电流，$A_2$ 增益 ~70 驱动大输出管），适用于 ISDN 线路驱动。

## 设计启示

1. **Class A 效率低（25%）但线性度最好**，适用于小功率精密应用，不适用于电池供电设备。
2. **Class B/AB 是功率放大器的主流选择**，效率可达 78.6%。Class AB 以微小的静态功耗代价消除了交越失真。
3. **负载线分析是输出级设计的核心工具**：最大瞬时功耗、最优负载、削波边界都从负载线几何得出。负载线中点始终是瞬时功耗最大点。
4. **驱动级往往才是输出摆幅的真正瓶颈**，不是输出管本身。设计时需核算驱动级的饱和和截止条件。
5. **BJT 在输出级中优于 MOS**：$V_{BE}$ 是对数关系、不含阈值分量，输出摆幅天然优于含 $V_t$ 的 MOS 跟随器。大功率场景更是必须用 BJT。
6. **CMOS 输出级需要额外技巧**：要么牺牲摆幅（共漏），要么引入误差放大器反馈（共源准互补），要么并联快速路径（feedforward 共漏+共源）。
7. **误差放大器增益的折中**：在 CMOS 准互补级中，误差放大器增益存在上限（由 offset 公差和允许的 $\Delta I_Q$ 决定），否则失配会导致静态电流失控。
8. **短路保护必须设计**：单靠器件本身的 $\beta_F$ 高频衰减和基极电阻限流通常不够，需要主动的电流检测和分流保护。
9. **BJT 热设计**：$V_{CE\max}$ 可达到 $2V_{CC}$，因此 $BV_{CEO} > 2V_{CC}$ 是保守设计的安全边界。$BV_{CEO}$ 是共射组态下的击穿电压，为最恶劣情况。
10. **准互补 pnp 的稳定性风险**：复合 pnp（lateral + 大功率 npn）构成的局部反馈环在有容性负载时可能不稳定（参见第九章）。
