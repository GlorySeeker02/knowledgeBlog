# Chapter 2: Bipolar, MOS, and BiCMOS Integrated-Circuit Technology

## 本章定位

本章是 Gray 教材的"工艺基础"章节。它从硅材料电学性质出发，系统介绍双极型、MOS 和 BiCMOS 三种主流工艺的基本制造步骤、器件结构、寄生参数提取方法，以及制造成本模型。本章是后续所有电路设计章节的"物理约束层"——理解器件从何而来、寄生从何而来、匹配能做到多好、成本如何随面积变化，是做出合理设计决策的前提。

> [!summary] 一句话总结
> 了解工艺不是为了进产线，而是为了知道电路中的晶体管、电阻、电容是怎么做出来的，寄生从哪来，版图怎么画才不踩坑。

## 核心概念

### 1. 硅的电阻率与掺杂

- **掺杂 (Doping)**：向本征硅中加入施主（n 型：P, As, Sb）或受主（p 型：B）杂质，控制多数载流子浓度。
- **质量作用定律**：平衡时 $np = n_i^2$，多数载流子浓度翻倍，少数载流子浓度减半。
- **电导率**：$\sigma = q(\mu_n n + \mu_p p)$，迁移率 $\mu$ 在掺杂浓度高时显著下降（Fig. 2.1）。
- **电阻率与掺杂浓度的关系**呈倒"U"形（Fig. 2.2），高掺杂 = 低电阻率 = 低电阻。

> [!info] 设计意义
> 精确知道扩散层的薄层电阻 $R_{\square}$（单位 $\Omega/\square$），就能计算集总电阻 $R = R_{\square} \times \frac{L}{W}$。一个方块的电阻和十个方块串联一样，但十个方块并联就变成 $R_{\square}/10$。

### 2. 六个基本工艺步骤

| 步骤 | 英文 | 关键参数 | 作用 |
|------|------|---------|------|
| 固态扩散 | Solid-State Diffusion | 1100°C, 1h | 高温下杂质原子从表面向体内迁移，形成 pn 结 |
| 光刻 | Photolithography | 最小尺寸 0.1 um | 用光掩模+光刻胶定义扩散/刻蚀区域，批量制造的关键 |
| 外延生长 | Epitaxial Growth | 1-20 um 厚 | 在硅表面生长单晶硅，杂质浓度可独立控制 |
| 离子注入 | Ion Implantation | 深度 < 0.1-0.6 um + 退火 | 精确控制掺杂剂量和深度，可做埋层峰值 |
| 局部氧化 | Local Oxidation (LOCOS) | SiN 掩蔽 | 形成厚/薄氧化层分界，实现器件隔离且表面平坦 |
| 多晶硅沉积 | Polysilicon Deposition | $R_{\square}$ 20 $\Omega/\square$ 起 | 做 MOS 栅极、双极型发射极、电容极板、电阻、熔丝 |

### 3. 薄层电阻与电阻计算

- 均匀薄膜：$R = \frac{\rho}{T} \cdot \frac{L}{W} = R_{\square} \cdot \frac{L}{W}$
- 扩散层（非均匀掺杂）：$R_{\square} = \frac{1}{q \bar{\mu}_n \int_0^{x_j} N_D(x) dx}$，实际由工艺监控测试确定。
- 方块法：一个 $L=W$ 的正方形就是一个"方块"，串联逐块加总电阻。

## 关键工艺

### 一、双极型 (Bipolar) 工艺

#### 高压结隔离工艺 (High-Voltage Junction-Isolated)

这是经典的双极型 IC 制造流程（6-8 次掩模+扩散）：

```
p 型衬底 -> 掩埋层扩散 (n+, As/Sb, 20-50 Ω/□)
-> 外延生长 (n 型, 5 Ω·cm, 17 um)
-> 隔离扩散 (p+ 穿透到衬底, 1200°C)
-> 基区扩散 (p 型 B, 100-300 Ω/□, 1-3 um 深)
-> 发射区扩散 (n+, 2-10 Ω/□, 0.5-2.5 um 深)
-> 接触孔 + 铝金属化 (1 um Al)
-> 测试 -> 划片 -> 封装
```

典型掺杂剖面见 Fig. 2.17，展示了发射区-基区-埋层-外延-衬底的五层结构。

#### 高压 npn 晶体管参数示例 (500 um² 发射极面积, 5 Ω·cm / 17 um 外延)

| 参数 | 典型值 | 参数 | 典型值 |
|------|--------|------|--------|
| $\beta_F$ | 200 | $r_b$ | 200 Ω |
| $V_A$ | 130 V | $r_c$ (饱和) | 200 Ω |
| $BV_{CEO}$ | 50 V | $\tau_F$ | 0.35 ns |
| $C_{je0}$ | 1 pF | $C_{\mu 0}$ | 0.3 pF |
| $C_{cs0}$ | 3 pF | $I_S$ | $5 \times 10^{-15}$ A |

**集电极电阻 $r_c$ 的三分量模型**（Fig. 2.28）：

- $r_{c1}$：发射极下方到埋层的垂直路径（由非均匀截面模型公式 2.18 估算）
- $r_{c2}$：埋层从发射极下到集电极触点下方的横向路径（$R_{\square} \times$ 方块数）
- $r_{c3}$：埋层到集电极触点上方的垂直路径
- **饱和区**：电导调制效应使 $r_c$ 更低（约等于 $r_{c2} + r_{c3}$）

#### 先进氧化物隔离工艺 (Advanced Oxide-Isolated)

主要改进：

- 1 um 薄外延层 + **氧化物隔离 (moat)** 替代结隔离 -> 极小寄生电容 + 密集布局
- **多晶硅发射极** (Poly-emitter)：n+ 多晶作为掺杂源向外扩散形成极薄发射区 (0.1 um)
- **自对准结构**：基区 p+ 注入被多晶硅发射极自动遮蔽，不需额外对准
- 金属硅化物覆盖所有硅/多晶区域 -> 减小串联电阻
- $f_T > 10$ GHz（对比典型高压工艺 500 MHz）

| 先进器件参数 (2 um² 发射极) | npn | Lateral pnp |
|---|---|---|
| $\beta_F$ | 120 | 50 |
| $\tau_F$ | 10 ps | 650 ps |
| $BV_{CEO}$ | 8 V | 14 V |
| $C_{je0}$ | 5 fF | 14 fF |
| $C_{\mu 0}$ | 5 fF | 15 fF |

#### 横向 pnp (Lateral pnp)

- 发射极和集电极用 npn 基区扩散形成，载流子横向流过外延基区。
- **致命限制**：基区（外延层）掺杂极低 -> 基区宽度必须达 8 um 以防止穿通 -> $\tau_F \approx 30$ ns, $f_T$ 仅 ~5 MHz。
- 集电极电流超过几十 uA 即进入大注入，$\beta$ 崩溃（基区多数载流子需增多以维持电中性）。
- 电流增益典型 30-50，>100 uA 即跌落至 < 10。
- 氧化物隔离版本性能大幅改善：$\tau_F = 650$ ps, $C_{je0} = 14$ fF。

#### 衬底 pnp (Substrate pnp)

- 电流垂直流动，发射极有效面积大（5100 um² 典型）。
- **限制**：集电极 = p 型衬底 -> 只能接最负电位，仅用于射随器。
- 集电极电流在衬底中流动 -> 需大面积隔离扩散接触防止衬底压降误偏置。
- 典型 $\beta_F = 50$，$\tau_F = 20$ ns，$r_b = 150$ Ω。

#### 工艺改造

- **介质隔离 (Dielectric Isolation)**：用 SiO2 而非 pn 结隔离，极低寄生电容 + 抗辐射。
- **超 Beta 晶体管**：极窄基区使 $\beta$ 达 2000-5000，但 $BV_{CEO}$ 仅约 1 V（穿通限制）。
- **双扩散 pnp**：加 3 次掩模 + 2 次外延 -> pnp 性能可比 npn。
- **薄层电阻器** (薄膜电阻) ：NiCr、Ta 或 Cermet (Cr-SiO)，零结电容 + 低温度系数。

#### 无源器件 (Bipolar)

| 电阻类型 | $R_{\square}$ (Ω/□) | 绝对容差 | 温度系数 (ppm/°C) |
|----------|---------------------|---------|-------------------|
| 基区扩散 | 100-200 | ±20% | +1500 ~ +2000 |
| 发射区扩散 | 2-10 | ±20% | +600 |
| 离子注入 | 100-1000 | ±3% | 可控至 ±100 |
| 基区夹断 (Pinch) | 2k-10k | ±50% | +2500 |
| 外延 | 2k-5k | ±30% | +3000 |
| 外延夹断 | 4k-10k | ±50% | +3000 |
| 薄膜 | 0.1k-2k | ±5~20% | ±10 ~ ±200 |

- **MOS 电容**：Al - 薄 SiO2 - n+ 发射区，电容密度 0.3-0.5 fF/um²，击穿电压 60-100 V，极高线性度。底板到衬底的寄生电容 $C_{ISO}$ 不可忽略。
- **齐纳二极管**：发射极-基极结反向击穿（6-8 V），击穿温度系数在 ~5 V 附近过零（隧穿 vs. 雪崩两种机制竞争）。

### 二、MOS (CMOS) 工艺

#### n 阱硅栅 CMOS 流程

```
p 型衬底 -> n 阱注入 (P) 和推进扩散
-> SiN 沉积 + 场区注入 + LOCOS 场氧化
-> 沟道阈值调整注入 (有选择性的掩蔽注入)
-> 多晶硅栅沉积 + 定义
-> n+ 源漏 (As/P) + p+ 源漏 (B) 分别注入/扩散
-> CVD 沉积氧化层 -> 接触孔 -> 金属化
```

#### 跨工艺节点的参数演进

| 工艺节点 ($L_{min}$) | $t_{ox}$ | $V_{t}$ (n/p) | $\mu_n / \mu_p$ (cm²/V·s) | $C_{j0}$ (n/p, fF/um²) |
|---|---|---|---|---|
| 3 um | 400 A | 0.7 / -0.7 | 700 / 350 | 0.08 / 0.20 |
| 0.8 um | 150 A | 0.7 / -0.7 | 550 / 250 | 0.18 / 0.30 |
| 0.4 um | 80 A | 0.6 / -0.8 | 450 / 150 | 0.2 / 0.4 |
| 0.1 um | 25 A | 0.27 / -0.28 | 390 / 100 | 1.0 / 1.1 |

> [!warning] 深亚微米变迁
> - $t_{ox} < 30$ A 时出现**栅极漏电流**（载流子隧穿），需在模型中纳入 $I_G$。
> - **鸟嘴效应**：场氧化时横向氧化侵蚀沟道宽度，使有效宽度小于版图宽度。
> - 短沟道下输出电压**不再**简单地按平方律缩放——SPICE 用 BSIM 等高级模型。

#### 阈值电压构成

$$
V_t = \phi_{ms} + 2\phi_f + \frac{Q_b}{C_{ox}} + \frac{Q_{ss}}{C_{ox}}
$$

- $\phi_{ms}$：金属-硅功函数差（n 沟约 -0.6 V）
- $2\phi_f$：表面强反型所需能带弯曲（~0.54 V）
- $Q_b/C_{ox}$：沟道耗尽层电荷（与掺杂浓度的平方根成正比）
- $Q_{ss}/C_{ox}$：表面态电荷（~$10^{11} q$/cm²）
- **沟道注入的作用**：在表面形成盒状掺杂分布，精确调整 $V_t$。浅注入影响等价于增加 $Q_{ss}$；深注入等价于提高有效衬底掺杂。

#### 有效沟道长度

$$
L_{\text{eff}} = L_{\text{drwn}} - 2L_d - X_d
$$

其中 $L_d$ 为源漏侧向扩散，$X_d$ 为漏端耗尽区宽度。未注入器件的 $X_d$ 远大于注入器件（衬底掺杂低 -> 耗尽区宽），因此未注入器件需要更长的版图沟道长度来维持相同的 $r_o$。

#### CMOS 中的双极晶体管

- **纵向 pnp**：n 阱 = 基区, p+ 源漏 = 发射极, p 衬底 = 集电极（接最低电位）。
- **横向 pnp**：n 阱 = 基区, 两个 p+ 扩散分别做发射极和集电极，基区宽度 = 沟道长度。**关键问题**：同时存在寄生的纵向 pnp 分流集电极电流，$I_{C2}/I_{C1}$ 不可控。需要用负反馈调整发射极电流来稳定所需集电极电流。
- 随沟道长度持续缩小，横向双极的 $\beta$ 和 $f_T$ 不断提高。

#### Latchup (闩锁效应)

CMOS 结构天然构成 pnpn 四层 SCR。若寄生双极的 $\beta_{npn} \times \beta_{pnp} > 1$ 且任一结正偏 -> 正反馈开启 -> VDD 到 GND 大电流 -> 烧毁。

**防护手段**：
- 增加衬底和阱接触密度（降低 $R_1$, $R_2$）
- 拉大 n 沟源到 n 阱的距离（降低横向 npn 的 $\beta$）
- 使用 guard ring（源漏扩散形成的低阻保护环）

### 三、BiCMOS 工艺

在低压 (5 V)、薄外延 (1 um / 0.5 Ω·cm) 条件下，双极和 CMOS 工艺高度兼容：

```
n+ 埋层 (Sb, 双极 + PMOS 区域) + p 阱 (B, NMOS 区域)
-> 1 um n- 外延
-> 场区刻蚀 + 场氧化 + 平坦化
-> 双极基区/发射极 + MOS 源漏依次注入
-> 栅氧生长 + 多晶硅栅 + 发射极
-> 多层金属互连 (Al/Cu)
```

优点：利用双极高电流驱动能力驱动大容性负载；同时享用 CMOS 高密度和低功耗。

### 四、SiGe 异质结双极晶体管 (HBT)

**核心思想**：在基区掺入锗（SiGe），利用 Si (发射极) 和 SiGe (基区) 的禁带宽度差（异质结），在不牺牲发射极注入效率的前提下提高基区掺杂浓度。

**收益三角**：

$$
\text{高基区掺杂 } N_A \uparrow \rightarrow \begin{cases}
r_b \downarrow &\text{(可减薄基区宽度)} \\
V_A \uparrow &\text{(基区宽度调制减弱)} \\
C_{je} \downarrow &\text{(发射极掺杂可降低)}
\end{cases}
$$

- Ge 浓度通常约 15%（应变 SiGe 稳定上限，由晶格失配决定）
- 渐变 Ge 成分可产生加速载流子的内建电场 -> 进一步提高 $f_T$
- 0.3 um CMOS + SiGe HBT：$f_T$ 达 50 GHz，约为同节点同质结双极的 2 倍

### 五、互连延迟与新材料

随尺寸缩小，互连延迟逐渐成为速度瓶颈（$RC$ 乘积增大）：

- **Cu 替代 Al**：电阻率降约 40%，更抗电迁移和应力迁移。需使用**大马士革工艺**（先刻氧化层槽再填充 Cu + CMP 平坦化）+ 扩散阻挡层包裹（Cu 在 Si/SiO2 中扩散极快）。
- **低 k 介质替代 SiO2**：聚合物（k ~ 2.5-3.0）、泡沫/凝胶（k < 2.0），挑战在于热导率、击穿电压、高温稳定性、附着力。SiO2 的 $k=3.9$ 是全面优秀的基准。

## 器件制造流程

### 双极 npn 晶体管制作（高压工艺）

```
p型衬底
  |-> 掩埋层扩散 (n+ As/Sb 注入)
  |-> n型外延生长 (5Ω·cm, 17um)
  |-> 隔离扩散 (p+ B 穿透至衬底)
  |-> 基区扩散 (p型 B, 100-300 Ω/□)
  |-> 发射区扩散 (n+ P, 2-10 Ω/□)
  |-> 接触孔 + Al 金属化
  |-> 测试 -> 划片 -> 封装
```

### CMOS 反相器制作

```
p型衬底 -> n阱注入
  |-> SiN沉积 + 场注入 + LOCOS 场氧化
  |-> Vt 调整注入
  |-> 多晶硅栅沉积与定义
  |-> n+ S/D 注入 (n沟)
  |-> p+ S/D 注入 (p沟)
  |-> CVD氧化层 + 接触孔 + 金属化
```

## 设计启示

> [!important] 工艺知识对电路设计的具体指导

| 工艺事实 | 设计启示 |
|----------|---------|
| 扩散电阻 $R = R_{\square} \times L/W$ | 用方块法快速心算电阻值 |
| 低压 -> 薄外延 -> 小尺寸 -> 高频 | 低压工艺的 $C_\mu$, $C_{cs}$ 小很多但 $BV_{CEO}$ 有限 |
| 横向 pnp 的 $\beta$ 在 >10 uA 崩溃 | 不可用横向 pnp 做大电流驱动 |
| 衬底 pnp 集电极 = 最低电位 | 仅用作射随器 |
| p 沟迁移率约为 n 沟的 1/2~1/3 | n 沟做输入级，p 沟做负载时需加倍宽度 |
| n 沟无注入时 $V_t \approx 0$ V | 必须有沟道注入来设正阈值 |
| 集电极电阻 $r_c$ 在饱和时变小 | 开关应用中 $r_{c(sat)}$ 约等于 $r_{c2}+r_{c3}$ |
| $C_{je}$ 侧墙面积不可忽略 | 用圆柱近似 $A_{\text{sidewall}} = P \times d \times \pi/2$ |
| 结电容全是电压依赖的 | 用 $(1 + V_R/\psi_0)^{-n}$ 公式做偏置修正 |
| 氧化物隔离消除了结隔离寄生 | 接触孔可叠到 moat 上，大幅缩小面积 |
| 栅氧 < 30 A -> 栅极漏电不可忽略 | 超深亚微米设计中需评估 $I_G$ 对偏置的影响 |
| MOS 电容的底板寄生约为主电容的 10-30% | 关键开关电容电路中底板必须接到低阻节点 |
| 多晶硅电阻 $R_{\square}$ 20-80 Ω/□ | 适合做中等阻值，匹配 ≈ 扩散电阻 |
| 阱电阻 $R_{\square} \approx 10$ kΩ/□ | 极高阻值但温度/电压系数大 |
| Latchup 由 $\beta_{npn} \times \beta_{pnp} > 1$ 触发 | layout 必须加 guard ring + 密集衬底/阱接触 |
| 制造成本 = 晶圆成本 + 封装测试成本 | 大片数 -> 管芯成本主导；小片数 -> 封装测试成本主导 |
| pnpn SCR 正反馈: $\beta_{npn} \times \beta_{pnp} > 1$ | 浅阱 + 高阻衬底 = 高风险，layout 须加 guard ring |
| 工艺缩放 -> 互连 RC 增 | 先进节点中互连延迟可能超过门延迟 |
| 多晶硅上 silicide 可降 $R_{\square}$ 一个量级 | 低阻多晶互连/电阻需确认工艺是否含 silicide block 选项 |

## 章节关联

- **Chapter 1 - Models for Integrated-Circuit Active Devices**：第 1 章定义了本章所有器件参数（$I_S$, $\beta$, $C_\mu$, $g_m$, $r_o$ 等）的物理来源；本章给出了这些参数如何在工艺中被设定。读本章时需频繁回看 Ch01 的模型公式。尤其是：$I_S$ 与 $Q_B$（Gummel 数）的关系、$C_\mu$ 与 epi 掺杂浓度的关系、$f_T$ 与基区渡越时间 $\tau_F$ 的关系、$V_t$ 公式四项的物理来源。
- **Chapter 3 - Single-Transistor and Multiple-Transistor Amplifier**：第 3 章中放大器的性能（增益、带宽）直接受 $g_m$, $r_o$, $C_\mu$, $C_{gs}$ 等参数限制，而这些参数的物理来源由本章工艺确定——选什么工艺决定放大器的可实现性能边界。
- **工艺选择决策树**：
  - 需要高电压 (> 20V) -> 高压双极
  - 需要 GHz 级射频 -> SiGe BiCMOS 或先进氧化物隔离双极
  - 混合信号 + 高密度数字 -> CMOS 或 BiCMOS
  - 超大驱动电流 (> 100 mA) -> 双极输出级
