# 第 5 章 同步数字电路中的抖动（Effects of Jitter in Synchronous Digital Circuits）

> [!abstract] 章节概览
> 本章分析时钟抖动（jitter）对同步数字系统时序约束的影响。核心思路是：把经典静态时序分析（STA）中的建立时间（setup time）与保持时间（hold time）约束，扩展到时钟边沿带有随机抖动的情形，看抖动如何"吃掉"时序裕量（timing margin）。
>
> 工程意义：现代 SoC 的最高工作频率往往由关键路径的建立时间裕量决定。抖动使时钟周期变短的概率永远不为零，因此抖动直接限制了系统能跑多快、能以多低的失效率运行。本章还覆盖实际设计中常见的门控时钟、分频时钟、使能系统、多周期路径，以及高速全定制设计中的锁存器（latch）时序。

## 5.1 边沿触发同步设计（Edge-Triggered Synchronous Design）

### 寄存器的时序参数

边沿触发同步设计的核心元件是寄存器（register，即触发器 flip-flop）。理想寄存器在时钟 CK 上升沿把输入 X 瞬间传到输出 Y；实际寄存器有三个非理想时序参数：

| 参数 | 符号 | 含义 |
| --- | --- | --- |
| 建立时间 | $\tau_{su}$ | 时钟上升沿**之前**，输入数据必须保持稳定的最短时间 |
| 保持时间 | $\tau_{ho}$ | 时钟上升沿**之后**，输入数据不允许变化的最短时间 |
| 时钟到输出延迟 | $\tau_{cq}$ | 时钟上升沿之后，新数据出现在输出所需时间（clock-to-Q） |

### 基本时序约束（无抖动、无 skew）

典型结构：寄存器 1 用 CK 采样 X1 → 输出 Y1 → 经组合逻辑（延迟 $\tau_L$）→ X2 → 寄存器 2 用同一个 CK 采样。

**建立时间约束**：最坏情况发生在组合逻辑延迟最大（$\tau_{Lmax}$）时。数据经 $\tau_{cq} + \tau_{Lmax}$ 才到达第二级，且必须在下一个时钟沿前 $\tau_{su}$ 稳定，因此：

$$T > \tau_{cq} + \tau_{Lmax} + \tau_{su} \tag{5.1}$$

> [!important] 式 (5.1) 给出了时钟周期 $T$ 的下限，即系统最高工作频率的上限。这是同步设计最根本的速度约束。

**保持时间约束**：第二级寄存器要求输入在时钟沿之后 $\tau_{ho}$ 内不变。X2 最早在时钟沿后 $\tau_{cq} + \tau_{Lmin}$ 变化（$\tau_{Lmin}$ 为组合逻辑最小延迟），故：

$$\tau_{cq} + \tau_{Lmin} > \tau_{ho} \tag{5.2}$$

> [!note] 保持时间约束**与时钟频率无关**，只约束组合逻辑的最小延迟。原因：建立时间涉及两个相邻时钟沿（周期长则裕量大），而保持时间只涉及同一个时钟沿。

### 时钟偏斜（Clock Skew）的影响

实际芯片中，时钟通过庞大的时钟树（clock tree）分配到各寄存器，到达时间存在残余差异。设到达寄存器 1、2 的延迟差为 skew $\tau_{sk} = \tau_{d2} - \tau_{d1}$，则约束变为：

$$T > \tau_{cq} + \tau_{Lmax} + \tau_{su} - \tau_{sk} \tag{5.3}$$

$$\tau_{Lmin} > \tau_{ho} - \tau_{cq} + \tau_{sk} \tag{5.4}$$

设计直觉：若第二级时钟到得**更晚**（$\tau_{sk} > 0$），建立时间裕量变大，但保持时间更容易违反——skew 对两者的作用方向相反。

### 抖动对时序约束的影响

假设时钟分配网络本身不引入额外抖动，只考虑 CK 上的抖动。

**建立时间**：涉及两个相邻时钟沿，相关量是**周期抖动**（period jitter）$p$，即实际周期与标称周期 $T_{nom}$ 的偏差。把式 (5.3) 中的 $T$ 换成 $T_{nom} + p$：

$$p > \tau_{cq} + \tau_{Lmax} + \tau_{su} - \tau_{sk} - T_{nom} \tag{5.5}$$

在健康的设计中右端为负数（即标称周期留有裕量），该式约束的是**负峰值周期抖动** $\rho_p^-$：

$$\rho_p^- < T_{nom} + \tau_{sk} - \left(\tau_{cq} + \tau_{Lmax} + \tau_{su}\right) \tag{5.6}$$

> [!important] 设计直觉
> 式 (5.6) 右端正是该路径的**标称时序裕量**（slack）。含义直白：时钟周期"意外缩短"的最大幅度必须小于既有裕量，否则建立时间被违反。抖动预算直接计入时序预算。

**保持时间**：两个寄存器由**同一个**时钟沿释放/采样数据，时钟沿上的抖动对两者是共模的，从时序预算中完全抵消。因此：

> [!note] 保持时间对时钟抖动**不施加任何约束**（前提是时钟分配网络不引入附加抖动）。这与保持时间与时钟频率无关的结论一脉相承。

### 亚稳态与 MTBF

随机抖动服从高斯分布、无界，因此式 (5.6) 无法以 100% 概率满足——无论裕量多大，建立时间被违反的概率永远不为零。违反时寄存器进入**亚稳态**（metastable state）：内部电路增益不足，输出可能错误，或虽采对数据但需极长时间才达到有效电平，污染后级逻辑。

对单个数据与时钟异步的寄存器，平均无故障时间（Mean Time Between Failures）为：

$$\mathrm{MTBF} = \frac{e^{t_r / \tau_{BW}}}{f_D\, f_{CK}\, T_w} \tag{5.7}$$

符号含义：

- $f_D$：输入数据翻转频率；$f_{CK}$：时钟频率（两者越高，"冒险"机会越多）
- $T_w$：亚稳态窗口（metastability window），由寄存器实现决定
- $\tau_{BW}$：寄存器增益带宽积的倒数
- $t_r$：分辨时间（resolution time），系统允许输出达到有效电平的时间

> [!note] MTBF 随分辨时间 $t_r$ **指数**增长——这是同步器（synchronizer）用两级触发器串联的根本原因：多等一拍，失效率指数下降。系统能容忍多高的失效率，取决于寄存器数量、有无纠错机制、各子系统对同步错误的敏感度。

## 5.2 门控时钟、分频时钟与使能系统（Gated Clock, Divided Clock, Enabled Systems）

实际设计中并非所有寄存器都按时钟全速运行，三种常见方案：

- **分频时钟（divided clock）**：部分逻辑用主时钟的 N 分频版本驱动；
- **门控时钟（gated clock）**：只在需要采样数据时放行时钟沿（省功耗）；
- **使能信号（enable）**：时钟照常打拍，但寄存器仅每 N 拍使能一次。

三者效果相同：**寄存器每 N 个输入时钟周期才有效采样一次**。

### 抖动约束分析

- **保持时间**：与 5.1 同理，对分频/门控时钟及原时钟 CK 的抖动均不产生约束。
- **建立时间**：对分频/门控系统，约束落在分频/门控时钟的峰值周期抖动上；对使能系统，约束落在 CK 某边沿相对其**第 N 个前序边沿**的位移上。统一起来，都是对原时钟 CK 的**峰值 N 周期抖动**（N-period jitter）的约束：

$$\rho_{p(N)}^- < N\,T_{nom} + \tau_{sk} - \left(\tau_{cq} + \tau_{Lmax} + \tau_{su}\right) \tag{5.8}$$

### 为什么 N 周期抖动更苛刻

由第 3 章结论：对自由振荡器或带宽足够低的 PLL 产生的时钟，N 周期抖动约为周期抖动的 $\sqrt{N}$ 倍（相位随机游走按方差累积）。代入式 (5.8)：

$$\rho_p^- < \frac{N\,T_{nom} + \tau_{sk} - \left(\tau_{cq} + \tau_{Lmax} + \tau_{su}\right)}{\sqrt{N}} \tag{5.9}$$

> [!important] 设计直觉
> 若分频域内的逻辑同样被"塞满"（分子上的裕量与全速域同量级），则对原时钟周期抖动的要求比不分频系统**严格 $\sqrt{N}$ 倍**。换句话说：分频时钟域虽然周期长了 N 倍，但抖动也随之放大约 $\sqrt{N}$ 倍，净收益没有想象中大。这是高速芯片中低频域时序反而难收敛的常见原因。

## 5.3 多周期路径（Multicycle Paths）

复杂设计中某些组合逻辑一个周期算不完。若功能上允许 N 个周期出结果，可不改架构，把它声明为**多周期路径**：数据应在第 (N−1) 与第 N 个时钟沿之间稳定。

> [!note] 与分频/门控时钟的关键区别：多周期路径中第二级寄存器**每个时钟沿都在采样**（始终使能）。这导致保持时间也会约束抖动——这是分频系统没有的现象。

**建立时间**：数据须在第 N 个时钟沿前 $\tau_{su}$ 稳定，与分频系统完全相同，式 (5.8) 的 N 周期抖动约束直接适用。

**保持时间**：数据不得在第 (N−1) 个时钟沿后 $\tau_{ho}$ 之内到达，否则输出会**提前一拍**出现在 Y2。这给出**正峰值 (N−1) 周期抖动**的上限：

$$\rho_{p(N-1)}^+ < \tau_{cq} + \tau_{Lmin} - \tau_{ho} - \left[(N-1)T_{nom} + \tau_{sk}\right] \tag{5.10}$$

> [!example] 直觉理解
> 多周期路径中，"释放数据"的沿与"意外捕获"的沿相隔 (N−1) 个周期。若时钟抖动使这 (N−1) 个周期整体**变长**（正抖动），而新数据又来得特别快（$\tau_{cq} + \tau_{Lmin}$ 小），数据就可能在第 (N−1) 沿的保持窗口内变化。由于 $N \geq 2$ 时右端通常为很大的负数，此约束一般很宽松，但 $N=2$ 且 skew 不利时需要检查。

## 5.4 基于锁存器的同步设计（Latch-Based Synchronous Design）

**锁存器**（latch）是电平敏感元件：CK 高电平时输出跟随输入（**透明**，transparent）；CK 变低后输出保持最后值（隔离输入输出）。

> [!note] 锁存器在自动 RTL 流程中易引入难以排查的竞态（race），不推荐使用；但在全定制高速设计中，锁存器允许"时间借用"（time borrowing），可显著提高系统最高速度，故高速 SerDes、CPU 数据通路常用。

四个时序参数：$\tau_{su}$、$\tau_{ho}$（均相对 CK **下降沿**定义，与寄存器相反）、$\tau_{cq}$（进入透明时输出跟随的延迟）、$\tau_{dq}$（透明期间输入变化到输出变化的 data-to-Q 延迟）。

### 锁存器链的时序结构

典型结构：锁存器 1（CK 高电平透明）→ 组合逻辑 1 → 锁存器 2（反相时钟，CK 低电平透明）→ 组合逻辑 2 → 锁存器 3（同锁存器 1）。本质上就是把主从触发器的 master/slave 两级之间插入组合逻辑。

### 建立时间约束与半周期抖动

以第一个下降沿为时间零点，设数据 X1 在下降沿前 $\tau_{su}$ 已稳定（锁存器 1 无问题），则 Y1 经 $\tau_{dq}$ 更新，再经组合逻辑最坏延迟 $\tau_{Lmax1}$ 到达 X2。锁存器 2 要求数据在下一个**上升沿**（即低电平相位结束）前 $\tau_{su}$ 稳定：

$$\left(0 - \tau_{su}\right) + \tau_{dq} + \tau_{Lmax1} < T_{low} - \tau_{su} \tag{5.11}$$

其中 $T_{low}$ 为 CK 低电平相位时长。

> [!important] 与边沿触发设计的两大差异
> 1. **$\tau_{su}$ 在等式两边同号相消**，从时序预算中消失——锁存器对建立时间天然更宽容；
> 2. 约束敏感于**低电平相位时长**，即敏感于时钟**占空比**（duty cycle）$\delta$。

把低电平相位写成 $T_{low} = (1-\delta)T_{nom} + p_{(1/2)}$（$p_{(1/2)}$ 为半周期抖动，(1/2)-period jitter），得负峰值半周期抖动约束：

$$\rho_{p(1/2)}^- < (1-\delta)\,T_{nom} - \left(\tau_{dq} + \tau_{Lmax1}\right) \tag{5.12}$$

对锁存器 2 → 锁存器 3 的路径同理，只是改用 CK **高**电平相位：

$$\rho_{p(1/2)}^- < \delta\,T_{nom} - \left(\tau_{dq} + \tau_{Lmax2}\right) \tag{5.13}$$

> [!note] 设计要点
> 两式哪一个更紧，取决于占空比失真（$\delta - 0.5$ 的符号）与两段组合逻辑延迟的差异。这解释了高速锁存器设计为何对**时钟占空比**如此敏感：占空比偏离 50% 直接压缩半周期裕量；同时要求时钟的半周期抖动（而不仅是整周期抖动）受控。

**保持时间**：锁存器 2 的保持窗口由 CK 下降沿界定，而释放数据的正是锁存器 1 的同一个上升沿——抖动共模抵消，与边沿触发逻辑相同，式 (5.4) 继续成立。

## 关键公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| 建立时间约束（理想） | $T > \tau_{cq} + \tau_{Lmax} + \tau_{su}$ | 决定最高时钟频率 |
| 保持时间约束（理想） | $\tau_{cq} + \tau_{Lmin} > \tau_{ho}$ | 与频率无关，约束最小逻辑延迟 |
| 含 skew 的建立约束 | $T > \tau_{cq} + \tau_{Lmax} + \tau_{su} - \tau_{sk}$ | 正 skew 利于建立、恶化保持 |
| 含 skew 的保持约束 | $\tau_{Lmin} > \tau_{ho} - \tau_{cq} + \tau_{sk}$ | |
| 峰值周期抖动约束 | $\rho_p^- < T_{nom} + \tau_{sk} - (\tau_{cq} + \tau_{Lmax} + \tau_{su})$ | 负周期抖动不得超过时序裕量 |
| MTBF | $\mathrm{MTBF} = \dfrac{e^{t_r/\tau_{BW}}}{f_D f_{CK} T_w}$ | 随分辨时间指数改善 |
| N 周期抖动约束 | $\rho_{p(N)}^- < N T_{nom} + \tau_{sk} - (\tau_{cq} + \tau_{Lmax} + \tau_{su})$ | 分频/门控/使能/多周期建立时间 |
| 折算到周期抖动 | $\rho_p^- < \dfrac{N T_{nom} + \tau_{sk} - (\cdots)}{\sqrt{N}}$ | $\rho_{p(N)} \approx \sqrt{N}\,\rho_p$（低带宽 PLL/自由振荡器） |
| 多周期保持约束 | $\rho_{p(N-1)}^+ < \tau_{cq} + \tau_{Lmin} - \tau_{ho} - [(N-1)T_{nom} + \tau_{sk}]$ | 防止数据提前一拍被采 |
| 锁存器半周期抖动约束 | $\rho_{p(1/2)}^- < (1-\delta)T_{nom} - (\tau_{dq} + \tau_{Lmax1})$ | 另一路径用 $\delta T_{nom}$ 与 $\tau_{Lmax2}$ |

## 要点总结

- 建立时间约束涉及时钟的**两个相邻沿**，因此对周期抖动敏感；保持时间只涉及**同一个沿**，抖动共模抵消，不约束时钟抖动。
- 时序裕量（slack）与抖动预算可直接互换：负峰值周期抖动必须小于路径的标称裕量。
- 高斯随机抖动无界，建立时间违反概率永不为零，表现为亚稳态；MTBF 随分辨时间指数增长，两级同步器是标准对策。
- 分频/门控/使能系统把约束转移到 **N 周期抖动**；因其约为周期抖动的 $\sqrt{N}$ 倍，对原时钟的抖动要求加严 $\sqrt{N}$ 倍。
- 多周期路径的第二级寄存器每拍都采样，故除 N 周期抖动（建立）外，还有 (N−1) 周期正峰值抖动约束（保持），防止数据提前一拍到达。
- 锁存器设计中 $\tau_{su}$ 从建立时间预算中抵消，时序对**占空比**和**半周期抖动**敏感；保持时间与寄存器逻辑相同，抖动抵消。
- 低带宽 PLL/自由振荡器中相位做随机游走，是 $\rho_{p(N)} \approx \sqrt{N}\,\rho_p$ 的物理来源；高带宽 PLL 锁定参考时钟后此标度关系不再成立。
