# 第 10 章 数值方法与 Matlab 仿真（Numerical Methods，含附录 B）

> [!abstract] 章节概览
> 本章是全书的**仿真工具箱**。研究含抖动系统的常规路线是频域线性模型加相位噪声轮廓，但面对复杂或非线性系统时，往往需要做**时域瞬态仿真**。瞬态仿真要求两项数值能力：
> 1. **正向**：在时域生成具有指定相位噪声轮廓 $\mathcal{L}(f)$ 的时钟边沿序列；
> 2. **反向**：从瞬态仿真（或测量）得到的边沿时刻向量中提取各类抖动、重建相位噪声图，并通过**尾部拟合**（tail fitting）由有限样本外推极低误码率下的总抖动 TJ。
>
> 本章给出全部算法思路与公式，附录 B 给出对应的 Matlab 参考实现。所有代码刻意写得直白，便于移植到其他语言。数学基础（PSD、自相关、遍历性等）见 [附录 随机过程复习](附录 随机过程复习.md)。

## 10.1 生成指定相位噪声轮廓的抖动样本

### 通用框架

目标：生成数列 $t_k$，表示标称频率 $f_0$、相位噪声轮廓为 $\mathcal{L}(f)$ 的时钟边沿时刻。把 $t_k$ 分解为理想时钟加抖动过程：

$$t_k = t_{id,k} + a_k = \frac{k}{f_0} + a_k,\qquad k \geq 0$$

其中 $a_k$ 就是第 2 章定义的**绝对抖动**（absolute jitter）。问题归结为：生成具有指定 $\mathcal{L}(f)$ 的随机序列 $a_k$。

> [!important] PSD 与 PDF 相互独立
> 把 $a_k$ 的一次实现画出来：PSD 描述样本沿 **x 轴**（时间/序号方向）如何演化，PDF 描述样本沿 **y 轴**（幅度方向）如何分布。两者原则上互不约束：白过程（平坦 PSD）可以具有高斯、均匀、三角等任意 PDF；给定 PDF 的过程也可以呈现各种 PSD 形状。**高斯过程不一定白，白过程不一定高斯**。本章默认以高斯伪随机数发生器（零均值、单位方差）作为所有算法的起点。

全书第 3 章已建立抖动 PSD 与相位噪声的桥梁公式，此处重复使用：

$$S_a(f) = \frac{\mathcal{L}(f)}{\omega_0^2}, \qquad \omega_0 = 2\pi f_0 \tag{10.1}$$

> [!note] 算法总路线
> 除 1/f 类轮廓外，所有算法的骨架都是：**先生成平坦谱高斯序列，再用"数字滤波器或累加器"把它整形成目标谱形**；各分量方差由目标 $\mathcal{L}(f)$ 反解得到。

### 10.1.1 平坦相位噪声轮廓

目标 $\mathcal{L}(f) = \mathcal{L}_0$（常数），由式 (10.1) 知 $a_k$ 必须有平坦 PSD，即白噪声序列。离散时间白噪声定义在 $1/f_0$ 整数倍的时间栅格上，方差与 PSD 的关系为：

$$S_a(f) = \frac{\sigma_a^2}{f_0} \tag{10.2}$$

与式 (10.1) 联立（注意 $\omega_0 = 2\pi f_0$），解出所需标准差：

$$\sigma_a = \frac{1}{2\pi}\sqrt{\frac{\mathcal{L}_0}{f_0}} \tag{10.3}$$

**算法步骤**：
1. 把目标本底 $\mathcal{L}_0$ 从 dBc/Hz 换成线性值（$10^{\mathcal{L}_0|_{\mathrm{dB}}/10}$），按式 (10.3) 算 $\sigma_a$；
2. 生成 $n$ 个零均值单位方差高斯随机数，乘以 $\sigma_a$，得 $a_k$；
3. 叠加理想时钟：$t_k = k/f_0 + a_k$。

### 10.1.2 低通、高通或带通轮廓

实际中最常需要特定形状的轮廓（例如简单 PLL 频谱 = 带内平坦 + 3dB 拐点之后的滚降，属低通型）。思路极为直接：

> [!note] 白噪声 + 数字滤波器整形
> 先按 10.1.1 生成平坦轮廓抖动序列，再通过数字滤波器 $H(f)$ 整形。由随机过程通过线性系统的性质（$S_y = |H|^2 S_x$），结果相位噪声为：
> $$\mathcal{L}(f) = |H(f)|^2\,\mathcal{L}_0$$

**算法步骤**：
1. 生成平坦轮廓抖动序列（10.1.1）；
2. 设计数字滤波器（如目标为 PLL 低通谱，用一阶 Butterworth，归一化截止频率 $2f_{\mathrm{3dB}}/f_0$）；
3. 滤波输出即为目标抖动样本。高通、带通同理，只换滤波器设计。

### 10.1.3 1/f² 相位噪声轮廓

自由振荡器近载波处呈 $1/f^2$ 或 $1/f^3$ 特性。由于没有平坦区域，10.1.2 的方法不能直接用。由线性系统理论：**平坦谱通过理想积分器即得 $1/f^2$ 谱**。

**算法**：生成平坦谱高斯序列 $l_k$（方差 $\sigma_l^2$），送入累加器：

$$a_k = a_{k-1} + l_k$$

即 $a_k$ 是 $l_k$ 的**随机游走**（离散积分）。推导如下：$S_l(f) = \sigma_l^2/f_0$；累加器的传递函数为 $1/(1-e^{-j2\pi f/f_0})$，故

$$S_a(f) = \frac{S_l(f)}{\left|1-e^{-j2\pi f/f_0}\right|^2} \tag{10.4}$$

在关心区域 $f \ll f_0$，$\left|1-e^{-j2\pi f/f_0}\right|^2 \approx (2\pi f/f_0)^2$，代入式 (10.1)：

$$\mathcal{L}(f) = \left(\frac{f_0}{2\pi f}\right)^2 \frac{\sigma_l^2}{f_0}\,\omega_0^2 = \frac{f_0^3\,\sigma_l^2}{f^2} \tag{10.5}$$

与目标轮廓 $\mathcal{L}(f) = \mathcal{L}_1 f_1^2/f^2$（$\mathcal{L}_1$ 为偏移 $f_1$ 处的相位噪声）联立，解出：

$$\sigma_l = \frac{f_1}{f_0}\sqrt{\frac{\mathcal{L}_1}{f_0}} \tag{10.6}$$

**算法步骤**：
1. 按式 (10.6) 由 $(\mathcal{L}_1, f_1)$ 计算 $\sigma_l$；
2. 生成 $l_k = \sigma_l \times$ 单位高斯噪声；
3. 累积求和（`cumsum`）得 $a_k$；叠加理想时钟。

> [!warning] 随机游走是非平稳过程
> 累加序列的方差随 $k$ 线性增长，时钟相位会持续漂移——这正是自由振荡器**相位扩散**（phase diffusion）的物理本质，属预期行为而非算法缺陷。但它也意味着：序列越长绝对时间漂移越大，做抖动统计时应使用周期抖动等平稳化度量，或结合 10.2 的最小二乘去趋势。

### 10.1.4 1/f 与 1/f³ 相位噪声轮廓

$1/f$ 谱是闪烁噪声（flicker noise）的典型特征，无法由单一有理滤波器精确实现。采用 **Bernamont 模型**：让平坦谱序列通过**一组并联的一阶低通滤波器**，输出求和。

> [!note] 滤波器组的构造原理
> 关键尺度关系：若某个一阶低通的直流增益缩小 $\alpha$ 倍、同时拐点频率抬高 $\alpha^2$ 倍，则整条滤波器链的叠加传输函数近似 $1/f$。可以证明，**每十倍频程放置一个滤波器**（即 $\alpha = \sqrt{10}$）就足以得到相当精确的 $1/f$ 近似。这正是多种物理现象中 $1/f$ 噪声生成机制（大量不同时间常数的 Lorentzian 谱叠加）的数学翻版。

设目标频段为 $[f_{\min}, f_{\max}]$，滤波器拐点频率应至少覆盖同一区间；取 $f_{\max} = 10^N f_{\min}$，第 $n$ 个滤波器（$n = 0 \dots N$）为：

$$H_n(f) = \frac{10^{-n/2}}{1 + j\,f/(10^n f_{\min})} \tag{10.7}$$

即拐点频率每十倍频抬高 10 倍，增益每十倍频降低 $1/\sqrt{10}$。输出过程 PSD 为：

$$S_a(f) = \left|\sum_{n=0}^{N} H_n(f)\right|^2 S_l(f), \qquad S_l(f) = \frac{\sigma_l^2}{f_0} \tag{10.8}$$

**系数 $\gamma$ 的由来**：在第 $n_0$ 个滤波器的拐点 $f = 10^{n_0}f_{\min}$ 附近，主要贡献来自该滤波器本身及左右相邻两个：

$$\left|\sum_{n=0}^{N} H_n(10^{n_0}f_{\min})\right|^2 \approx \left|H_{n_0-1} + H_{n_0} + H_{n_0+1}\right|^2 = \frac{1}{10^{n_0}}\underbrace{\left|\frac{\sqrt{10}}{1+j10} + \frac{1}{1+j} + \frac{\sqrt{10}}{10+j}\right|^2}_{\gamma\;\approx\;1.426} \tag{10.9-10.10}$$

由于该值在每个拐点处都满足"与频率成反比"的标度，整条合成曲线满足：

$$\left|\sum_{n=0}^{N} H_n(f)\right|^2 = \gamma\,\frac{f_{\min}}{f} \tag{10.11}$$

代入式 (10.8) 与 (10.1)，得 $1/f$ 轮廓的相位噪声：

$$\mathcal{L}(f) = \frac{4\pi^2 f_0\,\sigma_l^2\,\gamma f_{\min}}{f} \tag{10.12}$$

与目标 $\mathcal{L}(f) = \mathcal{L}_1 f_1/f$ 联立，解出输入噪声方差：

$$\sigma_l^2 = \frac{\mathcal{L}_1 f_1}{4\pi^2\gamma f_{\min} f_0} \tag{10.13}$$

**1/f 算法步骤**：
1. 选定覆盖目标频段的 $f_{\min}, f_{\max}$，按式 (10.13) 计算 $\sigma_l$；
2. 生成平坦谱高斯序列 $l_k$；
3. 用每十倍频一个的一阶低通（如 Butterworth）分别滤波，第 $n$ 路输入幅度额外除以 $(\sqrt{10})^n$；
4. 各路输出求和得 $a_k$；叠加理想时钟。

**1/f³ 轮廓**：在已得到的 $1/f$ 序列基础上**再做一次累加积分**（同 10.1.3），PSD 增加因子 $[f_0/(2\pi f)]^2$，最终：

$$\mathcal{L}(f) = \frac{\sigma_l^2\,\gamma f_{\min} f_0^3}{f^3},\qquad \sigma_l^2 = \frac{\mathcal{L}_1 f_1^3}{\gamma f_{\min} f_0^3} \tag{10.14-10.15}$$

即目标为 $\mathcal{L}(f) = \mathcal{L}_1 f_1^3/f^3$ 时按上式设定 $\sigma_l$，流程为"滤波器组求和 → `cumsum`"。

### 10.1.5 复杂组合轮廓

> [!important] 独立过程之和，PSD 相加
> 用**互不相关**的随机数源分别生成上述各基本轮廓的抖动分量，直接相加，则总和的 PSD 等于各分量 PSD 之和。于是任意复杂的相位噪声形状都可以"分段搭建"。

典型示例（附录 B.1.6）：$1/f^3$ 区 + $1/f^2$ 区 + PLL 低通谱 + 平坦本底四路独立分量相加，得到从近载波到远端、贴近真实"PLL + 振荡器"系统的完整相位噪声轮廓。

**各轮廓算法对照表**：

| 目标轮廓 | 核心构造 | 关键参数式 |
| --- | --- | --- |
| 平坦 $\mathcal{L}_0$ | 高斯白噪声直接缩放 | $\sigma_a = \frac{1}{2\pi}\sqrt{\mathcal{L}_0/f_0}$ |
| 低通/高通/带通 | 白噪声 + 数字滤波器 $H(f)$ | $\mathcal{L}(f) = |H(f)|^2\mathcal{L}_0$ |
| $1/f^2$ | 白噪声累加（随机游走） | $\sigma_l = (f_1/f_0)\sqrt{\mathcal{L}_1/f_0}$ |
| $1/f$ | 白噪声通过每十倍频一个的一阶低通组求和 | $\sigma_l^2 = \mathcal{L}_1 f_1/(4\pi^2\gamma f_{\min}f_0)$，$\gamma\approx1.426$ |
| $1/f^3$ | $1/f$ 序列再累加一次 | $\sigma_l^2 = \mathcal{L}_1 f_1^3/(\gamma f_{\min}f_0^3)$ |
| 任意组合 | 各独立分量相加 | PSD 直接叠加 |

## 10.2 由时间时刻向量计算抖动

**问题**：给定抖动时钟上升沿时刻数组 $t_k$（$k = 0 \dots n-1$，来自瞬态仿真或测量），提取抖动信息。绝对抖动定义为实际边沿相对理想时钟边沿的位移：

$$a_k := t_k - kT - t_{OS} \tag{10.16}$$

其中 $T$ 为理想周期、$t_{OS}$ 为允许的时间偏移，二者皆未知，需要两个准则定解：

1. **抖动零均值**：$\sum_k a_k = 0$，给出
$$t_{OS} = \frac{1}{n}\sum_{k=0}^{n-1}(t_k - kT) \tag{10.18}$$
2. **抖动方差最小**：$\partial \sum_k a_k^2 / \partial T = 0$。由 $\partial a_k/\partial T = (n-1)/2 - k$ 化简得 $\sum_k k\,a_k = 0$，最终：

$$T = \frac{12}{n(n^2-1)}\sum_{k=0}^{n-1}\left(k - \frac{n-1}{2}\right)t_k \tag{10.22}$$

> [!important] 最小二乘周期 ≠ 平均周期
> 直觉猜测 $T$ 等于平均周期 $(t_{n-1}-t_0)/(n-1)$，仅对 $n = 2, 3$ 成立；$n > 3$ 时正确的 $T$ 依赖中间各点的具体分布，可能大于或小于平均周期。
>
> **书中例 18**：$t_0 = 0$，$t_4 = 4\,\mathrm{ns}$（平均周期恒为 1 ns）：
> - (a) $t_1,t_2,t_3 = 1, 2, 3$ ns → $T = 1$ ns（等间隔，二者一致）
> - (b) $1.8, 2, 2.2$ ns → $T = 0.84$ ns（边沿挤在两端，最小二乘斜率变缓）
> - (c) $0.5, 2, 3.5$ ns → $T = 1.1$ ns（边沿聚在中间，斜率变陡）

**等价视角：回归直线**。把 $(k, t_k)$ 画在二维图上，理想时钟对应一条斜率为 $T$ 的直线，抖动即各点相对"最佳拟合直线"的残差。$n$ 个点的最小二乘回归线 $y = \beta_1 x + \beta_0$：

$$\beta_1 = \frac{n\sum x_k y_k - \sum x_k \sum y_k}{n\sum x_k^2 - \left(\sum x_k\right)^2},\qquad \beta_0 = \frac{\sum y_k - \beta_1 \sum x_k}{n} \tag{10.23-10.24}$$

代入 $x_k = k$、$y_k = t_k$、$\beta_1 = T$、$\beta_0 = t_{OS}$，与式 (10.18)、(10.22) 完全相同——两种推导是同一回事。

> [!note] 实用要点
> 求出 $a_k$ 后：周期抖动由 $T_k = t_{k+1} - t_k$ 统计（峰峰值、RMS）；周期间抖动由相邻周期之差统计；绝对抖动的 RMS/峰峰值由残差 $a_k$ 统计。附录 B.2 的函数一次性输出以上全部指标。

## 10.3 由抖动样本计算相位噪声图

提取抖动后，计算相位噪声非常直接：

1. **抖动 → 过剩相位**：$\phi_k = -\omega_0 a_k$（即第 3 章式 3.5 的离散形式；符号不影响 PSD，代码中取 $\phi_k = 2\pi a_k/T$）；
2. **PSD 估计**：对 $\phi_k$ 施加标准 PSD 算法——可直接用数学软件内置函数，或经 FFT 按周期图/Welch 方法（加窗、分段、平均）计算；
3. **相位噪声**：$\mathcal{L}(f) = S_\phi(f)/2$（第 3 章基本关系）。

附录 B.2 的实现采用 **Welch 平均周期图**：Hann 窗、32 段重叠分段、各段 FFT 幅度平方累加后按窗能量归一化。

## 10.4 尾部拟合算法（Tail Fitting）

**动机**：测量/仿真只能得到有限样本，无法直接观测 $10^{-12}$ 量级的极低概率事件；需要由抖动直方图的"尾部"拟合高斯渐近行为，外推低 BER 下的 TJ（回顾第 2.2.8 节的 RJ/DJ 分解与 dual-Dirac 思想）。核心洞察：**高斯 PDF 与有界 PDF 卷积结果的尾部，经过 Q-scale 变换后呈线性**，于是高斯拟合被转化为标准的直线拟合问题。

### Q-scale 变换

高斯 PDF 与其 CDF：

$$n(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right),\qquad N(x) = \int_{-\infty}^{x} n(t)\,dt \tag{10.25-10.26}$$

借助互补误差函数可写成闭合形式：

$$N(x) = \frac{1}{2}\,\mathrm{erfc}\left(-\frac{x-\mu}{\sigma\sqrt{2}}\right) \tag{10.28}$$

反演得基本关系：

$$-\sqrt{2}\,\mathrm{erfc}^{-1}\left[2N(x)\right] = \frac{x-\mu}{\sigma} \tag{10.29}$$

据此定义任意 CDF $F(x)$ 的 **Q-scale 变换**：

$$Q(x) := -\sqrt{2}\,\mathrm{erfc}^{-1}\left[2F(x)\right] \tag{10.30}$$

> [!important] 线性化性质
> 若 $F(x)$ 是高斯 CDF，则 $Q(x)$ 是**直线**：斜率 $1/\sigma$，与 x 轴交于 $\mu$。于是"在尾部拟合高斯"变成"在变换域拟合直线"，$\mu$、$\sigma$ 从直线参数直接读出。

**Q-scale 尾部拟合步骤**：
1. 由测量 PDF/直方图计算**左尾 CDF**（常规 CDF：从 $-\infty$ 积到 $x$）与**右尾 CDF**（从 $x$ 积到 $+\infty$）；
2. 对两条 CDF 分别施加 Q-scale 变换；
3. 对线性化后的曲线做最佳直线拟合（如 LMS 准则）；
4. 由斜率与截距提取左右尾各自的 $\mu$ 与 $\sigma$。

> [!warning] Q-scale 方法的系统偏差
> 该方法隐含假设待拟合高斯曲线面积为 1。但存在 DJ 时，PDF 下的部分面积属于 DJ，归属 RJ 的高斯面积必然 $< 1$。结果是：拟合高斯幅度虚高 → **DJ 被低估、$\sigma$（RJ）被高估** → 极低 BER 下 TJ 过于悲观。从拟合图上可直接看到：虚线高斯的峰值明显超出实测 PDF 的包络。

### 归一化 Q-scale 变换

改进思路（源自 Popovici 对数字链路误码率外推的工作，后经发展用于专用测试设备）：承认待拟合高斯带有**幅度因子** $A \leq 1$：

$$n_A(x) = A\cdot n(x) = \frac{A}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right),\qquad N_A(x) = A\cdot N(x) \tag{10.31}$$

把 CDF 先除以 $A$ 再做 Q-scale，仍可线性化：

$$-\sqrt{2}\,\mathrm{erfc}^{-1}\left(\frac{2N_A(x)}{A}\right) = \frac{x-\mu}{\sigma} \tag{10.32}$$

因变换前多了"除以幅度 $A$"这一步，故称**归一化 Q-scale**（normalized Q-scale）。$A$ 本身也是待估参数，识别方法是：把待测 CDF 除以可变因子 $k$ 后施加变换：

$$-\sqrt{2}\,\mathrm{erfc}^{-1}\left(\frac{2F(x)}{k}\right) \tag{10.33}$$

**只有 $k = A$ 时结果才是完美直线**；$k$ 偏离 $A$ 时曲线弯曲。因此扫描 $k$、取线性度最佳者即得 $A$。

**归一化 Q-scale 尾部拟合步骤**：
1. 计算左、右尾 CDF（同上）；
2. 除以可变因子 $k$、做 Q-scale 变换，扫描 $k$ 并检验线性度，取最佳直线对应的 $k$ 作为 $A$；
3. 对最佳线性化曲线做直线拟合；
4. 提取左右尾的 $A$、$\mu$、$\sigma$。

对 dual-Dirac 与均匀 DJ 两个测试案例，归一化方法给出明显更真实的尾部拟合，DJ 与 RJ 估计都更准确。

> [!important] 最大难点：拟合区间的选择
> 理想做法是取 PDF 最外侧的尾部——那里 DJ 对 RJ 的"污染"最小；但极端尾部样本最少、统计涨落与误差最大，二者矛盾。附录 B.3 的策略：在可变的 x 区间上评估变换后 CDF 的直线拟合误差，自动选择误差最小的区间。书中明示这只是可行方案之一，存在等价或更优的做法。

## 关键公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| 抖动 PSD ↔ 相位噪声 | $S_a(f) = \mathcal{L}(f)/\omega_0^2$ | 全章桥梁（源自 3.1.2 节） |
| 离散白噪声 PSD | $S_a(f) = \sigma_a^2/f_0$ | 采样栅格 $1/f_0$ |
| 平坦轮廓噪声幅度 | $\sigma_a = \frac{1}{2\pi}\sqrt{\mathcal{L}_0/f_0}$ | 式 (10.3) |
| 滤波整形 | $\mathcal{L}(f) = |H(f)|^2\mathcal{L}_0$ | 低/高/带通轮廓 |
| $1/f^2$ 输入方差 | $\sigma_l = \frac{f_1}{f_0}\sqrt{\mathcal{L}_1/f_0}$ | 累加器输入，式 (10.6) |
| Bernamont 滤波器 | $H_n(f) = \dfrac{10^{-n/2}}{1+jf/(10^n f_{\min})}$ | 每十倍频一个，式 (10.7) |
| 合成 $1/f$ 增益 | $\left|\sum_n H_n(f)\right|^2 = \gamma f_{\min}/f$ | $\gamma \approx 1.426$，式 (10.11) |
| $1/f$ 输入方差 | $\sigma_l^2 = \mathcal{L}_1 f_1/(4\pi^2\gamma f_{\min}f_0)$ | 式 (10.13) |
| $1/f^3$ 输入方差 | $\sigma_l^2 = \mathcal{L}_1 f_1^3/(\gamma f_{\min}f_0^3)$ | $1/f$ 再积分，式 (10.15) |
| 绝对抖动定义 | $a_k = t_k - kT - t_{OS}$ | 式 (10.16) |
| 最小二乘周期 | $T = \dfrac{12}{n(n^2-1)}\sum_k\left(k-\frac{n-1}{2}\right)t_k$ | $n>3$ 时 ≠ 平均周期，式 (10.22) |
| 时间偏移 | $t_{OS} = \frac{1}{n}\sum_k(t_k - kT)$ | 式 (10.18) |
| Q-scale 变换 | $Q(x) = -\sqrt{2}\,\mathrm{erfc}^{-1}[2F(x)]$ | 高斯 CDF → 直线，斜率 $1/\sigma$、截距 $\mu$ |
| 归一化 Q-scale | $-\sqrt{2}\,\mathrm{erfc}^{-1}[2F(x)/k]$ | 仅 $k=A$ 时成直线，式 (10.33) |
| 带幅度高斯 | $n_A(x) = A\cdot n(x)$，$A\leq 1$ | 补偿 DJ 占去的面积 |

## 要点总结

- 生成任意相位噪声轮廓的时钟边沿序列，归结为生成对应的**绝对抖动序列** $a_k$ 并叠加到理想时钟上；核心桥梁是 $S_a(f) = \mathcal{L}(f)/\omega_0^2$。
- PSD 与 PDF 相互独立：本章全部算法用高斯白噪声做原料，谱形完全由后续的滤波/积分操作决定。
- 平坦轮廓 = 白噪声直接缩放；任意有理谱形（低通/高通/带通、PLL 谱）= 白噪声过数字滤波器，$\mathcal{L}(f) = |H(f)|^2\mathcal{L}_0$。
- $1/f^2$ 轮廓 = 白噪声的**随机游走**（累加积分）；$1/f$ 轮廓 = 白噪声通过 Bernamont 滤波器组（每十倍频一个一阶低通，增益按 $1/\sqrt{10}$ 递减，合成误差由 $\gamma \approx 1.426$ 刻画）；$1/f^3$ = $1/f$ 再积分一次。
- 复杂轮廓利用"独立过程之和 PSD 相加"，把各基本分量分别生成后相加即可。
- 由边沿时刻向量求抖动，本质是**最小二乘直线拟合**：斜率给出理想周期 $T$、截距给出 $t_{OS}$、残差即绝对抖动；$n>3$ 时 $T$ 一般不等于平均周期。
- 相位噪声图的重建：抖动 → 过剩相位 → PSD 估计（Welch 平均周期图）→ $\mathcal{L}(f) = S_\phi/2$。
- 尾部拟合利用 Q-scale 变换把高斯 CDF 线性化（斜率 $1/\sigma$、截距 $\mu$），将外推问题化为直线拟合；基本 Q-scale 因强制面积为 1 而低估 DJ、高估 RJ。
- 归一化 Q-scale 引入幅度因子 $A\leq1$，扫描归一化系数 $k$ 取线性最佳者，显著改善 DJ/RJ 估计精度；拟合区间选择（极端尾部 vs. 统计涨落）是实际应用中的最大难点。
