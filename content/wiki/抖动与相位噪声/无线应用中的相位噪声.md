# 第 8 章 无线应用中的相位噪声（Phase Noise in Wireless Applications）

> [!abstract] 章节概览
> 本章面向 RF/无线工程师，讨论 PLL/VCO 的相位噪声如何损害无线收发机性能。发射机用 PLL 把基带信号上变频到射频，接收机用另一个 PLL 把射频下变频回基带；本振（LO）不纯净时，上/下变频过程会把相位噪声"涂抹"到邻近信道，或把强阻塞信号的噪声裙摆进有用频带。
>
> 三个核心问题：**发射机相位噪声泄漏到邻机接收频带**（推导 GSM/WCDMA 的 TX VCO 指标）、**接收机互易混频**（阻塞信号与 LO 相位噪声混频，在带内产生噪声）、以及作为基础概念的**噪声系数与接收机灵敏度**。本章结论全部可以直接用于写系统指标书。

## 8.1 无线收发机基础（Basics of Wireless Transceivers）

### 发射机与接收机链路

**发射机（TX）**简化链路：基带信号 → 两步上变频（先到中频 IF，再经 PLL 内部 LO 到射频 RF）→ 带通滤波器（BPF）→ 功率放大器（PA）→ 天线。

- 若 LO 是纯净单音，基带带宽为 $B$ 的信号被原样搬移到 $f_{RF}$，射频信号带宽为 $2B$。
- 实际 LO 带相位噪声，上变频后频谱在 $2B$ 之外仍有分量，落入**邻近接收信道**成为干扰。BPF 只保留 $2B$ 带内成分，衰减带外相位噪声。

**接收机（RX）**简化链路：天线 → 片外声表面波滤波器（SAW filter）→ 低噪声放大器（LNA）→ 混频器（mixer，下变频到 IF 或直接到 DC）→ 滤波选信道。

> [!note] 接收机中的 BPF/LPF 作用类似收音机选台：从接收频带内众多信道中选出目标信道。

### 阻塞信号（Blockers）

有用信号可能极弱——例如 GSM 中有用信号带宽 $B = 100\,\mathrm{kHz}$、功率可低至 $-102\,\mathrm{dBm}$（约 $2.5\,\mu\mathrm{V_{rms}}$）。与此同时，接收机还会收到强得多的无用信号，统称**阻塞信号（blocker）**：

| 类型 | 来源 | 抑制手段 |
| --- | --- | --- |
| 带外阻塞（out-of-band blocker） | 接收频带之外的强发射机 | SAW 滤波器衰减 |
| 带内阻塞（in-band blocker） | 同一接收频带内的邻近信道 | IF 级滤波衰减 |

> [!important] 阻塞信号的两条危害路径
> 1. **非线性**：未被充分衰减的阻塞信号幅度远大于有用信号，会把接收机电路逼进非线性区；多个强阻塞互调（intermodulation）后还可能产生恰好落在有用信号频谱上的分量。
> 2. **互易混频**：残余阻塞与 LO 相位噪声混频，直接在带内造出噪声（见 8.3，本章重点）。

### 噪声系数（Noise Figure, NF）

理想 LNA 把信号与噪声放大同一倍数，输出 SNR 等于输入 SNR；实际 LNA 的有源/无源器件会额外附加噪声，使输出 SNR 变差。噪声系数定义为输入/输出 SNR 之差（dB）：

$$\mathrm{NF[dB]} = \mathrm{SNR_{in}[dB]} - \mathrm{SNR_{out}[dB]} \tag{8.1}$$

典型 LNA 的 NF 约为 2–3 dB。NF 越大，说明器件自身"添"的噪声越多。

### 接收机灵敏度（Receiver Sensitivity）

**灵敏度**：在噪声中仍能被可靠检测的最小输入信号功率。大多数接收机要求信号功率比噪声功率高 3–5 dB（即 2–3 倍）。

输入端噪声的主要来源是天线热噪声 $kTB$（$k$ 为玻尔兹曼常数，$T$ 为绝对温度，$B$ 为信号带宽）：

$$N_{thermal}[\mathrm{dBm}] = 10\log_{10}(kTB) = \underbrace{10\log_{10}(kT)}_{-174\,\mathrm{dBm/Hz}\ (T=300\,\mathrm{K})} + 10\log_{10}(B)\ [\mathrm{dBHz}] \tag{8.2, 8.3}$$

把 LNA 自身噪声折算到输入端（加 NF），得**噪声底（noise floor）**：

$$N_{floor}[\mathrm{dBm}] = -174\ [\mathrm{dBm/Hz}] + 10\log_{10}(B)\ [\mathrm{dBHz}] + \mathrm{NF[dB]} \tag{8.4}$$

若可靠检测要求最低信噪比 $\mathrm{SNR_{min}}$，则灵敏度为：

$$\boxed{RX_{sensitivity}[\mathrm{dBm}] = N_{floor}[\mathrm{dBm}] + \mathrm{SNR_{min}[dB]}} \tag{8.5}$$

> [!example] 物理图像
> 热噪声是"地板"，NF 把地板垫高，SNR 要求决定信号必须高出垫高后的地板多少。三者叠加即为灵敏度。

## 8.2 发射机 VCO 相位噪声要求实例

### GSM（P-GSM-900）

P-GSM-900 频段规划：TX 频带（上行，手机→基站）890–915 MHz，RX 频带（下行，基站→手机）935–960 MHz；信道间隔 200 kHz，每方向 124 个信道，两侧各 100 kHz 保护带；**TX 与 RX 频带之间留有 20 MHz 间隔**——这个间隔就是留给 TX 相位噪声衰减的"缓冲区"。

> [!note] 最坏情形
> 一部手机在 TX 频带**最右端**信道发射，其 LO 相位噪声裙边向右延伸 20 MHz 后，恰好落入**旁边另一部手机** RX 频带的最左端信道。因此关注的偏移量为 $\Delta f = 20\,\mathrm{MHz}$。

由相位噪声定义（式 3.25：偏移 $\Delta f$ 处 1 Hz 带宽内的噪声功率与载波功率之比）：

$$\mathcal{L}_{GSM}(\Delta f) = \frac{S_{LO}(f_{TX}+\Delta f)}{P_{TX}} \tag{8.6}$$

若接收信道内允许的最大噪声功率为 $N_{RXmax}$，则落入带宽 $B$ 的泄漏噪声须满足 $\mathcal{L}(\Delta f)\cdot P_{TX}\cdot B \le N_{RXmax}$，写成 dB 形式：

$$\mathcal{L}_{GSM}(\Delta f)[\mathrm{dBc/Hz}] \le N_{RXmax}[\mathrm{dBm}] - P_{TX}[\mathrm{dBm}] - 10\log_{10}(B)\ [\mathrm{dBHz}] \tag{8.8}$$

代入 $\Delta f = 20\,\mathrm{MHz}$、$N_{RXmax} = -79\,\mathrm{dBm}$、$P_{TX} = 33\,\mathrm{dBm}$、$B = 100\,\mathrm{kHz}$：

$$\mathcal{L}_{GSM}(20\,\mathrm{MHz}) \le -79 - 33 - 50 = -162\ \mathrm{dBc/Hz} \tag{8.9}$$

> [!important] 符号与直觉
> 发射功率 $P_{TX}$ 越大、允许的噪声上限 $N_{RXmax}$ 越低、信道带宽 $B$ 越宽，对远端相位噪声的要求就越苛刻。$-162\,\mathrm{dBc/Hz}$ @ 20 MHz 是相当严格的指标，这也是为什么 GSM 手机 TX 要用心设计 VCO 与 PA 前的滤波。

### WCDMA

WCDMA 中泄漏路径更"尴尬"：**同一部手机自己的 TX** 相位噪声会干扰**自己的 RX**。双工器（duplexer）理论上应隔离 TX→RX，实际只能衰减约 45 dB：

- 最大发射功率 $26\,\mathrm{dBm}$，经双工器后泄漏到 RX 端为 $26 - 45 = -19\,\mathrm{dBm}$；
- TX–RX 频带间隔 $\Delta f$ 依频段不同在 30–400 MHz 之间。

用同样的式 (8.8) 计算，得：

$$\mathcal{L}_{WCDMA}(\Delta f) \le -161\ \mathrm{dBc/Hz} \tag{8.10}$$

## 8.3 接收机的互易混频（Reciprocal Mixing at the Receiver）

### 机理

理想混频器用 $f_{LO}$ 处的纯净单音，把 $f_{RF}$ 附近的窄带信号平移到中频 $f_{IF} = |f_{RF} - f_{LO}|$ 附近处理。实际 LO 带着相位噪声裙边。设某阻塞信号位于 $f_B$：阻塞与"偏移载波 $f_B - f_{IF}$ 处的那个相位噪声分量"混频后，产物恰好落在 $f_{IF}$ 附近——与有用信号落入同一频带。

> [!note] 为什么叫"互易"（reciprocal）
> 正常混频是"LO 单音搬移 RF 信号"；这里角色互换——**阻塞信号扮演了 LO 的角色，LO 的相位噪声扮演了 RF 信号的角色**，故得名。

文字版频谱示意（以直接变频接收机 $f_{IF}=0$ 为例）：

```
混频前（RF 域）：

 功率 │
      │   阻塞 P_B                     期望信号 P_C
      │     │                            ┌─┐
      │     │                            │ │
      │     ▼             LO 载波        └─┘
      │     █              █╲
      │     │              │ ╲___ ← 相位噪声裙边 L_LO(Δf)
      └─────┴──────────────┴───────────┬───┴──────────→ f
            f_B = f_LO + Δf           f_LO = f_RF

混频后（基带）：

      │   期望信号
      │    ┌─┐
      │    │ │░░░░░░ ← 阻塞与 Δf 处相位噪声的混频产物，
      │    │ │░░░░░░   恰好摊在信号带宽 B 内，无法滤除
      └────┴─┴────────────────────────────→ f
            0 (DC)
```

### 定量分析

设 LO 相位噪声为 $\mathcal{L}_{LO}(f)$，阻塞总功率 $P_B$，信号带宽 $B$。互易混频附加到带内的噪声功率为：

$$N_{RM} = P_B \cdot \mathcal{L}_{LO}(\Delta f) \cdot B \tag{8.11}$$

dB 形式：

$$N_{RM}[\mathrm{dBm}] = P_B[\mathrm{dBm}] + \mathcal{L}_{LO}(\Delta f)[\mathrm{dBc/Hz}] + 10\log_{10}(B)\ [\mathrm{dBHz}] \tag{8.12}$$

阻塞通常很大，使该噪声远超热噪声，于是输出 SNR 近似为：

$$\mathrm{SNR[dB]} = P_C - P_B - \mathcal{L}_{LO}(\Delta f) - 10\log_{10}(B) \tag{8.13}$$

其中 $P_C$ 为有用信号载波功率。若标准要求最低 $\mathrm{SNR_{min}}$，得到对 LO 相位噪声的硬性要求：

$$\boxed{\mathcal{L}_{LO}(\Delta f)[\mathrm{dBc/Hz}] \le P_C - P_B - 10\log_{10}(B) - \mathrm{SNR_{min}}} \tag{8.14}$$

> [!important] 互易混频为何要求"近端"相位噪声足够低
> 1. **带内阻塞滤不掉**：SAW 只能衰减带外阻塞；与有用信号同频带的阻塞（如 GSM 600 kHz 外的邻信道）直达混频器。
> 2. **相位噪声越靠近载波越大**（$1/f^2$ 裙边）：小 $\Delta f$ 处的 $\mathcal{L}_{LO}(\Delta f)$ 最高，而近端阻塞恰恰混这段最差的噪声。
> 3. 混出来的噪声**就在信号带宽 $B$ 内**，任何后级滤波都无能为力。
>
> 因此阻塞指标书的第一个近端阻塞点（最小 $\Delta f$）往往直接决定了 VCO 的近端相位噪声指标。

> [!example] GSM 接收机数值实例
> GSM 要求 $\mathrm{SNR_{min}} = 9\,\mathrm{dB}$，灵敏度（即载波电平 $P_C$）为 $-99\,\mathrm{dBm}$，信道带宽 $B = 200\,\mathrm{kHz}$（$10\log_{10} B = 53\,\mathrm{dBHz}$）。阻塞模板（blocker mask）允许阻塞功率随频偏增大而升高：
>
> - **600 kHz 处阻塞 $P_B = -43\,\mathrm{dBm}$**：
> $$\mathcal{L}_{LO}(600\,\mathrm{kHz}) \le -99 - (-43) - 53 - 9 = -118\ \mathrm{dBc/Hz}$$
> - **3 MHz 处阻塞 $P_B = -23\,\mathrm{dBm}$**：
> $$\mathcal{L}_{LO}(3\,\mathrm{MHz}) \le -99 - (-23) - 53 - 9 = -138\ \mathrm{dBc/Hz}$$
>
> 注意虽然 3 MHz 处阻塞更强（$-23$ vs $-43$ dBm），但由于 VCO 相位噪声随频偏自然下降，$-138\,\mathrm{dBc/Hz}$ @ 3 MHz 往往并不比 $-118\,\mathrm{dBc/Hz}$ @ 600 kHz 更难做到——**近端那一点才是真正的设计难点**。

### 阻塞噪声系数（Blocker NF）

把互易混频噪声与热噪声 $-174\,\mathrm{dBm/Hz} + 10\log_{10}B$ 相比（dB 相减，带宽项恰好抵消），得到阻塞引入的等效噪声系数恶化量：

$$\mathrm{Blocker\ NF[dB]} = P_B[\mathrm{dBm}] + 174[\mathrm{dBm/Hz}] + \mathcal{L}_{LO}(\Delta f)[\mathrm{dBc/Hz}] \tag{8.15}$$

> [!note] dB 对 dB 的交换律
> 式 (8.15) 表明：阻塞功率每增加 1 dB，就必须用相位噪声降低 1 dB 来补偿，否则 SNR 受损。降阻塞靠 SAW 滤波；没有 SAW 的宽带接收机只能把压力全部转嫁给 VCO 相位噪声与 LNA 线性度。

> [!tip] 进阶技巧
> 相位噪声谱关于载波近似对称，可利用这一对称性设计电路抵消互易混频产物（原书参考文献 [102]）。

## 关键公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| 噪声系数 | $\mathrm{NF} = \mathrm{SNR_{in}} - \mathrm{SNR_{out}}$ (dB) | LNA 典型 2–3 dB |
| 热噪声功率 | $N_{thermal} = -174 + 10\log_{10}B$ [dBm] | 室温 300 K，$B$ 单位 Hz |
| 噪声底 | $N_{floor} = -174 + 10\log_{10}B + \mathrm{NF}$ [dBm] | 输入参考总噪声 |
| 接收机灵敏度 | $RX_{sens} = N_{floor} + \mathrm{SNR_{min}}$ [dBm] | 信号须高出噪声底 $\mathrm{SNR_{min}}$ |
| TX 相位噪声要求 | $\mathcal{L}(\Delta f) \le N_{RXmax} - P_{TX} - 10\log_{10}B$ [dBc/Hz] | GSM: $-162$ dBc/Hz @ 20 MHz |
| 互易混频带内噪声 | $N_{RM} = P_B + \mathcal{L}_{LO}(\Delta f) + 10\log_{10}B$ [dBm] | dB 形式，各项直接相加 |
| 互易混频 SNR | $\mathrm{SNR} = P_C - P_B - \mathcal{L}_{LO}(\Delta f) - 10\log_{10}B$ [dB] | 假设远大于热噪声 |
| LO 相位噪声要求 | $\mathcal{L}_{LO}(\Delta f) \le P_C - P_B - 10\log_{10}B - \mathrm{SNR_{min}}$ [dBc/Hz] | GSM: $-118$ @ 600 kHz，$-138$ @ 3 MHz |
| 阻塞 NF | $\mathrm{BlockerNF} = P_B + 174 + \mathcal{L}_{LO}(\Delta f)$ [dB] | 阻塞每 +1 dB，相位噪声须 −1 dB |

## 要点总结

- 无线收发机的上/下变频质量由 PLL 时钟质量（相位噪声）直接决定：相位噪声会把信号能量涂抹到邻近信道，也会把强阻塞"翻译"成带内噪声。
- 阻塞分带内/带外两类：带外靠 SAW、带内靠 IF 滤波；残余阻塞通过非线性互调与互易混频两条路径恶化 SNR。
- 灵敏度公式 $-174 + 10\log_{10}B + \mathrm{NF} + \mathrm{SNR_{min}}$ 是接收机噪声预算的骨架，所有量都是 dB 域加减。
- TX 相位噪声指标由"最恶劣几何关系"决定：GSM 是邻机 RX 频带边缘（$\Delta f = 20$ MHz → $-162$ dBc/Hz）；WCDMA 是双工器泄漏路径（→ $-161$ dBc/Hz）。
- 互易混频中阻塞与 LO 相位噪声角色互换；带内噪声 $N_{RM} = P_B \cdot \mathcal{L}_{LO}(\Delta f) \cdot B$ 无法被后级滤除。
- 相位噪声要求式 $\mathcal{L}_{LO}(\Delta f) \le P_C - P_B - 10\log_{10}B - \mathrm{SNR_{min}}$ 中，最强阻塞点给出最严指标；近端阻塞点决定 VCO 近端相位噪声。
- Blocker NF 揭示"阻塞功率与相位噪声 dB 对 dB 互换"的硬约束；无 SAW 的宽带接收机把压力全压在 VCO 上。
