# 第 1 章 抖动导论（Introduction to Jitter）

> [!abstract] 章节概览
> 本章用直觉性的例子回答"抖动是什么、为什么重要"。核心线索：任何依赖时间基准的系统都要面对**时间不确定性**（timing uncertainty），电子系统中这种不确定性就叫**抖动**（jitter）。本章从五个角度建立定性认识：时钟抖动（周期抖动 / 绝对抖动 / 故意抖动）、数据抖动（眼图、随机 vs 确定性）、计时测量中的抖动（电流给电容充电的"电子沙漏"）、环形振荡器中的抖动（CMOS 反相器延迟噪声如何累积成随机游走）、以及抖动在各类电子系统（数字、数据转换器、有线链路）中的影响。
>
> 与后续章节的关系：本章只做定性介绍，严格的数学定义与统计刻画在第 2 章给出；环形振荡器抖动的严格分析在第 4 章；有线链路（CDR）在第 7 章深入讨论。

**日常生活的类比**：拍月食要提前开机留裕量、赴约要按"手表可能偏慢"提前出门、新干线准点发车但你可能上错车——错过事件、迟到、上错车都是时间不确定性的后果。数字电路用带有抖动的时钟给事件定时，同样会"错过数据"或"采错数据"（误码）。工程目标是：**先研究不确定性的本质并建模，再把出错概率降到可接受的水平**。

## 1.1 什么是时钟抖动？（What Is Clock Jitter?）

### 1.1.1 周期抖动（Period Jitter）

微处理器（μP）和 DSP 都假设"每个时钟周期时长完全一致"，但时钟由物理器件产生，周期只能以**有限精度**相同。

> [!example] 三级反相器环形振荡器
> 三个相同的 CMOS 反相器连成环（见图 1.1 的文字描述：v_out 节点状态翻转一次需经过 3 级传播延迟 $t_{pd}$，完成一个完整周期需两次翻转），因此标称周期
> $$T_{nom} = 6\,t_{pd}$$
> 关键点是：$t_{pd}$ 并非常数，而是**随机变量**——任何在 0 K 以上处理电子运动的物理器件都固有随机性。于是周期（6 个随机变量之和）也是随机变量，会偏离其标称（期望）值。

低频时周期远大于偏差，抖动无害；频率升高后，**同样的绝对偏差**就会危及电路工作。

> [!example] 4 GHz 时钟的设计裕量（重要数值直觉）
> 4 GHz → 标称周期 250 ps，设周期服从高斯分布、标准差 $\sigma = 1$ ps。由第 9 章表 9.1（高斯尾部概率表）：周期小于 243 ps（即偏短 7σ）的概率约 $10^{-12}$。
>
> 设计含义：任何"必须在一个周期内完成"的任务，都应按**最坏情况周期 243 ps**（而非标称 250 ps）来验证，才能保证以 $1-10^{-12}$ 的概率不出错。若把失效概率再压低，可按 242 ps 最小周期设计，失效率降到 $6.22\times10^{-16}$，约合 4 GHz 下**每 4.6 天出一次错**。

> [!note] 定义（直觉版）
> **周期抖动**：时钟周期偏离其标称值的量。与之密切相关的 **N 周期抖动**（N-period jitter）：N 个连续周期构成的时间区间偏离 N 个标称周期的量。严格定义见 [第 2 章](抖动基础与统计.md)。

### 1.1.2 绝对抖动（Absolute Jitter）

周期抖动关注的是**时间区间**，但在时钟数据恢复（CDR）等应用中，时钟边沿用于**采样**数据——采样发生在一个**时刻**而非一段时间上。此时重要的是边沿的**绝对时刻**是否精确。

理想时钟的上升沿恰好在 $t = kT$（k 为整数）；非理想时钟的第 k 个上升沿在 $t_k$，其偏差就是**绝对抖动**（absolute jitter）。"绝对"二字强调它是**时刻**的偏差，区别于周期抖动那种**区间**的偏差。

> [!important]
> 把绝对抖动从时钟波形中单独画出来，它是一个**离散时间随机信号**。任何随机信号都有明确定义的频谱（第 2、3 章展开），因此绝对抖动可能包含连续范围的频率成分。绝对抖动与周期抖动关系密切，第 2 章将给出两者互换的公式。

### 1.1.3 故意抖动（Intentional Jitter）

抖动并非总是坏事，两个"故意加抖动"的例子：

1. **扩频时钟**（Spread-Spectrum Clocking, SSC）：干净的周期时钟能量集中在基波和各次谐波的尖峰上。时钟频率超过约 100 MHz 后，某些谐波波长与 PCB 走线长度可比拟，会辐射并造成**电磁干扰**（EMI）。SSC 给时钟施加受控抖动——典型做法是令频率偏移随时间**线性上升再线性下降**（三角调制，周期 $kT$）——把谱峰能量摊到更宽的频带上，降低峰值与 EMI。频率升高 $\Delta f$（设 $\Delta f \ll f_0$）等效于周期缩小约 $2\Delta f/f_0$ 的比例（往返一次）。
2. **抖动容限测试**：表征 CDR 鲁棒性时，故意往输入数据里加抖动，观察系统误码率随抖动频率的变化（详见第 7 章）。

## 1.2 什么是数据抖动？（What Is Data Jitter?）

D 触发器在时钟上升沿把 D 采到 Q，输出数据因此与时钟同步——**时钟抖动直接传递到数据边沿**。在 CDR 应用中，一个数据比特的时长称为**单位间隔**（Unit Interval, UI）。理想时钟产生的数据流 UI 恒定（"干净"数据）；非理想时钟产生的数据流每个 UI 都略有不同（"带抖动"数据）。

> [!note] 抖动只在跳变沿上可观察
> 数据序列是随机的，并非每个 UI 边界都有跳变；没有跳变就无法观察抖动。解决办法是把许多个 UI 叠画在一起——即**眼图**。

### 1.2.1 眼图（Eye Diagram）

CDR 中时钟以间隔 T 的时刻采样带抖动的数据。把数据波形切成长度 T 的片段并全部叠画（即"对 1T 取模"后的波形），得到的复合图形像一只眼睛，称为**眼图**。

- **垂直方向**：眼高（vertical eye opening）最大的时刻，是数据 "1" 与 "0" 分得最开的时刻——我们希望时钟上升沿正好落在这里采样。
- **水平方向**：抖动随时间累积会使眼在水平方向闭合。**水平眼开度**（horizontal eye opening）代表无误码工作所剩的**定时裕量**。
- 当噪声、干扰、衰减和抖动过大时，眼完全闭合——不存在任何能稳定区分 1/0 的时刻，必须借助**均衡**（equalization）和**抖动清理**（jitter cleaning）重新把眼打开。

### 1.2.2 随机抖动 vs 确定性抖动（Random vs Deterministic Jitter）

抖动是对理想定时的任何偏离，按其产生机理分两类：

| | 随机抖动（RJ） | 确定性抖动（DJ） |
| --- | --- | --- |
| 产生机理 | 电子的随机热运动（不可预测） | 有明确物理原因，给定模型可精确预测 |
| 典型例子 | 器件热噪声 | PCB 走线的低通滤波效应拖慢数据跳变沿 |
| 直方图 / PDF | **无界**（高斯状，尾巴无限延伸） | **有界**（分布范围有限） |

> [!important]
> 实际系统中多种抖动源同时起作用，合成抖动既含 RJ 也含 DJ。第 2 章和第 7 章将讨论如何把总抖动**分解**成各个分量。无论哪种抖动，作为离散时间序列总可以用**峰峰值**（peak-to-peak）或**均方根值**（RMS）来刻画。

## 1.3 计时测量中的抖动（Jitter in Measuring Time）

测量时间常靠观察某个物理过程的完成。**沙漏**是个好类比：

- **精度**（accuracy）：重复同一实验，测得时间的分散程度——沙粒尺寸分布与随机排列使每次流完的时间略有差异，这个差异就是沙漏的"抖动"。
- **分辨率**（resolution）：能分辨的最小时间间隔。

> [!example] 电子沙漏：电流源给电容充电
> 把沙粒换成电子、玻璃瓶换成电容：理想电流源 $I_0$ 给电容 C 从 0 V 充到阈值电压 $V_{TH}$（如 $V_{DD}/2$），"事件完成"所需时间为
> $$t = \frac{C\,V_{TH}}{I_0}$$
> 这只"电子沙漏"有三个调节分辨率的旋钮：减小 C、增大 $I_0$、或降低比较器阈值 $V_{TH}$。但**精度受限于电流源固有的电流噪声**。

实际的简单电流源（栅接地的 PMOS）与理想电流源有两方面差别：

1. **电流随电压变化**（电容越充电流越小，充电变慢）——这是确定性偏差，可通过**校准时间单位**吸收掉；
2. **电流含噪声**（电子热运动）——把实际电流源建模为"恒定电流 $I_0$ 并联噪声电流源"，噪声使电容电压偏离理想斜坡、提前或推迟到达 $V_{TH}$。这个时间偏差是**随机过程**，正是抖动，且与噪声电流（本身也是随机过程）的特性直接相关。

## 1.4 环形振荡器中的抖动（Jitter in a Ring Oscillator）

振荡器是产生时钟的电路，环形振荡器（ring oscillator）由奇数个（如 3 个）反相器连成闭环。本节直觉分析其抖动来源，严格处理见第 4 章。

### 1.4.1 CMOS 反相器延迟中的抖动

输入从 0 升到 $V_{DD}$，输出从 $V_{DD}$ 降到 0。**高到低延迟** $t_{phl}$ 定义为输入 50% 摆幅点到输出 50% 摆幅点之间的时间；**低到高延迟** $t_{plh}$ 类似。假设输入跳变是瞬时的，则：

- 输出上升时只有 PMOS 导通，输出下降时只有 NMOS 导通；
- 两种情形各得一个等效电路：**受栅压控制的确定性电流源** 与 **代表电子热运动的随机噪声电流源** 并联，对负载电容充/放电。

于是反相器延迟分解为两部分：

$$\underbrace{t_{phl},\,t_{plh}}_{\text{总延迟}} = \underbrace{\frac{C_L V_{TH}}{I_0}}_{\text{基础延迟（确定性）}} + \underbrace{(\text{随机部分})}_{\text{超额延迟 = 抖动}}$$

> [!important] 抖动是随机过程（random process）
> - **随机性**：同一时刻测两个相同反相器，噪声电流不同 → 延迟测量值不同；
> - **时变性**：同一反相器在不同时刻测 $t_{phl}$，结果也不同。
>
> 因此抖动是**随时间变化的随机变量**，即随机过程。

由此得到反相器的简化抖动模型：输入、输出都是"信号延迟"这一随机过程，**输出抖动 = 输入抖动 + 反相器内部噪声产生的抖动**。若输入是理想时钟，则该模型的输入为零。

### 1.4.2 环形振荡器的抖动建模

三级环形振荡器的抖动模型：设 $X_i[n]$ 为第 i 个反相器在第 n 个周期引入的总超额延迟（高到低 + 低到高两部分之和），n 为离散时间序号；输出的**绝对抖动**记为随机过程 $Y[n]$。

由模型结构直接看出：当前输出抖动 = 上周期的累积抖动 + 本周期三个反相器新产生的超额延迟：

$$Y[n] = Y[n-1] + X_1[n] + X_2[n] + X_3[n]$$

> [!important] 绝对抖动是随机游走（random walk）
> 若各 $X_i$ 统计相同且互不相关，则 $Y[n]$ 是离散随机变量 X 的"滚动求和"，即**随机游走过程**。随机游走的**方差随 n 线性增长**——自由运行的环形振荡器，其绝对抖动方差随周期数线性发散，除非用 PLL 等手段加以约束。

同一模型也解释**周期抖动**：它只是单个周期内新产生的超额延迟 $X_1[n]+X_2[n]+X_3[n]$，不累积历史，因此**方差有限、与周期数 n 无关**。这正是第 2 章将严格区分的两类抖动（绝对抖动累积、周期抖动不累积）的物理根源。

## 1.5 电子系统中的抖动（Jitter in Electronic Systems）

电容充电、反相器延迟中的时间不确定性普遍存在于一切电子系统，但后果各不相同：

- **同步数字系统**：关心"运算能否在若干周期内完成"——抖动使完成时间变得不确定（第 5 章）。
- **数据转换器（DAC/ADC）**：时钟的时间不确定性转化为模拟输出的**电压不确定性**，损害精度（第 6 章）。
- **有线链路**：抖动沿链路各模块传播、被整形，见下。

> [!example] 有线收发链路中抖动的旅程（图 1.14）
> 链路 = 发送机 + 信道 + 接收机，抖动在多处被注入和改造：
> 1. **发送端**：数据在发送时钟 $CK_{TX}$ 上升沿被打上信道。即使时钟由 PLL 产生也含抖动，这是链路中**第一处**时钟抖动直接传给数据的地方。
> 2. **信道**：互连的容性与介质损耗使信道呈**低通特性**，等效于"有记忆"——前一比特（NRZ 信令）的脉冲尾巴拖进当前比特，造成**码间干扰**（ISI），移动过零点位置 → 产生抖动。该抖动是**确定性**的（已知数据图案与信道响应即可完全确定）。这是链路中**第二处**注入抖动的地方。
> 3. **均衡器（EQ）**：接收机前端的均衡器可减小（理想情况消除）确定性抖动，但均衡后数据仍残留部分 RJ 与 DJ。
> 4. **时钟数据恢复（CDR）**：一个反馈环路，调节内部时钟的频率与相位以最小化其与输入数据的相位差，输出恢复时钟。此过程中恢复时钟会**继承**输入数据的一部分抖动，环路内其他模块（如鉴相的数字电路）还会**额外贡献**抖动。
>
> 由此引出两个核心问题：恢复时钟的抖动特性与数据抖动是否相似？定时不确定性被放大还是减小？——回答它们需要先量化抖动，即第 2 章的任务。

## 关键公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| 环形振荡器标称周期 | $T_{nom} = 6\,t_{pd}$ | 3 级反相器环，$t_{pd}$ 为单级传播延迟（随机变量） |
| 理想时钟边沿时刻 | $t_k^{ideal} = kT$ | 绝对抖动的参照系 |
| 电子沙漏计时 | $t = C V_{TH}/I_0$ | 恒流充电至阈值电压所需时间 |
| 反相器基础延迟 | $t_{base} = C_L V_{TH}/I_0$ | 确定性部分；随机部分即抖动 |
| 环振绝对抖动递推 | $Y[n] = Y[n-1] + X_1[n] + X_2[n] + X_3[n]$ | 随机游走，方差随 n 线性增长 |
| 环振周期抖动 | $p[n] = X_1[n]+X_2[n]+X_3[n]$ | 只含本周期的超额延迟，方差有限 |

## 要点总结

1. 抖动是电子系统中的**时间不确定性**；研究它的目的是把误码/失效概率降到可接受水平。
2. **周期抖动**关注时间区间（周期）的偏差，适用于"任务能否在一个周期内完成"的数字设计场景；**绝对抖动**关注边沿**时刻**的偏差，适用于采样/恢复场景。
3. 高速下抖动裕量设计实例：4 GHz、σ=1 ps 的周期抖动要求按最坏 243 ps 周期设计，换取 $10^{-12}$ 量级的失效概率。
4. **故意抖动**有用处：扩频时钟降低 EMI 峰值；抖动注入用于 CDR 抖动容限测试。
5. **眼图**是观察数据抖动的标准工具：垂直眼开度决定最佳采样点，水平眼开度即定时裕量。
6. 抖动按成因分**随机**（无界、高斯状）与**确定性**（有界、可预测）两大类；实际抖动是两者的合成。
7. 反相器延迟 = 确定性基础延迟 + 噪声引起的随机超额延迟；噪声电流使抖动成为**随机过程**。
8. 自由运行环形振荡器的**绝对抖动是随机游走**，方差随周期数线性增长；周期抖动不累积、方差有限——这是两类抖动最本质的区别。
9. 有线链路中抖动在 TX 时钟、信道 ISI、CDR 环路多处被注入与整形；均衡主要对付确定性抖动。
