# 第 2 章 抖动基础与统计（Basics of Jitter）

> [!abstract] 章节概览
> 工业界和学术界对抖动常有含糊的近似处理，导致误解和非最优设计。本章的任务是建立**严格、统一、可操作**的抖动语言。两条主线：
> 1. **定义**：给出四个基本抖动定义——绝对抖动、相对抖动、周期抖动、N 周期抖动，并证明文献中其他常见定义（TIE、cycle-to-cycle、长期抖动等）都可用这四个基本量表达。
> 2. **统计**：抖动是离散时间随机过程，本章用直方图 / PDF 刻画其幅度分布，引出均值、中位数、RMS、峰值等统计量，进而建立 RJ / DJ 分类体系、分量组合规则（卷积）、抖动分解（dual-Dirac 尾部拟合）与总抖动 TJ 和误码概率的关系。
>
> 与前后章的关系：第 1 章的定性直觉在此形式化；本章专注"统计（幅度域）"视角，"频域"视角（频谱、相位噪声）由第 3 章补上——两者互补，合起来才是抖动过程的完整描述。

## 2.1 抖动术语与形式化定义

文献中抖动术语繁多（period jitter、cycle jitter、cycle-to-cycle、accumulated、long-term……），且同一术语常被不同作者赋予不同含义。本书的原则是：**按"如何测量"来定义抖动**，使每个定义都对应一个明确的操作过程。

> [!note] 总定义
> 抖动 = 某事件发生**时刻**相对于某个（可任意选取的）参考时间框架的偏差。本书中"事件"指时钟边沿，即信号穿越给定阈值的时刻。参考系有两种选法：
> - 与**另一个时钟**比 → 绝对抖动、相对抖动；
> - 与**同一个时钟先前的边沿**比（自参考）→ 周期抖动、N 周期抖动。

### 时钟信号的数学模型

通用时钟信号写为

$$v(t) = A(t)\sin\big(\omega_0 t + \varphi(t)\big) \tag{2.1}$$

- 若 $A(t)$ 为常数且 $\varphi(t)\equiv 0$：完美正弦，正斜率过零点等间隔出现在 $kT$（$T=2\pi/\omega_0$）——理想时钟（自然界不存在）。
- **$A(t)$（幅度调制 / 幅度噪声）**：只要不为零，就**不改变过零点位置**，信号仍可用作理想时钟。故本书默认 $A(t)$ 为常数。
- **$\varphi(t)$**：叠加在理想相位 $\omega_0 t$ 上，使过零点偏离 $kT$——**正是抖动的来源**。本书统一称之为**过剩相位**（excess phase）；文献中的"phase noise / phase jitter"等叫法易与他概念混淆，应慎用。

更一般地，用任意每周期只有一个正过零点的周期波形 $x(\omega_0 t)$ 替代正弦：

$$v(t) = A(t)\,x\big(\omega_0 t + \varphi(t)\big) \tag{2.2}$$

实际的矩形时钟可看作正弦过零比较器的输出，借助符号函数写成

$$v(t) = A\,\mathrm{sgn}\big[\sin\big(\omega_0 t + \varphi(t)\big)\big] \tag{2.3}$$

于是正弦情形下关于相位与过剩相位的结论可原样搬到矩形时钟。

### 2.1.1 绝对抖动（Absolute Jitter）

设被测时钟标称周期为 T（各周期不同，但平均周期为 T）。取一个同周期、无抖动的**理想时钟**，其边沿恰在 $kT$。**绝对抖动**是离散时间随机序列 $a_k$：

$$a_k := t_k - kT \tag{2.4}$$

即被测时钟第 k 个上升沿 $t_k$ 相对理想时钟对应边沿的时间位移。因两时钟周期相同，总可选取理想时钟的位置使 $a_k$ 均值为零；若存在固定偏移 $t_{OS}\neq 0$，则重新定义 $a_k := t_k - kT - t_{OS}$（式 2.5）。本书默认 $t_{OS}=0$。

> [!note] "绝对"的含义
> 理想时钟以与任何具体实现无关的方式定义了**绝对时间尺度**，被测时钟与之比较，故称绝对抖动。

### 2.1.2 相对抖动（Relative Jitter）

比较对象换成**另一个真实的、非理想的**同周期时钟 ck2，则**相对抖动**为

$$r_k := t_k^{ck1} - t_k^{ck2} \tag{2.6}$$

在式 (2.6) 中加减 $kT$ 并引用式 (2.4)，立即得到相对抖动与两个时钟各自绝对抖动的关系：

$$r_k = a_k^{ck1} - a_k^{ck2} \tag{2.7}$$

同样默认均值为零；两时钟间若有固定 skew，需先扣除。

### 2.1.3 周期抖动（Period Jitter）

不再借助别的时钟，而是比较**同一个时钟相邻边沿**的间距。操作上等于：示波器用时钟某个边沿触发，观察下一个边沿在其平均位置附近的摆动。**周期抖动** $p_k$ 定义为实际周期对标称周期的偏差：

$$p_k := (t_{k+1} - t_k) - T = T_k - T \tag{2.8}$$

其中 $T_k$ 为第 k 个实际周期。在右端加减 $(k+1)T$ 可得与绝对抖动的关系：

$$p_k = a_{k+1} - a_k \tag{2.9}$$

> [!example] 为什么需要 N 周期抖动？
> 考虑理想（无延迟、无噪声）的 N 分频器：输出时钟的一个周期恰好对齐输入时钟相隔 N 个周期的两个边沿，因此**分频器输出的周期抖动 = 输入时钟相隔 N 周期的两边沿的相对变化**——这正是下一节的 N 周期抖动。

### 2.1.4 N 周期抖动（N-Period Jitter）

比较一个边沿与**同时钟第 N 个之前的边沿**的位置（示波器触发后观察后面第 N 个边沿的摆动）：

$$p_k(N) := (t_{k+N} - t_k) - NT \tag{2.10}$$

注意 $t_{k+N}-t_k$ 就是 N 个连续周期的总时长，故也可写成

$$p_k(N) = \sum_{i=k}^{k+N-1} T_i - NT \tag{2.11}$$

加减 $(k+N)T$ 得与绝对抖动的关系：

$$p_k(N) = a_{k+N} - a_k \tag{2.12}$$

而由式 (2.11) 与式 (2.8) 可得重要关系——**N 周期抖动 = N 个连续周期抖动之和**：

$$p_k(N) = \sum_{i=k}^{k+N-1}(T_i - T) = \sum_{i=k}^{k+N-1} p_i \tag{2.13}$$

> [!note]
> - $N=1$ 时 N 周期抖动退化为周期抖动。
> - 文献中也称 **accumulated jitter**（累积抖动），因它来自连续周期抖动的累加；本书用 N-period jitter。
> - 记号上 N 可替换为具体数字或符号，如 5-period jitter、m-period jitter。

### 2.1.5 其他常见抖动定义

#### TE 与 TIE（ITU-T G.810 标准）

国际电信联盟 G.810 建议对式 (2.2) 形式的时钟定义**时间函数** $T(t) := \phi(t)/(2\pi f_0)$（总相位 $\phi(t)=2\pi f_0 t+\varphi(t)$ 除以角频率），参考时钟类似定义 $T_{ref}(t)$（理想参考时 $T_{ref}(t)=t$）。

**时间误差**（Time Error, TE）：

$$TE(t) := T(t) - T_{ref}(t) \tag{2.14}$$

容易证明：在被测时钟第 k 个边沿处，**TE 就是绝对抖动**：

$$TE(t)\big|_{t=t_k} = a_k \tag{2.15}$$

**时间区间误差**（Time Interval Error, TIE）：用被测时钟（相对参考时钟）测量时长 $\tau$ 的准确度：

$$TIE(t,\tau) := \big[T(t+\tau)-T(t)\big] - \big[T_{ref}(t+\tau)-T_{ref}(t)\big] \tag{2.16}$$

可证 $TIE(t,\tau)=TE(t+\tau)-TE(t)$；若 t 与 $t+\tau$ 分别对应第 k 与第 k+N 个边沿，则

$$TIE(t,\tau) = a_{k+N} - a_k = p_k(N) \tag{2.17}$$

即 **TIE 就是 N 周期抖动**，N 为 $\tau$ 内包含的时钟周期数。

**最大时间区间误差**（MTIE，ITU-T 与 ANSI 均采用）：给定区间 $\tau$ 上 TE 的最大峰峰值：

$$MTIE(\tau) := \max_{t\le t_1\le t+\tau} TE(t_1) - \min_{t\le t_1\le t+\tau} TE(t_1) \tag{2.18}$$

即被测时钟在 $[t,\,t+\tau]$ 内的**峰峰值绝对抖动**。

> [!warning] MTIE 的名字有迷惑性
> MTIE(τ) 并不一定等于该区间内的最大 TIE（书图 2.5 给出反例）。它度量的是 TE 曲线在窗内的最大起伏。

#### Cycle-to-Cycle 抖动（JEDEC JESD65B）

相邻两个周期之差：

$$cc_k := T_{k+1} - T_k \tag{2.19}$$

用周期抖动、绝对抖动表示：

$$cc_k = p_{k+1} - p_k \tag{2.20}$$

$$cc_k = a_{k+2} - 2a_{k+1} + a_k \tag{2.21}$$

> [!example] 为什么 SSC 用 cycle-to-cycle 抖动表征？
> 三角调制的扩频时钟：频率随时间是斜坡 → 过剩相位（及绝对抖动）是频率的积分，呈 $t^2$ 型；周期抖动是绝对抖动的一阶差分，随 t 线性变化；cycle-to-cycle 抖动再差分一次，在整条斜坡上是**常数**。因此它比其他定义更适合考察 SSC 的短期抖动。
>
> 注意：JESD65B 发布前，有文献把 cycle-to-cycle 用作周期抖动的同义词；有的场合也称 adjacent period jitter。使用前务必确认语境。

#### 其他术语速览

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| 长期抖动（long-term jitter） | N 很大时的 N 周期抖动 | 未标准化。PLL 的 N 周期抖动随 N 增大后趋于饱和（原因见 3.2.2 节）；自由振荡器则随 N 无限增长，谈"长期"无意义。N 多大算"长期"取决于应用（如视频系统约一行像素数） |
| 短期抖动（short-term jitter） | 有文献指 cycle-to-cycle，有文献指周期抖动 | 未标准化且含义冲突，**慎用** |
| 相位抖动 / 积分抖动（phase-jitter / integrated jitter） | 绝对抖动功率谱在某个**给定频率区间**内的 RMS 值 | 由对相位噪声积分得到，详见 3.1.5 节 |
| adjacent period jitter | 即 cycle-to-cycle 抖动 | 非标准术语 |
| cycle jitter | 即周期抖动 | 非标准术语 |
| 孔径抖动（aperture jitter） | ADC 采样保持电路中，开关断开采样电容所需"孔径时间"的不确定性 | 不直接作用于时钟/数据，但等效于采样时钟上的抖动，见第 6 章 |

### 2.1.6 基本定义与关系汇总

**基本抖动定义（对照表）**：

| 抖动 | 符号 | 定义 | 用边沿时刻表示 |
| --- | --- | --- | --- |
| 绝对抖动 | $a_k$ | 时钟边沿位置相对理想位置的偏差 | $t_k - kT$ |
| 相对抖动 | $r_k$ | 两个时钟（A、B）对应边沿位置之差 | $t_k^A - t_k^B$ |
| 周期抖动 | $p_k$ | 时钟周期相对标称值的偏差 | $t_{k+1} - t_k - T$ |
| N 周期抖动 | $p_k(N)$ | N 个连续周期总时长相对标称值的偏差 | $t_{k+N} - t_k - NT$ |
| cycle-to-cycle | $cc_k$ | 相邻两个时钟周期之差 | $t_{k+2} - 2t_{k+1} + t_k$ |

**相互关系（以绝对抖动、周期抖动为基准）**：

| 抖动 | 用绝对抖动表示 | 用周期抖动表示 |
| --- | --- | --- |
| $a_k$ | — | 不适用 |
| $r_k$ | $a_k^A - a_k^B$ | 不适用 |
| $p_k$ | $a_{k+1} - a_k$ | — |
| $p_k(N)$ | $a_{k+N} - a_k$ | $\sum_{i=k}^{k+N-1} p_i$ |
| $cc_k$ | $a_{k+2} - 2a_{k+1} + a_k$ | $p_{k+1} - p_k$ |

## 2.2 抖动的统计

无论哪种定义，抖动都是**离散时间随机过程** $j_k$（k 为边沿序号）。同一只时钟在不同时刻测得的抖动序列（同一过程的不同**实现**）各不相同。因此需要把整个过程压缩成少数几个对任意实现都有效的导出量。两条互补路线：

| | 频域路线 | 统计路线 |
| --- | --- | --- |
| 工具 | 自相关函数的傅里叶变换 → 频谱 | 幅度的直方图 / PDF |
| 能揭示 | 序列随时间的演化（如正弦分量在谱上表现为强谱线） | 罕见离群事件（outlier） |
| 盲区 | 极罕见事件对谱几乎无影响，检测不到 | 丢失样本的顺序信息：两个时间行为完全不同的序列可以有相同直方图 |

> [!important]
> 两条路线谁也无法替代谁，**只有两者结合才是抖动过程的完整画像**。本章讲统计路线，第 3 章讲频域路线。

### 2.2.1 直方图与概率密度函数（PDF）

**直方图**：对过程 $j_k$ 采 n 个样本，把幅度轴等分为若干 bin，统计落入各 bin 的样本数（occurrence），画成条形图。它能直观暴露分布特征（书中例：1 万个样本、1 ps bin 宽的直方图显示分布既非高斯也不对称、有两个鼓包、左侧远处还有罕见事件）。

**PDF**（概率密度函数）：连续随机变量 x 的 PDF $f_x$ 满足

$$P[a < x < b] = \int_a^b f_x(c)\,dc \tag{2.22}$$

故 PDF 非负、全轴积分为 1。

> [!important] 直方图 ≠ PDF（遍历性假设）
> - **直方图**：同一**实现**沿时间的大量样本的统计（一个时间点只记一个值）——"一次实现 × 所有时刻"的性质。
> - **PDF**：在**某一时刻**、对**所有可能实现**（ensemble）取值的分布——"一个时刻 × 所有实现"的性质。
>
> 默认两者等价（时间平均 = 集平均）的过程称为**遍历的**（ergodic），是平稳过程的子集。抖动涉及的大多数过程可视为遍历，因此可用直方图推断 PDF。

**由直方图得到 PDF**：设直方图有 m 个 bin、宽度 $\Delta t$、中心 $t_i$、计数 $h_j(t_i)$，总样本数 n，则

$$\sum_{i=1}^{m} h_j(t_i) = n \tag{2.23}$$

把直方图按 $1/(n\Delta t)$ 缩放：

$$f_j(t_i) := \frac{h_j(t_i)}{n\,\Delta t} \tag{2.24}$$

于是其离散积分为 1，即得到 PDF：

$$\sum_{i=1}^{m} f_j(t_i)\,\Delta t = 1 \tag{2.25}$$

直方图到 PDF 只是 y 轴缩放，形状不变。由于抖动幅度在 ps（$10^{-12}$ s）量级，PDF 纵轴数值在 $10^{12}$ 量级。

**四种典型抖动 PDF**（各有"签名"形状，反之同一 PDF 形状可对应很不相同的时域序列——遍历性成立时形状才有强提示作用）：

| 分布 | PDF 表达式 | 适用情形 |
| --- | --- | --- |
| 高斯 | $f_j(t)=\dfrac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\dfrac{(t-\mu)^2}{2\sigma^2}\right)$ (2.26) | 热噪声等随机抖动 |
| 均匀 | $f_j(t)=\dfrac{1}{B-A}$，$A\le t\le B$ (2.27) | 有界确定性抖动 |
| 正弦 | $f_j(t)=\dfrac{1}{\pi A}\,\dfrac{1}{\sqrt{1-\big((t-\mu)/A\big)^2}}$，$\mu-A\le t\le\mu+A$ (2.28) | 正弦调制抖动（两端呈浴缸状凸起） |
| Dirac | $f_j(t)=\sum_{i=1}^{m}A_i\,\delta(t-t_i)$，$\sum_i A_i=1$ (2.29) | 抖动集中于若干离散值的抽象；只有两个值的 **Dual Dirac** 在抖动分解中起核心作用 |

实际电路中多种机制同时起作用，合成 PDF 形状更复杂（2.2.7 节讲组合规则）。

### 2.2.2 均值（Mean）

多数抖动定义下均值**天然为零**：周期抖动若均值非零，说明标称周期 T 算错了；绝对抖动正确提取后均值也应为零。例外：相对抖动——两时钟间存在固定 skew 时，均值就等于该 skew。

n 个样本的**样本均值**估计：

$$\hat{\mu}_j = \frac{1}{n}\sum_{k=1}^{n} j_k \tag{2.30}$$

### 2.2.3 中位数（Median）

中位数 j̄ 定义为抖动样本各以 50% 概率落于其两侧的值：

$$P[j_k < \bar{j}] = P[j_k > \bar{j}] = 0.5 \tag{2.31}$$

PDF 对称时中位数 = 均值；PDF 有偏斜（一侧尾巴更长）时两者不同。

> [!example] 中位数的实际意义：bang-bang CDR
> 采用**二进制（bang-bang）鉴相器**的 CDR / PLL，环路锁定在数据与反馈时钟之间**相对抖动的中位数**附近，而非均值。若相对抖动分布很不对称，锁定点的偏移会显著压缩眼图，超出按均值预期的程度。

### 2.2.4 标准差与方差（RMS）

**RMS 值 = 标准差** $\sigma$，是方差 $\sigma^2$ 的平方根，衡量抖动在均值附近的散布宽度。它是高斯分布的核心参数，但对任意分布都可计算。

n 个样本的**样本方差**估计：

$$\hat{\sigma}_j^2 = \frac{1}{n-1}\sum_{k=1}^{n}\left(j_k - \mu_j\right)^2 \tag{2.32}$$

### 2.2.5 峰值与峰峰值（Peak and Peak-Peak）

许多应用关心的是抖动的**极端值**而非 RMS。例：同步数字电路要求"最短时钟周期仍够组合逻辑完成工作"，需刻画的是周期抖动的最大值（第 5 章详述）。

> [!warning] 裸峰值没有意义
> 热噪声是高斯的、**无界**：测 100 个样本得到一个峰峰值范围，测 1000 个样本范围几乎必然更大。因此峰值 / 峰峰值必须附带"如何测得"的说明才有意义。

**方法一：样本极值法**（不假设分布形状）。取 n 个样本：

$$\rho_j^+ := \max_k(j_k) - \mu_j \tag{2.33}$$

$$\rho_j^- := \mu_j - \min_k(j_k) \tag{2.34}$$

$$\rho\rho_j := \max_k(j_k) - \min_k(j_k) \tag{2.35}$$

分布不对称时需区分正峰值 $\rho^+$ 与负峰值 $\rho^-$。两个缺点：
- 样本超出峰值边界的概率大致**反比于样本量**（9.2.3 节）；要支撑 $10^{-12}$ 量级的指标，需要采集处理海量数据；
- 基于最大/最小值的统计**最不鲁棒**——单个离群点（一次测量毛刺）就能毁掉结果，数据必须先彻底清洗。

**方法二：高斯假设法**。若有理由相信抖动（近似）高斯，则"偏离均值超过 Q 倍 RMS"的概率是确定的（计算见 9.2 节，$P(Q)$ 数值见表 9.1）。定义：

$$\rho_j := Q\cdot\sigma_j \tag{2.36}$$

$$\rho\rho_j := 2Q\cdot\sigma_j \tag{2.37}$$

样本落在峰值、峰峰值范围外的概率分别为 $P(Q)$ 与 $2P(Q)$。此法无需海量数据即可外推极低概率处的峰值，且少量离群点对 RMS 估计影响很小。

**非高斯怎么办？** 真实抖动常非高斯，用 RMS 配高斯近似去外推尾部概率会出错（书中例：某真实分布 RMS=2.204 ps，同 RMS 的高斯曲线给出的"样本大于 x 的概率"与真实曲线明显不符）。解决之道是基于确定性抖动知识的方法学——即下面的 RJ/DJ 分类与抖动分解。

### 2.2.6 基于 PDF 的抖动分类（RJ / DJ 体系）

复杂系统中的抖动是多种机制各自的抖动分量叠加的结果（例：有线接收端数据抖动 = 发送 PLL 抖动 + 驱动器热噪声抖动 + 信道带宽限制造成的边沿畸变 + ……）。一个常见错误观念是"抖动本质上只是随机的"——实际上抖动既可随机也可确定。类比调幅信号：DJ 相当于"水平方向"的失真/串扰，RJ 相当于经典的垂直方向高斯幅度噪声。

> [!important] 顶层二分法
> 按 PDF 形状，一切抖动分量（无论哪种抖动定义）分属两类：
> - **随机抖动 RJ**：PDF **无界**（样本越多范围越大），源于器件电子噪声（热噪声、闪烁噪声、散粒噪声），呈**高斯分布**；
> - **确定性抖动 DJ**：PDF **有界**，成因包括电源噪声调制、串扰、占空比失真、信道带宽限制等。

**DJ 的子类**：

| 子类 | 全称 | 成因 / 特征 |
| --- | --- | --- |
| DDJ | 数据相关抖动（data-dependent jitter） | 串行数据特有，与发送数据图案**相关**（如 ISI） |
| DCD | 占空比失真抖动（duty-cycle distortion） | 应用中同时使用时钟上升沿与下降沿时，占空比不对称所致 |
| BUJ | 有界不相关抖动（bounded-uncorrelated jitter） | 有界但与数据**不相关**，如邻信道串扰；可细分为周期性（PJ）与非周期性 |
| SJ | 正弦抖动（sinusoidal jitter） | 正弦剖面，常用于高速接口抖动容限测试 |

串行数据场合还可按与发送数据的关系分为**相关**与**不相关**抖动。子类命名未完全标准化，不同作者用词不同，但根本区分始终是：**RJ 无界且高斯；DJ 有界且形状各异**。

> [!warning] RJ、DJ 也用作"数值"，且各家约定不同
> - **RJ 作为数值**：本书采用较流行的约定——RJ = RMS × 与 BER 挂钩的因子（BER=$10^{-12}$ 时因子为 14）。例：高斯抖动 RMS = 1 ps 的时钟，在目标误码概率 $10^{-12}$ 下称其 RJ = 14 ps。注意 Serial-ATA 用此约定，而 **PCIe 直接用 RMS 本身**作 RJ，阅读规范时务必留意。
> - **DJ 作为数值**：指该分量的**峰峰值**。例：幅度 1 ps 的正弦调制抖动 → DJ = 2 ps。

### 2.2.7 抖动分量的组合

多数情况下，各机制新引入的抖动与已有抖动无关，总抖动是各分量之**和**：

$$j_k = j_{1,k} + j_{2,k} + \cdots + j_{n,k} \tag{2.38}$$

（该独立性假设并非永远成立，但大多数场合有效。）

各分量独立时，概率论基本结论：**总抖动的 PDF = 各分量 PDF 的卷积**：

$$f_j(t) = f_{j1}(t) * f_{j2}(t) * \cdots * f_{jn}(t) \tag{2.39}$$

> [!note] 卷积对 PDF 形状的影响（书图 2.14 的要点）
> 高斯（RMS=0.2）分别与峰峰值均为 2 的 dual-Dirac、正弦、均匀、三角 DJ 卷积：
> - 卷积**抹平** DJ 分布的硬边界；
> - 合成分布的峰（或最高处）位置**不向 DJ 极端值对齐，而是内移**——DJ 越"中间鼓"（如三角）内移越明显；唯一例外是理想 dual-Dirac；
> - 因此**无法靠肉眼从合成 PDF 直接读出 DJ 大小**。
>
> 再由中心极限定理：多个 DJ 分量之和趋向高斯形（仅尾巴有界）；再与高斯 RJ 卷积（高斯⊗高斯仍为高斯），总分布看起来几乎就是高斯——目视分解彻底不可能，必须借助 2.2.8 节的算法。

**组合规则**（各分量不相关时）：

- **RJ 按平方和（quadratically）相加**——不相关高斯变量之和仍为高斯，方差相加：

$$\sigma^2_{total} = \sigma^2_{j1} + \sigma^2_{j2} + \cdots + \sigma^2_{jn} \tag{2.40}$$

- **DJ 按线性（linearly）相加**——有界函数卷积后的范围等于各范围之和：

$$DJ_{total} = DJ_{j1} + DJ_{j2} + \cdots + DJ_{jn} \tag{2.41}$$

> [!warning] 式 (2.41) 只是上界
> DJ 分量间有强相关时线性相加不再成立。例：两级缓冲器分别接两个受正弦噪声污染的电源，两噪声同频但相位差 90°——第一级噪声最大时第二级恰好为零，输出 DJ 明显小于两级各自 DJ 之和。一般而言相关 DJ 的总范围**小于（至多等于）**各分量范围之和，故式 (2.41) 可作最坏情况上界；但若因此设计得过于保守，需对 DJ 来源及其相关性做更深入分析。RJ 分量源于彼此天然不相关的热噪声过程，式 (2.40) 的估计通常很好。

### 2.2.8 抖动分解（Jitter Decomposition）

目的：从非高斯的总抖动 PDF 中分离出 RJ 与 DJ，进而得到有意义的统计参数。两种主流方法：

1. **独立 σ 法（independent-σ）**：在频域测量时钟的**相位噪声**以提取 RJ 的 RMS（原理见第 3 章），然后通过反卷积、或用"σ 固定为该 RJ、均值可变"的高斯曲线拟合分布尾部来提取 DJ。
2. **尾部拟合法（tail fitting）**：更流行。总 PDF = 有界 DJ ⊗ 高斯 RJ，因此在远离 DJ 边界的深处，分布**尾部仍非常接近高斯形**。于是用参数化高斯曲线分别拟合左、右尾，参数为均值 μ、RMS σ 和**幅度 A**（A 是乘在标准高斯 PDF 前的因子，因为单侧尾部曲线只占整个 PDF 的一部分，面积小于 1）。

> [!note] 简化版 vs 完整版
> - 简化版固定 A = 1：算法简单，但**低估 DJ、高估 RJ**，误码概率预测不准；
> - 完整版把 A 也作为优化参数：共 6 个参数 $(A_L, \sigma_L, \mu_L)$、$(A_R, \sigma_R, \mu_R)$。对真实电子系统，$\sigma_L$ 与 $\sigma_R$ 通常收敛到同一数值。
>
> 尾部拟合只关注分布**两端**的行为、不去精确描述 DJ 主导的中央部分——对绝大多数应用这不是缺陷，因为决定误码的恰恰是尾部。

本质上，尾部拟合对原 PDF 施加了一个 **Dual-Dirac 模型**：用"高斯抖动 ⊗ 双 Dirac 抖动"来近似原分布，两个 Dirac 冲激位于 $\mu_L$、$\mu_R$，幅度 $A_L$、$A_R$。

> [!warning] 工程难点
> 拟合区间必须取得足够靠外，以免受 DJ 影响而错误估计 RJ 参数；但越靠外直方图计数越少、离群点影响越大，可靠鲁棒的拟合非常困难。过去十年发展了多种改进算法，基本思路涉及 Q-scale 与归一化 Q-scale（10.4 节概述），详见文献 [15–23]。

### 2.2.9 总抖动与误码概率（Total Jitter & Dual-Dirac 模型）

基于尾部拟合得到的参数，对任意抖动分布定义左峰、右峰与峰峰值：

$$\rho^- = \mu_L - Q\cdot\sigma_L \tag{2.42}$$

$$\rho^+ = \mu_R + Q\cdot\sigma_R \tag{2.43}$$

$$\rho\rho = \mu_R - \mu_L + Q\left(\sigma_R + \sigma_L\right) \tag{2.44}$$

Q 是决定"样本落在峰界之外"概率的因子。由于拟合高斯带有权重 $A_L$、$A_R$，超出各界限的概率为：

$$P[j_k > \rho^+] = A_R\cdot P(Q) \tag{2.45}$$

$$P[j_k < \rho^-] = A_L\cdot P(Q) \tag{2.46}$$

$$P[j_k\ \text{在}\ \rho\rho\ \text{之外}] = \left(A_R + A_L\right)\cdot P(Q) \tag{2.47}$$

其中 $P(Q)$ 由高斯尾部积分给出（式 9.14，数值查表 9.1）。

式 (2.44) 中 $\mu_R - \mu_L$ 刻画 DJ 的贡献，称为 **Dual-Dirac DJ**，记作 $DJ_{\delta\delta}$（或 $DJ_{dd}$）：

$$DJ_{\delta\delta} := \mu_R - \mu_L \tag{2.48}$$

$Q(\sigma_R+\sigma_L)$ 刻画随机部分，即 RJ（注意 RJ 依赖于所选 Q）。抖动分解语境下峰峰值 $\rho\rho$ 称为**总抖动 TJ**：

$$\boxed{TJ = DJ_{\delta\delta} + RJ(Q)} \tag{2.49}$$

> [!important] TJ 必须附带概率水平
> 不说明所依据的概率水平（或 Q 因子）的 TJ 数值**毫无意义**。任何 TJ 指标都必须同时给出其对应的误码/越界概率。

> [!example] 书中 Example 1（图 2.15 的数值）
> 尾部拟合得 $\mu_R=1.9$ ps、$\mu_L=-3.4$ ps、$\sigma_L=\sigma_R=1$ ps、$A_L=0.45$、$A_R=0.19$。
> - $DJ_{\delta\delta} = 1.9-(-3.4) = 5.3$ ps；
> - 取 Q = 7：RJ = 7×(1+1) = 14 ps；$\rho^+ = 1.9+7 = 8.9$ ps，$\rho^- = -3.4-7 = -10.4$ ps；**TJ = 19.3 ps**，对应越界概率 $(0.19+0.45)\times1.28\times10^{-12} = 0.82\times10^{-12}$；
> - 若取 Q = 3：RJ = 6 ps，TJ 只有 11.3 ps——数值小得多，但对应概率仅 $0.86\times10^{-3}$。
>
> 教训：同一抖动，Q 不同 TJ 天差地别，比较 TJ 必先对齐概率水平。

> [!note] 为什么要发明 $DJ_{\delta\delta}$，直接用 DJ 不行吗？
> 两者很少相等。$DJ_{\delta\delta}$ 是从尾部拟合算法纯数学地导出的抽象量（两条拟合高斯中心之距），并不代表系统中某个真实抖动分量。由于 RJ 与 DJ 卷积使合成分布的"拐点"相对 DJ 峰值**内移**，拟合算法提取的 DJ 系统性偏小（优化 A 的算法更准确，但仍偏小）。因此恒有 $DJ_{\delta\delta} \le DJ$，等号基本只在真实 DJ 恰好是完美 dual-Dirac 时成立。在式 (2.49) 中误用 DJ 代替 $DJ_{\delta\delta}$ 会得到错误的 TJ。

## 关键公式速查

| 名称 | 公式 | 说明 |
| --- | --- | --- |
| 绝对抖动 | $a_k = t_k - kT$ | 边沿时刻相对理想时钟的偏差 |
| 相对抖动 | $r_k = a_k^{A} - a_k^{B}$ | 两时钟对应边沿之差 |
| 周期抖动 | $p_k = a_{k+1} - a_k$ | 实际周期 − 标称周期 |
| N 周期抖动 | $p_k(N) = a_{k+N} - a_k = \sum_{i=k}^{k+N-1} p_i$ | 周期抖动的 N 项累加（= TIE） |
| cycle-to-cycle | $cc_k = a_{k+2} - 2a_{k+1} + a_k = p_{k+1} - p_k$ | 相邻周期之差 |
| 样本均值 / 方差 | $\hat\mu_j=\frac1n\sum j_k$；$\hat\sigma_j^2=\frac{1}{n-1}\sum (j_k-\mu_j)^2$ | 式 (2.30)、(2.32) |
| 高斯峰值近似 | $\rho = Q\sigma$，$\rho\rho = 2Q\sigma$ | 越界概率 $P(Q)$、$2P(Q)$ |
| 分量组合 | $f_j = f_{j1} * \cdots * f_{jn}$ | 独立分量 PDF 卷积 |
| RJ 合成 | $\sigma^2_{total} = \sum_i \sigma^2_{ji}$ | 平方相加 |
| DJ 合成 | $DJ_{total} = \sum_i DJ_{ji}$ | 线性相加（上界） |
| Dual-Dirac DJ | $DJ_{\delta\delta} = \mu_R - \mu_L$ | 尾部拟合两高斯中心间距，$\le DJ$ |
| 总抖动 | $TJ = DJ_{\delta\delta} + RJ(Q)$ | 必须注明概率水平 / Q |

## 要点总结

1. 抖动定义应**按测量方式**给出：与他钟比（绝对、相对）或与自钟先前边沿比（周期、N 周期）——四个基本定义可导出文献中几乎所有其他定义。
2. 过剩相位 $\varphi(t)$ 是抖动的载体；幅度噪声 $A(t)$ 只要不过零就不影响时钟定时。
3. 换算关系核心两条：$p_k = a_{k+1}-a_k$（差分）与 $p_k(N)=\sum p_i$（累加）；TIE = N 周期抖动，MTIE = 窗内峰峰值绝对抖动。
4. 抖动的完整刻画需要**频域（谱）+ 统计（PDF）**双视角：谱看不见离群点，直方图丢失时间顺序。
5. 直方图是"一次实现 × 所有时刻"，PDF 是"一个时刻 × 所有实现"，两者互通依赖**遍历性**假设。
6. bang-bang 鉴相的 CDR/PLL 锁定在相对抖动的**中位数**而非均值——分布不对称时锁定点偏移会额外压缩眼图。
7. 无界高斯抖动的裸峰值无意义：必须说明样本量（极值法）或 Q 因子（高斯外推法）。
8. 一切抖动分量按 PDF 有界性二分：**RJ 无界高斯**（器件噪声）、**DJ 有界**（DCD、DDJ/ISI、BUJ/PJ、SJ 等）；组合时 **RJ 平方相加、DJ 线性相加（上界）**。
9. 非高斯分布靠**尾部拟合**做抖动分解，其数学本质是 dual-Dirac 模型；拟合只需关注决定误码的分布尾部。
10. **TJ = DJ$_{\delta\delta}$ + RJ(Q)**：$DJ_{\delta\delta}$ 恒不大于真实 DJ；脱离概率水平谈 TJ 没有意义。
