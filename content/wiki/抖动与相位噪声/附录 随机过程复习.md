# 附录 A 随机变量与随机过程复习（Review of Random Variables and Processes）

> [!abstract] 章节概览
> 本附录是全书的**数学基础速查手册**，以极紧凑的形式回顾理解抖动与相位噪声所需的随机变量与随机过程概念。目的不是系统讲授，而是帮助读者回忆定义与含义——假定读者已学过概率论基础，最好接触过研究生级别的随机过程课程。
>
> 与本书主题的关联：抖动是**离散时间随机过程**，过剩相位是**连续时间随机过程**；相位噪声 $\mathcal{L}(f)$ 本质是过剩相位的**功率谱密度**（PSD）；Wiener–Khinchin 定理、宽平稳性、遍历性是第 3 章全部时频转换关系的理论地基。配套仿真实践见 [数值方法与Matlab仿真](数值方法与Matlab仿真.md)。

## A.1 随机变量（Random Variables）

### A.1.1 定义

随机变量 $X$ 是把实验的每个可能结果映射为一个实数的**函数**。成为随机变量的前提条件：对任意实数 $a$，满足 $X \leq a$ 的结果集合都有**良好定义的概率**。

> [!example] 掷骰子
> 实验结果为骰子的六个面，规则"第 $i$ 面 ↔ 整数 $i$"定义了取值为 $1 \dots 6$ 的函数 $X$。对任意实数 $a$（如 $a = 3.4567$ 或 $a = -1$），$P[X \leq a]$ 都明确（分别为 $3/6$ 与 $0$），故 $X$ 是随机变量。

> [!note] "随机变量"其实名不副实
> 它指的是**函数**而非变量；"随机性"属于底层的实验结果，而非函数返回值。工程中实验结果往往本身就是数（如某时刻的噪声电压），映射步骤被省略，于是直接把实验的数值结果称作随机变量。

按取值性质分类：**离散**随机变量只取一组离散实数值；**连续**随机变量可在实轴的连续区间上取任意值。

### A.1.2 分布函数与密度函数

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 累积分布函数（CDF） | $F_X(a) := P[X \leq a]$ | 单调不减；$F_X(-\infty)=0$，$F_X(+\infty)=1$；常简称"分布函数" |
| 概率密度函数（PDF） | $f_X(a) := \dfrac{\partial F_X(a)}{\partial a}$ | 等于"$X$ 落在 $a$ 附近小区间 $\Delta$ 内的概率除以 $\Delta$"在 $\Delta \to 0$ 时的极限 |
| 区间概率 | $P[a_1 < X \leq a_2] = F_X(a_2) - F_X(a_1) = \displaystyle\int_{a_1}^{a_2} f_X(v)\,dv$ | PDF 非负、定义于全实轴、总积分为 1 |

连续随机变量：CDF 与 PDF 都是连续函数。离散随机变量：CDF 为阶梯递增函数，PDF 由 **Dirac 冲激**组成，各冲激面积等于取该值的概率。

### A.1.3 期望（Expectation）

期望是随机变量的**概率加权平均**。

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 离散情形 | $E[X] := \sum_{i=1}^{N} a_i\,P[X = a_i]$ | $X$ 取 $N$ 个不同值 |
| 连续情形 | $E[X] := \displaystyle\int_{-\infty}^{+\infty} a\,f_X(a)\,da$ | |
| 线性性 | $E[aX + bY] = aE[X] + bE[Y]$ | 期望最重要的性质，**不要求独立** |
| 期望基本定理 | $E[g(X)] = \displaystyle\int_{-\infty}^{+\infty} g(a)\,f_X(a)\,da$（离散版：$\sum_i g(a_i)P[X=a_i]$） | 求 $Y=g(X)$ 的期望无需先求 $f_Y$ |
| 特征函数 | $\Phi_X(\omega) := E\!\left[e^{j\omega X}\right] = \displaystyle\int_{-\infty}^{+\infty} e^{j\omega a} f_X(a)\,da$ | 即 PDF 的傅里叶变换的**复共轭** |

### A.1.4 均值、方差与高阶矩

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 均值 | $\mu_X := E[X]$ | PDF"中心"的度量 |
| 方差 | $\sigma_X^2 := E\!\left[(X-\mu_X)^2\right]$ | PDF 围绕中心散布程度的度量 |
| 方差计算式 | $\sigma_X^2 = E[X^2] - \mu_X^2$ | 零均值时方差 = 二阶矩 $E[X^2]$ |
| 标准差 | $\sigma_X = \sqrt{\sigma_X^2}$ | |
| $n$ 阶矩 | $E[X^n]$ | |
| $n$ 阶中心矩 | $E[(X-\mu_X)^n]$ | |
| 特征函数求矩 | $E[X^n] = \dfrac{1}{j^n}\left.\dfrac{\partial^n \Phi_X(\omega)}{\partial \omega^n}\right|_{\omega=0}$ | 逐次微分即得各阶矩 |

### A.1.5 两个随机变量

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 联合 CDF | $F_{XY}(a,b) := P[X \leq a \;\mathrm{and}\; Y \leq b]$ | |
| 联合 PDF | $f_{XY}(a,b) := \dfrac{\partial^2 F_{XY}(a,b)}{\partial a\,\partial b}$ | 反演：$F_{XY}(a,b)=\displaystyle\int_{-\infty}^{a}\!\!\int_{-\infty}^{b} f_{XY}(v,w)\,dv\,dw$ |
| 区域概率 | $P[(X,Y)\in D] = \displaystyle\iint_D f_{XY}(v,w)\,dv\,dw$ | $D$ 为二维平面区域 |
| 边缘化 | $F_X(a) = F_{XY}(a,+\infty)$；$f_X(a) = \displaystyle\int_{-\infty}^{+\infty} f_{XY}(a,b)\,db$ | 由联合分布恢复单变量分布 |

### A.1.6 独立随机变量

若对任意两个事件 $A$、$B$ 都有

$$
P[X\in A \;\mathrm{and}\; Y\in B] = P[X\in A]\cdot P[Y\in B]
$$

则称 $X$ 与 $Y$ **独立**（independent）。等价地，联合分布可分解为各自分布的乘积：

$$
F_{XY}(a,b) = F_X(a)\,F_Y(b),\qquad f_{XY}(a,b) = f_X(a)\,f_Y(b)
$$

### A.1.7 两个随机变量函数的期望

$Z = g(X,Y)$ 的期望可直接由联合 PDF 计算（期望基本定理的二维版），无需先求 $Z$ 的分布：

$$
E[g(X,Y)] = \int_{-\infty}^{+\infty}\!\!\int_{-\infty}^{+\infty} g(a,b)\,f_{XY}(a,b)\,da\,db
$$

### A.1.8 相关与协方差（Correlation and Covariance）

二者度量两个随机变量的**相互依赖程度**。

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 相关 | $R_{XY} := E[XY]$ | |
| 协方差 | $C_{XY} := E[(X-\mu_X)(Y-\mu_Y)]$ | |
| 二者关系 | $C_{XY} = R_{XY} - \mu_X\mu_Y$ | |
| 相关系数 | $\rho_{XY} := \dfrac{C_{XY}}{\sigma_X\sigma_Y}$ | 恒有 $|\rho_{XY}| \leq 1$ |
| 不相关（uncorrelated） | $C_{XY}=0$，即 $E[XY]=E[X]\,E[Y]$ | |
| 正交（orthogonal） | $E[XY]=0$，即 $R_{XY}=0$ | |

> [!important] 三个概念的关系
> **独立 ⇒ 不相关**，反之一般不成立（不相关只排除线性依赖）。零均值时"不相关"与"正交"等价。第 10 章生成复杂相位噪声轮廓时，正是利用独立随机源之间不相关，使各抖动分量的 PSD 可以直接相加。

## A.2 随机过程（Random Processes）

### A.2.1 定义

随机变量把实验结果映射为数；**随机过程**把实验结果映射为**时间函数** $x(t)$。由于实验可有多个（甚至不可数多个）结果，随机过程定义了一**族**时间函数（各次实现，realizations）。

工程与物理中许多实验结果本身就是时间函数——布朗运动粒子的位置、电阻噪声电压、放射性物质累计发射粒子数、排队人数——因此习惯上直接把"实验结果随时间的演化"称为随机过程。

> [!note] 固定 $t$ 时，$x(t)$ 退化为一个随机变量，即过程在该时刻的"状态"。这是把随机变量理论延伸到随机过程的接口。

### A.2.2 分类

按 $t$ 的性质与 $x(t)$ 取值的性质两维划分：

| 维度 | 类别 | 含义 |
| --- | --- | --- |
| 时间 | 连续时间 | $t$ 取全实轴 |
| | 离散时间 | $t$ 只取整数值，常记作 $x_n$ |
| 状态 | 离散状态 | $x(t)$ 只取可数个值 |
| | 连续状态 | $x(t)$ 取连续区间内的任意值 |

> [!example] 与本书主题的对照
> 放射性物质累计粒子数 = 连续时间、离散状态；反复掷骰 = 离散时间、离散状态；**时钟上的抖动 = 离散时间、连续状态**；**过剩相位 = 连续时间、连续状态**。

### A.2.3 均值、自相关与自协方差

| 概念 | 定义/公式 | 备注 |
| --- | --- | --- |
| 均值 | $\mu_x(t) := E[x(t)]$ | 时间的函数，可视为过程的"平均波形" |
| 自相关 | $R_x(t_1,t_2) := E[x(t_1)x(t_2)]$ | $R_x(t,t) = E[x(t)^2]$ 为平均功率（$x(t)$ 的二阶矩）；零均值时即方差 |
| 自协方差 | $C_x(t_1,t_2) := E[(x(t_1)-\mu_x(t_1))(x(t_2)-\mu_x(t_2))]$ | $C_x(t,t)$ 为 $x(t)$ 的方差 |
| 二者关系 | $C_x(t_1,t_2) = R_x(t_1,t_2) - \mu_x(t_1)\mu_x(t_2)$ | 零均值过程二者相同 |
| 滞后变量形式 | $R_x(t,\tau) := E[x(t+\tau)x(t)]$，$\tau = t_2 - t_1$ | 更实用的写法 |

### A.2.4 平稳过程（Stationary Processes）

| 概念 | 定义 | 备注 |
| --- | --- | --- |
| 严格平稳（strict-sense stationary） | 全部统计性质对时间轴平移不变：$x(t+u)$ 与 $x(t)$ 统计相同，任意 $u$ | 环境条件不变时自然界常见（无限次掷骰、恒温电阻噪声） |
| 宽平稳（wide-sense stationary, WSS） | 仅均值与自相关对平移不变：$\mu_x(t+u)=\mu_x(t)$，$R_x(t_1,t_2)=R_x(t_1+u,t_2+u)$ | 严格平稳 ⇒ 宽平稳，反之不然 |

> [!important] 宽平稳过程的简化
> 均值为常数 $\mu_x(t) = \mu_x$；自相关只依赖**时间差**，写成单变量函数：
> $$
> R_x(\tau) := E[x(t+\tau)x(t)]
> $$
> 平均功率 $E[x(t)^2] = R_x(0)$，与时间无关。这是全书分析抖动/相位噪声的标准假设。

### A.2.5 宽循环平稳过程（Wide-Sense Cyclostationary Processes）

若均值与自相关对**周期 $T$ 的整数倍**平移不变，则称宽循环平稳：

$$
\mu_x(t+mT) = \mu_x(t),\qquad R_x(t,\tau) = R_x(t+mT,\tau),\qquad \forall\;m\in\mathbb{Z}
$$

> [!note] 相位随机化（phase randomization）
> 设 $x(t)$ 为周期 $T$ 的宽循环平稳过程，$u$ 为独立于 $x(t)$、在 $[0,T]$ 上均匀分布的随机变量，则时移过程 $y(t) = x(t-u)$ 是**宽平稳**的。$y$ 的均值与自相关等于 $x$ 相应量在一个周期内的**时间平均**：
> $$
> m_y = \frac{1}{T}\int_0^T m_x(t)\,dt,\qquad R_y(\tau) = \frac{1}{T}\int_0^T R_x(t,\tau)\,dt
> $$
> 当原过程的相位未知或不关心时，这是把循环平稳性降为宽平稳性的标准手段——振荡器噪声分析中大量使用。

### A.2.6 高斯过程（Gaussian Processes）

若对任意整数 $n$、任意 $n$ 个采样时刻与任意系数 $a_1 \dots a_n$，线性组合

$$
Y = \sum_{i=1}^{n} a_i\,x(t_i)
$$

都是高斯随机变量，则 $x(t)$ 为**高斯（正态）过程**。

> [!important] 高斯过程的全部统计性质仅由均值与自协方差（或自相关）完全确定。这是它成为噪声建模"默认选择"的根本原因：只需两个函数即可掌握一切；且高斯过程通过线性系统后仍为高斯过程。

### A.2.7 功率谱密度与 Wiener–Khinchin 定理

设 $x(t)$ 宽平稳。为考察其能量在频率上的分布，先取有限时段 $[-T/2, +T/2]$ 上的傅里叶变换：

$$
X_T(f) := \int_{-T/2}^{+T/2} x(t)\,e^{-j2\pi f t}\,dt
$$

由 Parseval 定理，$\int|X_T(f)|^2 df$ 是该时段内的信号能量，故 $\frac{1}{T}|X_T(f)|^2$ 可解释为**功率的频域分布**（对每个 $f$ 它是随机变量）。**功率谱密度**（PSD）定义为其期望在大 $T$ 下的极限：

$$
S_x(f) := \lim_{T\to\infty}\frac{1}{T}\,E\!\left[|X_T(f)|^2\right]
$$

> [!important] Wiener–Khinchin 定理
> 对"行为良好"的宽平稳过程，上述极限存在且等于**自相关的傅里叶变换**：
> $$
> S_x(f) = \int_{-\infty}^{+\infty} R_x(\tau)\,e^{-j2\pi f\tau}\,d\tau,\qquad R_x(\tau) = \int_{-\infty}^{+\infty} S_x(f)\,e^{j2\pi f\tau}\,df
> $$
> 直接推论：总功率 = 零滞后自相关 = PSD 的全频积分：
> $$
> R_x(0) = \int_{-\infty}^{+\infty} S_x(f)\,df
> $$
> 第 3 章"由 $\mathcal{L}(f)$ 积分求 RMS 抖动"的全部公式都根植于此。

### A.2.8 功率谱密度的工程定义

工程实践中 PSD 有四种常见变体，极易混淆，务必分清：

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 双边 PSD（two-sided） | $S_x(f)$，即自相关的傅里叶变换（前述标准定义） | 正负频率都保留 |
| 单边 PSD（one-sided） | $S_x^{1}(f) = \begin{cases}0 & f<0\\ S_x(f) & f=0\\ 2S_x(f) & f>0\end{cases}$ | 只留正频率、幅度加倍以保持总功率；仅当双边谱为**偶函数**（$x(t)$ 为实过程）时有意义 |
| 单边带 PSD（SSB） | $S_{\mathrm{SSB},x}(f) := S_x^{1}(f_0 + f)$ | 把频率原点平移到 $f_0$；$f$ 的含义变为**相对 $f_0$ 的偏移频率**——无线通信中 $f_0$ 即载波，$\mathcal{L}(f)$ 用的正是这套语言；与单边 PSD 数值相同，仅频率轴平移 |
| 双边带 PSD（DSB） | $S_{\mathrm{DSB},x}(f) = \begin{cases}0 & f<0\\ S_{\mathrm{SSB},x}(f) & f=0\\ 2S_{\mathrm{SSB},x}(f) & f>0\end{cases}$ | SSB 的"单边化"；仅当 SSB 谱关于零对称时成立——调相载波满足，若同时有幅度调制则 SSB 不对称、DSB 定义失效 |

### A.2.9 功率谱密度的物理意义

> [!important] 单边 PSD = 1 Hz 带宽内测得的平均功率
> $$
> S_x^{1}(f_0) = E[P(f_0,\,1\,\mathrm{Hz})]
> $$
> 即：信号在频率 $f_0$ 附近 1 Hz 带宽内所携带的、实际耗散在负载上的平均功率。

**思想实验**：设 $x$ 为电压源加在 $1\,\Omega$ 电阻上的电压，瞬时功耗 $P(t) = x^2(t)$。在源与电阻之间插入理想带通滤波器 $B(f)$（通带为 $f_0 \pm 0.5$ Hz 及其负频镜像，增益 1），测量电阻上的平均功耗。测量过程等效为零频增益为 1 的低通 $H(f)$，故

$$
E[P(f_0,1\,\mathrm{Hz})] = E[y^2(t)] = R_y(0) = \int_{-\infty}^{+\infty} S_x(f)\,B^2(f)\,df
$$

由于 $S_x(f)$ 在 1 Hz 窄带内近似常数，积分退化为两段带宽各 1 Hz 的求和：

$$
R_y(0) = 2\,S_x(f_0) = S_x^{1}(f_0)
$$

这正是频谱分析仪等仪器"读数"背后的物理图景。

### A.2.10 随机过程与线性系统

设线性时不变系统 $\mathcal{L}$（冲激响应 $h(t)$、频率响应 $H(f)$）对输入过程 $x(t)$ 的响应为 $y(t) = \mathcal{L}[x(t)]$。

| 概念 | 公式 | 备注 |
| --- | --- | --- |
| 输出的均值 | $E[y(t)] = \mathcal{L}[E[x(t)]]$；$\mu_y(t) = \displaystyle\int_{-\infty}^{+\infty}\mu_x(t-\tau)h(\tau)\,d\tau$ | 期望是线性算子，可与系统交换次序；**不要求 $x(t)$ 平稳** |
| 输出的自相关 | $R_y(t_1,t_2) = \displaystyle\iint R_x(t_1-\tau_1,\,t_2-\tau_2)\,h(\tau_1)h(\tau_2)\,d\tau_1 d\tau_2$ | 线性变换作用于两个时间变量 |
| WSS 输入的均值 | $\mu_y = \mu_x \displaystyle\int h(t)\,dt = \mu_x H(0)$ | |
| WSS 输入的自相关 | $R_y(\tau) = \displaystyle\int R_x(\tau-\tau_1)\,c_h(\tau_1)\,d\tau_1$，其中 $c_h(\tau_1) := \displaystyle\int h(\tau_1+\tau_2)h^*(\tau_2)\,d\tau_2$ | $c_h$ 是冲激响应的确定性自相关 |
| PSD 关系 | $S_y(f) = S_x(f)\,|H(f)|^2$ | **全书使用频率最高的一条**：第 10 章用数字滤波器整形白噪声生成任意相位噪声轮廓，理论依据就是它 |

### A.2.11 遍历性（Ergodicity）

期望算子给出的是"同一时刻、所有可能实现"上的概率加权平均（**集平均**）；但实践中往往只有**一次实现**的数据。能否用单次实现上的**时间平均**（如 $\frac{1}{2T}\int_{-T}^{+T} x(t)\,dt$）代替集平均，是随机过程理论的核心应用问题。

> [!important] 定义与条件
> 若过程的统计性质可以通过对**任意一次实现**做时间平均可靠地估计出来，则称该过程**遍历**（ergodic）。特别地，分别称**均值遍历**与**相关遍历**。
> - 统计性质随时间变化的过程不可能遍历 ⇒ **宽平稳是必要条件，但不充分**（遍历过程是宽平稳过程的真子集）。
> - 一个简单有力的**充分条件**：自协方差 $C_x(\tau) \to 0$（$\tau$ 大时，渐近不相关）⇒ 均值遍历。
> - 该条件一般不保证相关遍历；**但高斯过程例外**：渐近不相关的高斯过程同时是均值遍历与相关遍历的。
>
> 工程含义：实验室里对一段时钟波形做长时间平均来估计 RMS 抖动、或用单次仿真数据估 PSD（第 10 章做法），其合法性正建立在（近似的）平稳性与遍历性之上。

| CDF / PDF | $F_X(a)=P[X\leq a]$；$f_X(a)=\partial F_X/\partial a$ | 分布与密度 |
| 期望（连续） | $E[X]=\int a f_X(a)\,da$ | 概率加权平均，线性算子 |
| 期望基本定理 | $E[g(X)]=\int g(a)f_X(a)\,da$ | 无须先求新变量的分布 |
| 特征函数 | $\Phi_X(\omega)=E[e^{j\omega X}]$ | PDF 傅里叶变换的共轭；微分求各阶矩 |
| 方差 | $\sigma_X^2 = E[(X-\mu_X)^2] = E[X^2]-\mu_X^2$ | |
| 相关/协方差 | $R_{XY}=E[XY]$；$C_{XY}=R_{XY}-\mu_X\mu_Y$ | 独立 ⇒ 不相关 |
| 相关系数 | $\rho_{XY}=C_{XY}/(\sigma_X\sigma_Y)$，$|\rho_{XY}|\leq1$ | |
| 过程均值/自相关 | $\mu_x(t)=E[x(t)]$；$R_x(t_1,t_2)=E[x(t_1)x(t_2)]$ | |
| 自协方差 | $C_x(t_1,t_2)=R_x(t_1,t_2)-\mu_x(t_1)\mu_x(t_2)$ | |
| WSS 自相关 | $R_x(\tau)=E[x(t+\tau)x(t)]$ | 功率 $=R_x(0)$ |
| 循环平稳→WSS | $R_y(\tau)=\frac{1}{T}\int_0^T R_x(t,\tau)\,dt$ | 相位随机化 $y(t)=x(t-u)$ |
| PSD 定义 | $S_x(f)=\lim_{T\to\infty}\frac{1}{T}E[|X_T(f)|^2]$ | |
| Wiener–Khinchin | $S_x(f)=\int R_x(\tau)e^{-j2\pi f\tau}d\tau$ | PSD ↔ 自相关互为傅里叶变换对 |
| 总功率 | $R_x(0)=\int S_x(f)\,df$ | RMS 抖动积分的依据 |
| 单边 PSD | $f>0$ 时 $S_x^{1}=2S_x$ | 总功率守恒 |
| SSB / DSB | $S_{\mathrm{SSB}}(f)=S_x^{1}(f_0+f)$；$f>0$ 时 $S_{\mathrm{DSB}}=2S_{\mathrm{SSB}}$ | $\mathcal{L}(f)$ 的语言体系 |
| PSD 物理意义 | $S_x^{1}(f_0)=E[P(f_0,1\,\mathrm{Hz})]$ | 1 Hz 带宽内的平均功率 |
| 线性系统输出 | $\mu_y=\mu_x H(0)$；$S_y(f)=S_x(f)|H(f)|^2$ | 噪声整形的理论基础 |
| 遍历性充分条件 | $C_x(\tau)\to0\ (\tau\to\infty)$ ⇒ 均值遍历 | 高斯过程同时相关遍历 |

## 要点总结

- 随机变量是把实验结果映射为实数的函数；随机过程是映射为时间函数的函数，固定时刻即退化为随机变量。
- CDF/PDF 描述幅度维（y 轴）的分布，期望是线性算子；期望基本定理允许绕过新变量分布直接求 $E[g(X)]$。
- 独立 ⇒ 不相关（$E[XY]=E[X]E[Y]$），反之不然；相关、协方差、相关系数层层归一化，$|\rho_{XY}|\leq1$。
- 宽平稳（WSS）只需均值恒定、自相关仅依赖滞后 $\tau$，是全书噪声分析的默认假设；严格平稳 ⇒ 宽平稳。
- 循环平稳过程经**相位随机化**（随机均匀时移）化为 WSS，其统计量为原过程一个周期内的时间平均——振荡器噪声分析的标准技巧。
- 高斯过程由均值与自相关完全刻画，且通过线性系统后仍为高斯，是噪声建模的默认选择。
- Wiener–Khinchin 定理：PSD 与自相关互为傅里叶变换对；总功率 $= R_x(0) = \int S_x(f)df$，这是由 $\mathcal{L}(f)$ 积分求抖动的理论根基。
- PSD 的四种工程定义（双边/单边/SSB/DSB）极易混淆：单边 = 正频率加倍；SSB = 把原点平移到载波 $f_0$（偏移频率语言）；DSB 仅在纯调相（谱对称）时成立。
- 单边 PSD 的物理意义：信号在 $f_0$ 附近 1 Hz 带宽内耗散在负载上的平均功率。
- 随机过程通过线性系统：均值乘 $H(0)$，PSD 乘 $|H(f)|^2$；遍历性保证可用单次实现的时间平均代替集平均，渐近不相关的高斯过程同时均值遍历与相关遍历。
